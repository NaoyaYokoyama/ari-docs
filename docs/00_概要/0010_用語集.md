# 0010_用語集 用語集

| 用語 | 説明 | 関連 |
|---|---|---|
| ノード | `folder/` 以下にあるファイルまたはフォルダ。画面上は「Folder」 | FN0301, TBL0301 |
| 作業フォルダ | デスクトップアプリがファイルとデータを置くフォルダ。既定は exe と同じフォルダで、設定画面から変えられる。中に `folder/`（ノードのルート）と `.ari-docs/`（DB などのデータ）を置く | FN0002 |
| ノードのルート | ノードを置く最上位のフォルダ。デスクトップアプリでは `<作業フォルダ>/folder`、開発時は `back/config.toml` の `folder_root`（既定は `folder/`）。設計書では `folder/` と書く | FN0301 |
| ノードのパス | ノードのルートからの相対パス。先頭に `/` を付けない（例: `a/b/memo.txt`） | FN0301 |
| Note | 個人用の Markdown のメモ。画面・文書ともに「Note」と呼ぶ | FN0401, TBL0401 |
| Wiki | チームで共有する想定の Markdown の文書。ローカルモードでは Note と同じく利用者 1 人が使う | FN0501, TBL0501 |
| 作成者 | Note・Wiki を作成したユーザー。`user_id` に保存する | TBL0401, TBL0501 |
| お気に入り | ノード・Note・Wiki へのショートカット | FN0601, TBL0601 |
| ローカルモード | 1 人で PC 上で使う動作モード。ログイン不要。本設計書の対象 | FN0101 |
| 共有モード | 複数人でサーバー上の ari-docs を使う動作モード（`mode = "shared"`）。利用者はデスクトップアプリから接続し、ログインして使う | FN0101、OP0007 |
| ユーザー `local` | ローカルモードで処理に使う唯一のユーザー | FN0101, TBL0101 |
| マイグレーション | `back/src/data/migration/` の SQL。実行ファイルに埋め込み、起動時に未適用のものを番号順に実行する | TBL0001 |
| ノード同期 | `folder/` 以下のパスを `node` テーブルに登録するバッチ | BAT0301 |
| Markdown ビューア | 指定したフォルダの Markdown を閲覧専用で表示する画面。画面上は「Docs」 | FN0801 |
| Docs の初期フォルダ | Markdown ビューアを開いたときに表示するフォルダ。設定画面で設定する | FN0701, TBL0701 |
| front matter | Markdown の先頭に `---` で囲んで書く YAML の定型情報 | FN0801 |
| UAT | ユーザー受入テスト | - |
