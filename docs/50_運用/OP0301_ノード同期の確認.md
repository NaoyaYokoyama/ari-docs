# OP0301 ノード同期の確認

## 1. 概要

| 項目 | 値 |
|---|---|
| 目的 | ノード同期バッチ（BAT0301）が動いているかを確かめる |
| 実行するタイミング | お気に入りや `node` テーブルの内容がおかしいとき |
| 前提 | バックエンドを起動済み（OP0001） |

バッチはバックエンドと同じプロセスで動き、起動中だけ実行される。

| バッチ | 実行間隔 | ログ |
|---|---|---|
| BAT0301 ノード同期 | 毎分 00 秒 | 失敗時のみ `Node sync failed: <内容>`（標準エラー） |
| BAT0001 ヘルスチェック | 5 分ごと | `index batch executed start` / `end`（標準出力） |

## 2. 手順

1. `folder/` にファイルを置き、1 分待つ。
2. `back/` で `node` テーブルを確認する。

```bash
cd back
sqlite3 data/ari.db "select path from node order by path;"
```

## 3. 確認方法

- 置いたファイルのパスが `folder/` からの相対パス（先頭に `/` や `../folder/` が無い）で登録されている

## 4. うまくいかないとき

| 症状 | 原因 | 対処 |
|---|---|---|
| 行が追加されない | バックエンドが止まっている | OP0001 で起動する |
| `../folder/...` 形式の行がある | 修正前のバッチが登録した古い行 | `sqlite3 data/ari.db "DELETE FROM node WHERE path LIKE '../folder/%';"`（正しい形式の行は別にある） |
| `folder/` から消したファイルの行が残る | 現行のバッチは追加だけで、削除しない | 仕様（BAT0301 の未決事項） |
