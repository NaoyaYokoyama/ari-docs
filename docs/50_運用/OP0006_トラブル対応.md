# OP0006 トラブル対応

## 1. 概要

| 項目 | 値 |
|---|---|
| 目的 | 使っているとき・開発中によく起きる問題の原因と対処をまとめる |
| 実行するタイミング | 問題が起きたとき |
| 前提 | - |

## 2. 手順

症状から原因を探し、対処を行う。

| 症状 | 原因 | 対処 |
|---|---|---|
| デスクトップアプリの起動エラーの画面（SCR0002）に「ari-docs はもう起動しています」と出る | 同じ PC で ari-docs がもう動いている（8080〜8099 のどれかを使っている）。開発時は `cargo run` のバックエンドが残っている | 動いている ari-docs を使うか、止めてから起動する（FN0002-BR22） |
| 起動エラーの画面に「ポート 8080〜8099 がすべて使われています」「ポート {番号} をほかのアプリが使っています」と出る | ほかのアプリがポートを使っている。この PC を公開しているときは決めたポートだけを使う | ほかのアプリを止めるか、設定の「この PC の公開」でポートを変える（FN0005-BR10）。開発時は `ss -ltnp \| grep 8080` で確かめる |
| 共有サーバーにつながらない画面が出る | サーバーが止まっている・URL が違う・ネットワークに入っていない | サーバーの PC で ari-docs（サーバー）が動いているか、URL（`http://<名前か IP>:<ポート>`）を確かめる。自分の PC の場所に切り替えれば個人用は使える（FN0002-BR18・BR19） |
| ログインで「ログインに続けて失敗したため、15 分間ログインできません」と出る | パスワードを続けて間違えた（既定 5 回） | 時間をおいて試す。パスワードを忘れたら管理者に再設定してもらう（FN0101・FN0902） |
| 管理者なのに管理の画面が出ない・「この PC は管理者の PC ではないため…」と出る | 管理者の PC に登録していない PC から使っている（FN0102-BR12） | 登録した PC の設定の「管理者の PC」で発行したコード（10 分有効）を入れる。すべて失ったときは、サーバーのデータのフォルダの `setup-code.txt` の登録用のコードを使う |
| ファイルを上書き・移動・削除しようとすると「{名前}さんがロックしています」と出る | ほかの人がファイルをロックしている（FN0301-BR38） | 期限まで待つか、ロックした人か管理者に外してもらう（設定の「ロック中のファイル」） |
| ホームの検索でファイルの中身が見つからない | 取り込みがまだ（数分かかる）・検索の対象外・100 MB を超えるファイル・取り込まない形 | 数分待つ。設定の「検索の対象外」「対応するファイル」を確かめる（FN0202） |
| 新しい版のお知らせが出ない | 設定の「情報」の更新を調べない設定にしている。共有サーバーにつないでいるときはサーバーと同じ版までしか上げない | 設定の「情報」の「更新を確認」を押す。共有サーバーの版を先に上げる（FN0904） |
| デスクトップアプリで「作業フォルダで起動できませんでした」と出る | 作業フォルダを移動・削除した。共有フォルダに繋がっていない | 作業フォルダを元に戻すか、画面で選び直す（FN0002-BR07） |
| デスクトップアプリで「exe のフォルダに書き込めません」と出る | exe を Program Files・`/usr/bin` など書き込めないフォルダに置いた | exe を書き込めるフォルダ（ホームの下など）にフォルダごと移す（FN0002-BR06） |
| 画面は出るが、新しく追加した画面・API が動かない（404 など） | バックエンドが変更前のまま動いている | バックエンドを再起動する（OP0001） |
| 画面に `Failed to resolve import "xxx"` と出る | ホストでだけパッケージを入れた。開発サーバーのコンテナの `node_modules` は別の領域 | リポジトリのルートで `docker compose exec frontend npm install` → `docker compose restart frontend` |
| API がすべて 401 になる | DB にユーザー `local` が無い（通常は起動時に作られる） | バックエンドを再起動する（OP0004） |
| バックエンドの起動時に `folder_root が見つかりません` で止まる | ノードのルート（`config.toml` の `folder_root`）が無い | OP0005 |
| API の呼び出しが CORS エラーになる | フロントを `http://localhost:5173` 以外で開いている | `http://localhost:5173` で開く（OP0003） |
| 起動時に `Failed to execute migration` で止まる | マイグレーションの SQL の誤り | OP0004 の 4 |
| Markdown ビューアで「フォルダを読み込めませんでした」と出る | 指定したパスが無い、フォルダではない | 絶対パスを確認する。空欄で「表示」を押すと `docs/` に戻る |
