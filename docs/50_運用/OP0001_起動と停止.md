# OP0001 起動と停止

## 1. 概要

| 項目 | 値 |
|---|---|
| 目的 | アプリを起動・停止する（利用者向けのデスクトップアプリと、開発時の 2 通り） |
| 実行するタイミング | 使い始めるとき、終えるとき |
| 前提 | 開発時は開発環境を構築済み（TL0001） |

| 使い方 | 画面 | バックエンド（API・バッチ） | 設定 |
|---|---|---|---|
| デスクトップアプリ（利用者） | アプリのウィンドウ | アプリと同じプロセス | exe と同じフォルダの `config.toml`（FN0002） |
| 開発時（ブラウザ） | Docker の開発サーバー `http://localhost:5173` | `cd back && cargo run`（`127.0.0.1:8080`） | `back/config.toml`（OP0003） |
| 開発時（デスクトップアプリ） | Docker の開発サーバーを Tauri のウィンドウで表示 | アプリと同じプロセス（`cargo run` は止めておく） | `back/config.toml`（デバッグビルドのため。FN0002） |

## 2. 手順

### 2.1 デスクトップアプリ（利用者）

1. 書き込めるフォルダに置いた exe（ari-docs）を起動する。
2. ホームが開く。初回は exe の隣に `config.toml`・`folder/`・`.ari-docs/` ができる（FN0002）。
3. 終えるときはウィンドウを閉じる（バックエンドも止まる）。

### 2.2 開発時（ブラウザ）

1. フロントエンドの開発サーバーを起動する（リポジトリのルートで実行）。

```bash
docker compose up -d
```

2. バックエンドを起動する（`back/` で実行する。`config.toml` の相対パスは `back/` から解決する）。

```bash
cd back
cargo run
```

3. ブラウザで `http://localhost:5173` を開く。
4. 停止: バックエンドは `Ctrl+C`、開発サーバーはリポジトリのルートで `docker compose down`。

### 2.3 開発時（デスクトップアプリ）

1. 2.2 の 1 で開発サーバーを起動する。`cargo run` のバックエンドは止めておく（同じポート 8080 を使うため）。
2. `desktop/src-tauri/` で実行する。

```bash
cargo tauri dev
```

3. 停止はウィンドウを閉じる。

## 3. 確認方法

- デスクトップアプリ: ホームが表示される
- 開発時: バックエンドの端末に `Server running: http://127.0.0.1:8080` と表示され、`curl http://127.0.0.1:8080/api/me` でユーザー `local` の情報が返る
