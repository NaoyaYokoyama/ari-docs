# OP0005 フォルダの準備

## 1. 概要

| 項目 | 値 |
|---|---|
| 目的 | ノード（Folder 画面のファイル・フォルダ）の置き場所（ノードのルート）を用意する |
| 実行するタイミング | 開発時、初めて起動する前（デスクトップアプリは起動時に作業フォルダに自動的に作られる。FN0002） |
| 前提 | - |

ノードのルートは `back/config.toml` の `folder_root`（既定は `../folder`、つまりリポジトリの `folder/`）。`folder/` は git の管理対象外（`.gitignore`）なので、リポジトリを取得した直後には無い。中身はテスト用のデータとして扱う。ルートが無いとバックエンドは起動しない。

## 2. 手順

既定のまま使う場合は、リポジトリのルートで実行する。

```bash
mkdir -p folder
```

別の場所を使う場合は、そのフォルダを作り、`back/config.toml` の `folder_root` にパスを書く（OP0003）。運用を始めたあとは変えない。

## 3. 確認方法

- Folder 画面を開くと、`folder/` 直下の一覧（空なら何も無い一覧）が表示される

## 4. うまくいかないとき

| 症状 | 原因 | 対処 |
|---|---|---|
| バックエンドの起動時に `folder_root が見つかりません` で止まる | ノードのルートが無い | 2 の手順でフォルダを作る |
| Folder 画面の一覧が表示されず、バックエンドの端末にパニックのメッセージが出る | 存在しないフォルダを開こうとした（起動後にフォルダを消した場合など） | ホームから開き直す |
