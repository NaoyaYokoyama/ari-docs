# OP0008 バックアップと復元

## 1. 概要

| 項目 | 値 |
|---|---|
| 目的 | 定期のバックアップを設定し、必要なときに復元する |
| 実行するタイミング | 使い始めるとき（設定）・データを戻したいとき（復元） |
| 前提 | ローカルモード、または共有モードの管理者でログインしている |

## 2. 手順

### 2.1 定期のバックアップを設定する

1. 設定画面の「バックアップ」を開く。
2. 「自動のバックアップ」（毎日など）・時刻・保存期間を選ぶ。保存先は、できれば別のドライブや別の PC の共有フォルダにする（絶対パス）。
3. 「設定を保存」を押す。時刻を過ぎていれば、1 分以内に最初のバックアップが取られる。

### 2.2 復元する

1. 設定画面の「バックアップ」の一覧で、戻したい時点の「この時点に戻す」を押し、確認で OK を押す。
2. 今の状態が「復元の前」のバックアップとして残るので、間違えたときはそれを復元し直す。
3. 共有モードでは、復元中はほかの人の操作が失敗することがある。利用者の少ない時間に行う。

### 2.3 別の PC へ移す

1. 「ダウンロード」でバックアップの ZIP を保存する。
2. 移す先で ari-docs を個人用として起動し、ZIP の中の `folder/` の中身を作業フォルダの `folder/` に、`ari.db` を `.ari-docs/ari.db` に置く（アプリを閉じてから）。

## 3. 確認方法

- 一覧に「定期」のバックアップが出ている。ファイルは保存先の `ari-docs_<日時>_auto.zip`
- 起動したターミナル（共有サーバー）に `backup: created <ファイル名>` が出る

## 4. うまくいかないとき

| 症状 | 原因 | 対処 |
|---|---|---|
| 「保存先のフォルダが見つかりません」 | 保存先が無い・相対パス | フォルダを作るか、絶対パスで入れ直す |
| 一覧に「ファイルが見つかりません」 | 保存先のファイルを手で移動・削除した | 元の場所に戻すか、一覧から削除する |
| 定期のバックアップが取られない | 「しない」になっている、アプリ（サーバー）が止まっている | 設定を見直す。アプリが動いている間だけ取る |
| 容量が足りない | ファイルが多く、保存期間が長い | 保存期間を短くするか、容量の大きい保存先にする |
