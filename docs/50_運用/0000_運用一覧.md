# 0000_運用一覧 運用一覧

デスクトップアプリの使い方と、開発・動作確認のための手順。開発時に初めて使うときは OP0005 → OP0001 の順に行う。

| ID | 手順 | 概要 |
|---|---|---|
| [OP0001](OP0001_起動と停止.md) | 起動と停止 | デスクトップアプリと、開発時（ブラウザ・デスクトップアプリ）の起動・停止 |
| [OP0002](OP0002_ビルド.md) | ビルド | 配布物（Windows は NSIS のインストーラー、Linux は AppImage）の作成 |
| [OP0003](OP0003_設定.md) | 設定 | デスクトップアプリと開発時の設定ファイル、コードで固定している値 |
| [OP0004](OP0004_DBの初期化.md) | DB の初期化 | DB の場所と自動作成、開発用 DB の作り直し |
| [OP0005](OP0005_フォルダの準備.md) | フォルダの準備 | `folder/` の作成 |
| [OP0006](OP0006_トラブル対応.md) | トラブル対応 | よく起きる問題の原因と対処 |
| [OP0007](OP0007_共有サーバーの構築と起動.md) | 共有サーバーの構築と起動 | 共有モードのバックエンドの用意・起動と、最初の管理者の登録 |
| [OP0008](OP0008_バックアップと復元.md) | バックアップと復元 | 定期のバックアップの設定と、復元・別の PC への移行 |
| [OP0301](OP0301_ノード同期の確認.md) | ノード同期の確認 | ノード同期バッチの動作確認 |
