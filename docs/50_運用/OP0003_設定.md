# OP0003 設定

## 1. 概要

| 項目 | 値 |
|---|---|
| 目的 | アプリの設定を確認・変更する |
| 実行するタイミング | 設定を確認するとき |
| 前提 | - |

設定ファイルは、デスクトップアプリと開発時で別。

## 2. 手順

### 2.1 デスクトップアプリ

exe と同じフォルダの `config.toml`（FN0002 の 2 章）。インストーラー（Windows）か初回起動の画面で使い方を選ぶと作られる。

```toml
# local（個人用）/ server（共有サーバーに接続）。無ければ local
mode = "local"
# 個人用の作業フォルダ。相対パスは exe のフォルダから。"." は exe と同じフォルダ（既定）
workspace = "."
# 共有サーバーの URL（mode = "server" のとき）
server_url = "http://ari-server:8080"
```

- 使い方は設定画面の「使い方」で変える（FN0002-BR15）

- 作業フォルダは設定画面の「作業フォルダ」で変える（FN0002-BR08）。このファイルを直接書き換えてもよい（アプリを閉じてから書き換え、起動し直す）
- デバッグビルドのデスクトップアプリはこのファイルを使わず、2.2 の `back/config.toml` で動く
- ノードのルート・DB・Markdown ビューアの既定のフォルダは作業フォルダから決まる（`folder/`、`.ari-docs/ari.db`、`folder/`）

### 2.2 開発時

`back/config.toml`。変更したらバックエンドを再起動する（OP0001）。

```toml
mode = "local"
folder_root = "../folder"
```

| 項目 | 値（省略時） | 説明 |
|---|---|---|
| `mode` | （必須） | `local` はローカルモード、`shared` は共有モード（OP0007） |
| `bind_address` | `0.0.0.0` | 共有モードで待ち受けるアドレス。ローカルモードでは使わず、常に `127.0.0.1`（FN0101-BR06） |
| `tls_cert` / `tls_key` | （空） | 共有モードの HTTPS の証明書・秘密鍵（PEM）。両方あれば HTTPS（FN0101-BR14。OP0007） |
| `port` | `8080` | 待ち受けるポート（`cargo run`・共有サーバー。デスクトップアプリの個人用は常に 8080） |
| `folder_root` | `../folder` | ノードのルート。`back/` からの相対パスか絶対パス。運用中は変えない（FN0301-BR11） |
| `database_path` | `data/ari.db` | DB ファイル。`back/` からの相対パスか絶対パス |
| `docs_default_root` | `../docs` | Markdown ビューアの既定のフォルダ（FN0801-BR01） |
| `ocr_models_dir` | `models` | 文字認識のモデルのフォルダ（FN0202-BR15）。`back/` からの相対パスか絶対パス。開発時はビルドのときに `back/models/` に用意される（OP0002）。デスクトップアプリは同梱のものを使うので書かない |

引数なしで起動すると `back/config.toml`（パスはビルド時に決まる）を、`back <設定ファイル>` で起動するとその設定ファイルを読む（共有サーバー。OP0007）。相対パスは設定ファイルのフォルダから解決する。

### 2.3 コードで固定している値

| 値 | 場所 |
|---|---|
| デスクトップアプリ（個人用）の待ち受けポート `8080` | `desktop/src-tauri/src/lib.rs` |
| CORS の許可元 `http://localhost:5173`・`tauri://localhost`・`http://tauri.localhost` | `back/src/router.rs` |
| 画面から見た API の URL `http://localhost:8080`（共有サーバーに接続するときは `server_url` に変わる） | `front/src/api/client.ts` |

## 3. 確認方法

- 開発時: 起動時に `config path = <パス>/back/config.toml` と `Database connected: <DB のパス>` が表示される
- `curl http://127.0.0.1:8080/api/me` の `mode` が設定した値になっている

## 4. うまくいかないとき

| 症状 | 原因 | 対処 |
|---|---|---|
| 起動時に `Failed to read config.toml` で止まる | 開発用の設定ファイルが無い | `back/config.toml` を作る |
| 起動時に `Failed to parse config.toml` で止まる | 書き方の誤り、`mode` の値が `local` / `shared` 以外 | 書き方を直す |
| 起動時に `folder_root が見つかりません` で止まる | ノードのルートが無い | フォルダを作る（OP0005）か、`folder_root` を直す |
| 設定の「対応するファイル」で文字認識が「使えません」 | `models` フォルダか、その中のモデルのファイルが無い | 開発時は `back/` で `cargo build` し直す（ビルドのときに取得する。OP0002）。共有サーバーは `models` フォルダを `config.toml` の横に置くか `ocr_models_dir` を直す（OP0007）。デスクトップアプリは入れ直す。そのあと起動し直す |
