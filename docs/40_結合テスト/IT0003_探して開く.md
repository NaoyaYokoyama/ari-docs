# IT0003 探して開く

## 1. 基本情報

| 項目 | 値 |
|---|---|
| 目的 | どの画面からでも名前の一部で Note・Wiki・ファイル・フォルダ・画面・操作を探して開け、最近開いたものに戻れること |
| 対象 | FN0003, FN0702, API0207, SCR0001 |
| 結果 | 未実施 |

## 2. 前提条件

- `folder/qo-test/` に `alpha.txt`・`beta.txt`・`sub/議事録ﾒﾓ.txt`（半角カナ）がある（ノード同期の後）
- Note「テスト」があり、Wiki「手順」がフォルダ「手順書」に入っている

| No | 操作 | 期待結果 | 確認するルール・API | 結果 |
|---|---|---|---|---|
