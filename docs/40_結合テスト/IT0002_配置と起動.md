# IT0002 配置と起動

## 1. 基本情報

| 項目 | 値 |
|---|---|
| 目的 | exe を置いて起動してから、2 回目以降の起動、作業フォルダの変更、起動エラーからの復帰までが一続きで動くこと |
| 対象 | FN0002, SCR0002, SCR0701, API0001, API0002, API0003, OP0002 |
| 結果 | 未実施 |

## 2. 前提条件

- 配布物（OP0002）がある。Windows はインストーラーで入れたフォルダ（`%LOCALAPPDATA%\ari-docs\`）を、Linux は `.AppImage` を置いたフォルダを、下の `ari-it` と読み替える
- ポート 8080 を使っているプロセスが無い（`cargo run` のバックエンドは止めておく）

## 3. 手順と期待結果

| No | 操作 | 期待結果 | 確認するルール・API | 結果 |
|---|---|---|---|---|
| 1 | 空のフォルダ `ari-it` に exe（`.AppImage`）だけを置いて起動し、初回起動の画面（SCR0003）で「個人用」を選んで「保存して再起動」を押す（Windows はインストーラーの最初のページで「個人用」を選んでインストールし、起動する） | ホームが表示される。`ari-it/config.toml`（`mode = "local"`・`workspace = "."`）・`ari-it/folder/`・`ari-it/.ari-docs/ari.db` ができている | FN0002-BR03、FN0002-BR05、FN0002-BR11、API0001、API0004 | 未実施 |
| 2 | Folder 画面でフォルダ `test` を作り、Note を 1 件作る | `ari-it/folder/test/` ができ、Note が一覧に出る | FN0301、FN0401 | 未実施 |
| 3 | アプリを閉じて、もう一度起動する | ホームが表示される。作ったフォルダと Note が残っている | FN0002 の 5.1 | 未実施 |
| 4 | 設定画面の「作業フォルダ」で空のフォルダ `ari-it-ws` を選ぶ | `folder/` と `.ari-docs/` を作ることが表示される | FN0002-BR02、API0002 | 未実施 |
| 5 | 「このフォルダで再起動」を押す | アプリが再起動し、Note は 0 件。`config.toml` の `workspace` が `ari-it-ws` の絶対パスになっている | FN0002-BR08、FN0002-BR09、API0003 | 未実施 |
| 6 | アプリを閉じ、`ari-it-ws` を `ari-it-ws2` に名前を変えて起動する | 起動エラーの画面（SCR0002）に MSG0003 が表示される | FN0002-BR01、FN0002-BR07 | 未実施 |
| 7 | `ari-it` を選んで「このフォルダで再起動」を押す | 既存のデータを使う旨（MSG0002）が表示されたあと再起動し、No 2 の Note が表示される。`config.toml` の `workspace` は `"."` に戻っている | FN0002-BR04、FN0002-BR08 | 未実施 |
| 8 | アプリを閉じ、`ari-it` を書き込めないフォルダにコピーし（`config.toml` は消す）、そこから起動して「個人用」を選んで「保存して再起動」を押す | 初回起動の画面に MSG0005 が表示される | FN0002-BR06 | 未実施 |
| 9 | 共有サーバー（OP0007）を起動し、設定画面の「使い方」で「共有サーバーに接続」と URL を入れて「保存して再起動」を押す | 再起動してログイン画面（SCR0004）が表示される。管理者が未登録なら管理者の登録フォームが出る | FN0002-BR12〜BR15、FN0101-BR11 | 未実施 |
| 10 | No 9 で存在しない URL（`http://127.0.0.1:1`）を入れて「保存して再起動」を押す | MSG0006 が表示され、再起動しない | FN0002-BR14 | 未実施 |
