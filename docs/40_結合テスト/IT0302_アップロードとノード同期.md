# IT0302 アップロードとノード同期

## 1. 基本情報

| 項目 | 値 |
|---|---|
| 目的 | ドラッグ＆ドロップでのアップロードと、ノード同期バッチによる `node` テーブルへの登録がつながって動くこと |
| 対象 | FN0301, BAT0301, TBL0301, API0304, API0602 |
| 結果 | 未実施 |

## 2. 前提条件

- アプリを起動済み（OP0001）。ユーザー `local` が DB にある（OP0004）
- PC 上に、ファイル 2 つを入れたフォルダ `it-upload`（中に `sub/b.txt` を含む）を用意する

## 3. 手順と期待結果

| No | 操作 | 期待結果 | 確認するルール・API | 結果 |
|---|---|---|---|---|
| 1 | Folder 画面のルートに `it-upload` フォルダをドロップする | 一覧に `it-upload` が表示され、中に同じ構成でファイルが保存されている | API0304、FN0301-BR06 | 未実施 |
| 2 | 数秒待ち、`sqlite3 back/data/ari.db "select path from node where path like 'it-upload%'"` を実行する | `it-upload`、`it-upload/sub`、`it-upload/sub/b.txt` などが相対パスで登録されている（先頭に `/` や `../folder/` が無い） | BAT0301、FN0301-BR01 | 未実施 |
| 3 | `it-upload/sub/b.txt` をお気に入り登録する | MSG0301 が表示され、`node` に新しい行は増えない（同期済みの行を使う） | API0602、FN0601-BR02 | 未実施 |
| 4 | `it-upload` フォルダを削除し、No 2 のコマンドと `sqlite3 back/data/ari.db "select count(*) from favorite where node_id not in (select node_id from node) and node_id <> ''"` を実行する | `it-upload` で始まる行が無い。ホームのお気に入りから `b.txt` が消え、件数は 0 | API0303、FN0301-BR15 | 未実施 |
