# IT0701 ユーザー設定の変更

## 1. 基本情報

| 項目 | 値 |
|---|---|
| 目的 | 設定画面での表示名と Docs の初期フォルダの変更が保存され、他の画面に反映されること |
| 対象 | FN0701, FN0801, SCR0701, SCR0801, API0701, API0101, API0703, API0801 |
| 結果 | 未実施 |

## 2. 前提条件

- アプリを起動済み（OP0001）。ユーザー `local` が DB にある（OP0004）
- 変更前の表示名を控えておく（`sqlite3 back/data/ari.db "select display_name from user where user_id='local'"`）

## 3. 手順と期待結果

| No | 操作 | 期待結果 | 確認するルール・API | 結果 |
|---|---|---|---|---|
| 1 | 設定画面の「ユーザー名」で「結合テスト」と入れて「変更」を押す | 画面が再読み込みされ、MSG0701 が表示される | API0701、FN0701-BR01 | 未実施 |
| 2 | `http://localhost:8080/api/me` を開く | `displayName` が「結合テスト」になっている | API0101 | 未実施 |
| 3 | Docs 画面で「初期フォルダを変更」を押す | 設定画面が「Docs の初期フォルダ」を選んだ状態で開く | FN0701-BR05 | 未実施 |
| 4 | `folder/` の絶対パスを入れて「保存」を押す | MSG0702 が表示され、「現在」がそのパスになる | API0703、FN0701-BR02 | 未実施 |
| 5 | ヘッダーの Docs を押す | `folder/` 以下の Markdown の一覧が表示される | API0801、FN0801-BR01 | 未実施 |
| 6 | 設定画面に戻り「解除」を押してから、Docs を開く | MSG0704 が表示され、Docs ではリポジトリの `docs/` が表示される | API0703、FN0701-BR03 | 未実施 |

## 4. 後片付け

- 表示名を控えておいた値に戻す
- Docs の初期フォルダを元の設定に戻す
