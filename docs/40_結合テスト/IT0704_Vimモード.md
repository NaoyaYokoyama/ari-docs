# IT0704 Vim モード

## 1. 基本情報

| 項目 | 値 |
|---|---|
| 目的 | Vim モードで、スクロール・ヒント・画面の移動・一覧の操作・本文の Vim での編集と保存ができ、キーを変えるとすぐ効くこと |
| 対象 | FN0702, FN0701 |
| 結果 | 未実施 |

## 2. 前提条件

- 設定画面の「Vim モード」をオンにしている。Note「テスト」がある

## 3. 手順と期待結果

| No | 操作 | 期待結果 | 確認するルール・API | 結果 |
|---|---|---|---|---|
| 1 | 設定画面で `j` を何回か、`5j`、`G`、`gg` を押す | 下へ・5 回分下へ・末尾・先頭にスクロールする | FN0702-BR03・BR04 | 未実施 |
| 2 | `g` を押して待つ | 右下に `g` が出て、1.5 秒で消える | FN0702-BR03 | 未実施 |
| 3 | `f` を押す | 押せるところに文字が出る。ヘッダーの「Wiki」の文字を打つと Wiki の画面へ移る | FN0702-BR05 | 未実施 |
| 4 | `gf` → `j`・`j` → `l` → `h` | Folder の一覧で行を選び、フォルダに入り、上のフォルダへ戻る | FN0702-BR04 | 未実施 |
| 5 | `F` を押し、ファイルの行の文字を打つ | ファイルが開く（ダブルクリックと同じ） | FN0702-BR05 | 未実施 |
| 6 | `/` → 文字を打つ → Esc | 絞り込み欄に移って絞り込み、Esc で絞り込みが消えて入力欄から出る（続けて `j` が効く） | FN0702-BR06 | 未実施 |
| 7 | `gn` → 一覧で「テスト」を開き（表示はプレビュー）、`i` を押す | 分割に切り替わり、本文が挿入モード（下に -- INSERT --）になる | FN0702-BR07・BR08 | 未実施 |
| 8 | 文字を打ち、Esc → `:w` | ノーマルモードに戻り、保存される（「Noteを更新しました」） | FN0702-BR07、API0405 | 未実施 |
| 9 | `:q` | 一覧に移り、`j`・`k` で一覧を動ける | FN0702-BR07 | 未実施 |
| 10 | 設定で「下へ」を `j, <C-n>`、挿入モードを抜けるキーを `jk`、追加の設定に `nnoremap Y y$` を入れる | `Ctrl+N` でも下へ動く。本文で `jk` で挿入モードを抜け、`Y` で行末までコピーできる | FN0702-BR09・BR10 | 未実施 |
| 11 | 「上へ」を `j` にする | 設定画面に「「下へ」と同じキー」の注意が出る | FN0702-BR09 | 未実施 |
| 12 | `?` を押す | 一覧の先頭に「Vim モード」と今のキーが出る | FN0702-BR12 | 未実施 |
| 13 | Folder で `<C-h>` → `j` → `l` → `h` → `<C-l>` → `j` | ツリーに移り、行を選んでフォルダに入り、閉じ、右の一覧に戻って行を選ぶ | FN0702-BR13 | 未実施 |
| 14 | Note で本文（ノーマルモード）・タイトルから `<C-h>`、一覧から `<C-l>`、`<C-k>`・`<C-j>` | 一覧・本文・タイトルの間を移る。今いる領域に枠が出る | FN0702-BR13 | 未実施 |
| 15 | 設定で「左の領域へ」を `<C-w>h` にする | `Ctrl+W` → `h` で一覧へ移る（デスクトップアプリ） | FN0702-BR09・BR13 | 未実施 |
| 16 | 入力欄の外で `o` → `test` → `Enter` | 探して開くが開き、Note「テスト」が開く | FN0702-BR03、FN0003 | 未実施 |
| 17 | Folder でファイルが 3 つあるフォルダを開き、`gg` → `V` → `j` → `j` → `y` | 下の中央に `-- VISUAL LINE -- 3 件` が出て広がり、`y` で「3 件をコピーしました」が出て範囲選択が終わる（3 件は選んだまま） | FN0702-BR14 | 未実施 |
| 18 | `Esc` → `G` → `cw` → `Esc` → `gg` → `j` → `yy` → `p` → `G` → `D` | 選択が外れ、最後の行の名前の欄が開いて閉じ、2 行目のコピーが同じフォルダにでき、最後の行がゴミ箱へ移る | FN0702-BR14 | 未実施 |
| 19 | Vim モードをオフにする | j・k・f などが効かなくなり、本文はこれまでのエディタに戻る | FN0702-BR01 | 未実施 |

## 4. 後片付け

- 設定の「既定に戻す」でキーを戻し、Vim モードをオフにする。手順 18 のコピーをゴミ箱から完全に削除し、ゴミ箱に移したものを元に戻す
