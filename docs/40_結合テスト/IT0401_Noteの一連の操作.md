# IT0401 Note の一連の操作

## 1. 基本情報

| 項目 | 値 |
|---|---|
| 目的 | Note の作成・編集・保存・検索・お気に入り・削除が一続きで動き、削除でお気に入りも消えること |
| 対象 | FN0401, FN0201, FN0601, SCR0401, SCR0201, API0401, API0402, API0403, API0404, API0405, API0201, API0603, API0601 |
| 結果 | 未実施 |

## 2. 前提条件

- アプリを起動済み（OP0001）。ユーザー `local` が DB にある（OP0004）
- タイトルに「結合テスト」を含む Note が無い

## 3. 手順と期待結果

| No | 操作 | 期待結果 | 確認するルール・API | 結果 |
|---|---|---|---|---|
| 1 | Note 画面で、新規Note名に「結合テスト用Note」と入れて「追加」を押す | MSG0401 が表示され、一覧に追加される | API0403 | 未実施 |
| 2 | 追加した Note を選び、本文に `# 見出し` と「結合テストの本文」を入力する | 「● 未保存」が表示される | FN0401-BR06 | 未実施 |
| 3 | `Ctrl+S` を押す | MSG0403 が表示され、「保存済」になる | API0405、FN0401-BR07 | 未実施 |
| 4 | 「プレビュー」を押す | 見出しが大きな文字で表示される | FN0401-BR09 | 未実施 |
| 5 | ★ を押す | MSG0408 が表示され、★ が塗りつぶされる | API0603 | 未実施 |
| 6 | ホームで「結合テスト」と入力して Enter を押す | 検索結果に「結合テスト用Note」（種類 note）が表示される | API0201、FN0201-BR01 | 未実施 |
| 7 | ホームのお気に入りの「結合テスト用Note」を押す | Note 画面でその Note が開く | API0402 | 未実施 |
| 8 | 🗑 → OK を押す | MSG0405 で確認のあと MSG0406 が表示され、一覧から消える | API0404 | 未実施 |
| 9 | ホームに戻る | お気に入りから「結合テスト用Note」が消えている | FN0401-BR08 | 未実施 |
