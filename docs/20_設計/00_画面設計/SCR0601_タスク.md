# SCR0601 タスク

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | `/task` |
| 目的 | 個人のタスクの追加・ボード・一覧・WBS での管理（FN0602） |
| 表示できる人 | 利用者（本人のタスクだけ。FN0602-BR01） |
| 実装 | `front/src/pages/task/` |

## 2. 画面遷移

| 方向 | 画面 | きっかけ |
|---|---|---|
| 遷移元 | SCR0201 ホーム | 「やること」の行・「すべて見る」（FN0602-BR08） |
| 遷移元 | SCR0001 共通レイアウト | メニューの Task・`Alt+5`・探して開くのタスク（FN0602-BR09） |
| 遷移先 | SCR0301・SCR0401・SCR0501 | 詳細のメモの ari:// のリンク（FN0602-BR12） |

## 3. レイアウト

```text
+------------------------------------------------------------------------------+
| タスク   未着手 3  進行中 1  完了 5  期限切れ 1          [ボード|一覧|WBS]       |
| [タイトル（例: 見積を作る 金曜 !高）。Enter で足す] [優先度 中▾] [期限 なし▾]      |
+------------------------------------------------------------------------------+
| ボード:                                                                        |
| 未着手 (3)              進行中 (1)               完了 (5)  [🗑]                  |
| +--------------------+ +--------------------+ +--------------------+          |
| | ● 見積もりを出す 🔁 | | ● 議事録をまとめる  | | ✓ 週報             |          |
| | 12/5(金) 2 日過ぎ   | | 今日  📄 定例メモ   | |                    |          |
| +--------------------+ +--------------------+ +--------------------+          |
| 一覧: ☐ タイトル  優先度  状態  期限（↑）  追加   [完了を隠す]                  |
| WBS: 番号・タイトル・開始日・期限 と、日ごとのガントチャート（土日・祝日は灰色、今日の線）|
+------------------------------------------------------------------------------+
詳細のダイアログ: タイトル・優先度・状態・期限（今日・明日・1 週間後・なし）・開始日・繰り返し・メモ（リンクの一覧）、[削除] [閉じる]
```

## 4. 表示項目

| 項目 | 表示内容・形式 | 取得元（API ID） | 備考 |
|---|---|---|---|
| 数 | 未着手・進行中・完了の数と期限切れの数 | API0607 | FN0602-BR06 |
| 表示の切り替え | ボード・一覧・WBS（WBS は設定の「WBS を使う」がオンのときだけ）。選んだものはこの PC に覚える | - | FN0602-BR05・BR14 |
| 追加の欄 | タイトルの入力欄・優先度・期限。文の終わりの言葉（「金曜」「!高」など）を読んで、優先度・期限にその場で映す | - | FN0602-BR03・BR11 |
| ボード | 未着手・進行中・完了の 3 列。カードはタイトル・優先度の色・期限（曜日つき。過ぎたものは赤で「N 日過ぎ」、「今日」「明日」）・繰り返しの印・メモのリンクの印と名前 | API0607 | FN0602-BR04・BR06・BR10・BR12 |
| 一覧 | チェック・タイトル・優先度・状態・期限・追加。見出しで並べ替え（もう一度押すと逆順）。完了を隠せる | API0607 | FN0602-BR05 |
| WBS | `1`・`1.1` の番号付きの木と、日ごとのガントチャート（親の棒は子孫の日付の範囲、進みは完了の割合。開始日が無いものは期限にひし形） | API0607 | FN0602-BR14 |
| 詳細のダイアログ | タイトル・優先度・状態・期限・開始日・繰り返し・メモと、メモの中の ari:// のリンクの一覧（名前と場所） | API0607 | FN0602-BR04・BR12 |

## 5. 操作

| 操作 | 条件 | 処理 | 呼ぶ API | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| 追加の欄で Enter | タイトルがある | 未着手の一番上に足す | API0608 | 欄を空にする | サーバーの文言 |
| カードをドラッグ / `Alt+←→`・`Alt+↑↓` | ボード | 列（状態）と列の中の並びを変える。繰り返しのものを完了にしたら次の回を作る | API0609・API0610 | - | サーバーの文言 |
| カード・行を押す / Enter | - | 詳細のダイアログを開く | - | - | - |
| 詳細で変える | - | 変えた項目を保存する | API0609 | - | サーバーの文言 |
| チェック | 一覧・WBS（Space）・ホーム | 完了・未着手を切り替える | API0609 | - | サーバーの文言 |
| 詳細の「削除」 | 確認のあと | 消す（子は繰り上げる） | API0612 | - | サーバーの文言 |
| 完了の列の 🗑（完了したタスクをまとめて削除） | 確認のあと | 完了したものをまとめて消す | API0613 | - | サーバーの文言 |
| WBS で `Tab`・`Shift+Tab`・`Alt+↑↓` | WBS | 段を下げる・上げる・並べ替える | API0611 | - | 「自分の下へは動かせません」など |
| WBS で `Ctrl+Enter` | WBS | 選んだものの子を足す | API0608 | - | 深さの上限の旨 |
| メモのリンクを押す | 詳細 | 保存してからリンク先を開く | API0609 | 開く | - |

## 6. ショートカットキー

| キー | 動作 |
|---|---|
| Ctrl+N | 追加の欄へ |
| Alt+← / Alt+→ | カードを隣の列の一番上へ（ボード） |
| Alt+↑ / Alt+↓ | 列の中・同じ親の中の並びを変える |
| Tab / Shift+Tab | 段を下げる / 上げる（WBS） |
| Ctrl+Enter | 子を足す（WBS） |
| Space | 完了にする（WBS） |
| ← / → | 閉じる / 開く（WBS） |
| Enter | 詳細を開く |
