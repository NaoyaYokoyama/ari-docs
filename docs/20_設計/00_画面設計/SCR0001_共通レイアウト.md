# SCR0001 共通レイアウト（ヘッダー）

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | （全画面の上部） |
| 目的 | 画面の移動・探して開く・配色の切り替え・ショートカット一覧 |
| 表示できる人 | 利用者 |
| 実装 | `front/src/pages/common/Header.tsx, MainLayout.tsx`、`front/src/shortcut/ShortcutHelp.tsx`、`front/src/app/theme.ts`、`front/src/quickOpen/`（探して開く） |

## 2. 画面遷移

| 方向 | 画面 | きっかけ |
|---|---|---|
| 遷移先 | SCR0201〜SCR0801 | ロゴ・メニューのクリック、`Alt+数字`（FN0001-BR03）、探して開くで選んだもの |

## 3. レイアウト

```text
+-------------------------------------------------------------------+
| [ロゴ] ari-docs [● 自分の PC ▾] Home Folder Note Wiki Task Docs Setting [探して開く Ctrl+P] [⧉] [☀] [?] |
+-------------------------------------------------------------------+
| ⬇ 新しい版（0.2.0）があります  今の版: 0.1.0  [更新して再起動] [あとで] |  ← 新しい版があるときだけ（FN0904）
+-------------------------------------------------------------------+
| 各画面                                                            |
+-------------------------------------------------------------------+
```

場所の一覧（場所を押すか `Alt+0`。デスクトップアプリだけ。FN0002-BR20）

```text
+------------------------------------------------+
| 場所を切り替える（データ・ログインは場所ごとに別） |
| ● 💻 自分の PC                         ✓  [1] |
| ● 🖥 開発部                                 [2] |
|        http://ari-server:8080                  |
| ---------------------------------------------- |
|      場所の設定（共有サーバーの追加・名前・…）  |
+------------------------------------------------+
```

探して開く（`Ctrl+P` で開くダイアログ。FN0003）

```text
+---------------------------------------------------+
| (検索) [Note・Wiki・ファイル・画面・操作を名前で探す] |
|---------------------------------------------------|
| 最近開いたもの                                     |
|  (Note) 定例メモ          議事録/2026        Note  |
|  (ファイル) beta.txt      qo-test        ファイル  |
| 画面・操作                                         |
|  (家) Home                                 Alt+1   |
|  …                                                 |
|---------------------------------------------------|
| ↑↓ Ctrl+N/P 選ぶ  Enter 開く  Shift+Enter 場所を表示  Esc 閉じる |
+---------------------------------------------------+
```

## 4. 表示項目

| 項目 | 表示内容・形式 | 取得元（API ID） | 備考 |
|---|---|---|---|
| ロゴ | アイコンと「ari-docs」（`sm` 未満はアイコンだけ）。押すとホーム | - | - |
| 場所 | デスクトップアプリで、共有サーバーを登録したときだけ。今の場所の色の印・名前・▾。マウスを乗せると名前と URL・`Alt+0` | API0001 | FN0002-BR20 |
| 場所の一覧 | 説明・場所（色の印・自分の PC / 共有サーバーのアイコン・名前・URL・今の場所に ✓・番号）・「場所の設定」 | API0001 | FN0002-BR20 |
| メニュー | Home・Folder・Note・Wiki・Task・Docs・Setting（Docs は「Docs を使う」設定のときだけ。FN0902-BR06）。表示中の画面に差し色の下線（FN0001-BR01）。`lg` 未満は文字を隠す（FN0001-BR02）。マウスを乗せるとショートカット（例: `Home（Alt+1）`） | - | - |
| 探して開く | 虫めがねと「探して開く」・`Ctrl+P`（`md` 未満は虫めがねだけ）。押すと探して開くを開く（FN0003） | - | - |
| 探して開くの入力欄・候補 | 打つ前は最近開いたもの（8 件）と画面・操作。打つと点数の高い順に 50 件まで。各行はアイコン・名前・場所（薄く）・種類（Note・Wiki・フォルダ・ファイル・画面・操作・設定）かキー。一致した文字を太字にする（FN0003-BR02〜BR04）。問い合わせ中は入力欄の右に回る印 | API0207 | 合うものが無ければ MSG0010、探せなければ MSG0011 |
| 新しいウィンドウ | ⧉ のアイコン。押すと今の画面を新しいウィンドウで開く（`Ctrl+Shift+N`。FN0301-BR36） | API0015 | - |
| 配色 | 今の配色のアイコン（ライト・ダーク・OS に合わせる）。押すと次の配色に切り替える（FN0001-BR09） | - | - |
| ショートカット一覧 | `?` のアイコン。押すと一覧のダイアログを開く（FN0001-BR08） | - | - |
| 倍率 | デスクトップアプリで 100% 以外のとき、ヘッダーの右に倍率（例: 125%）。押すと 100% に戻す（FN0701-BR17） | - | - |
| 拡大・縮小のお知らせ | デスクトップアプリで Ctrl++・Ctrl+-・Ctrl+0・Ctrl+ホイールで変えたとき、「表示の大きさ: 125%（Ctrl+0 で 100% に戻す）」を短く出す（FN0701-BR17） | - | - |
| ユーザー名・ログアウト | 共有モードのときだけ表示 | API0101 | - |
| 更新のお知らせ | デスクトップアプリで新しい版があるときだけ、ヘッダーの下に出す。版の番号・今の版・「更新して再起動」・「あとで」。取ってきている間は進み具合（MSG0925）。今の場所が共有サーバーなら、ログインした後に 1 回調べる（FN0904-BR03・BR05） | API0009 | 自分の PC のときは自動で調べない（FN0904-BR04） |

## 5. 操作

| 操作 | 条件 | 処理 | 呼ぶ API | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| メニューを押す | 未保存の変更がある | 確認ダイアログ MSG0001 を表示 | - | OK なら移動 | キャンセルなら移動しない |
| 場所を押す / `Alt+0` | デスクトップアプリで、共有サーバーを登録している | 場所の一覧を開く・閉じる | - | - | - |
| 場所の一覧で選ぶ（クリック・Enter・数字） | 今と違う場所 | 未保存の変更・共有サーバーから開いたファイルがあれば確かめ、画面を読み込み直してホームを開く（FN0002-BR20） | - | 選んだ場所のホーム（共有サーバーにつながらなければ SCR0002 の 9 章、未ログインならログイン画面） | キャンセルなら切り替えない |
| 「場所の設定」 | - | 設定画面の「場所」を開く | - | SCR0701 | - |
| メニューを押す | 未保存の変更が無い | その画面へ移動 | - | - | - |
| 配色を押す | - | ライト → ダーク → OS に合わせる の順に切り替え、ブラウザに保存 | - | - | - |
| ショートカット一覧を押す | - | 一覧のダイアログを開く | - | - | - |
| 探して開くで打つ | - | 画面・操作・設定はすぐ、Note・Wiki・ノードは 0.12 秒待ってから探して並べる（FN0003-BR05） | API0207 | 候補を並べ直す | MSG0011 |
| 「更新して再起動」 | 新しい版がある | 保存していない変更があれば MSG0924 で確かめ、取ってきて入れ替え、再起動する（FN0904） | API0010 | アプリが再起動する | MSG0923 |
| 「あとで」 | - | お知らせを閉じる。次に起動するまで出さない（FN0904-BR05） | - | - | - |
| 探して開くで `Enter` | - | 選んだものを開く（FN0003-BR08）。最近開いたものに残す | - | その画面へ移る | ファイル・フォルダが無ければ MSG0009 |

## 6. ショートカットキー

| キー | 動作 |
|---|---|
| Alt+0 | 場所の一覧を開く（デスクトップアプリ。一覧では ↑↓・j・k・Enter・数字・Esc） |
| Alt+1 | ホームへ移動し、検索欄にフォーカス |
| Alt+2 | Folder へ移動 |
| Alt+3 | Note へ移動 |
| Alt+4 | Wiki へ移動 |
| Alt+5 | Task へ移動 |
| Alt+6 | Setting へ移動（Docs を使う設定のときは Docs へ移動） |
| Alt+7 | Docs を使う設定のときだけ、Setting へ移動（FN0001-BR03） |
| Ctrl+Shift+N | 今の画面を新しいウィンドウで開く（FN0301-BR36） |
| Ctrl++ / Ctrl+- / Ctrl+0 / Ctrl+ホイール | 拡大 / 縮小 / 100% に戻す / 拡大・縮小（デスクトップアプリ。FN0701-BR17） |
| ? | ショートカット一覧を開く・閉じる（入力中以外） |
| Ctrl+P | 探して開くを開く（入力欄の中からも。FN0003-BR01）。開いている間は前の候補へ |
| ↑ / ↓、Ctrl+N / Ctrl+P、Ctrl+J / Ctrl+K、Tab | 探して開くで候補を選ぶ（FN0003-BR07） |
| Enter / Shift+Enter / Esc | 探して開くで開く / ファイル・フォルダの場所を表示 / 閉じる |
| Alt+H / J / K / L | 画面内のフォーカスを左・下・上・右へ移す（FN0001-BR04） |
