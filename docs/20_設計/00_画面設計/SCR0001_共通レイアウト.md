# SCR0001 共通レイアウト（ヘッダー）

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | （全画面の上部） |
| 目的 | 画面の移動・探して開く・配色の切り替え・ショートカット一覧 |
| 表示できる人 | 利用者 |
| 実装 | `front/src/pages/common/Header.tsx, MainLayout.tsx`、`front/src/shortcut/ShortcutHelp.tsx`、`front/src/app/theme.ts`、`front/src/quickOpen/`（探して開く） |

## 2. 画面遷移

| 方向 | 画面 | きっかけ |
|---|---|---|
| 遷移先 | SCR0201〜SCR0801 | ロゴ・メニューのクリック、`Alt+数字`（FN0001-BR03）、探して開くで選んだもの |

## 3. レイアウト

```text
+-------------------------------------------------------------------+
| [ロゴ] ari-docs  Home Folder Note Wiki Docs Setting [探して開く Ctrl+P] [☀] [?] |
+-------------------------------------------------------------------+
| 各画面                                                            |
+-------------------------------------------------------------------+
```

探して開く（`Ctrl+P` で開くダイアログ。FN0003）

```text
+---------------------------------------------------+
| (検索) [Note・Wiki・ファイル・画面・操作を名前で探す] |
|---------------------------------------------------|
| 最近開いたもの                                     |
|  (Note) 定例メモ          議事録/2026        Note  |
|  (ファイル) beta.txt      qo-test        ファイル  |
| 画面・操作                                         |
|  (家) Home                                 Alt+1   |
|  …                                                 |
|---------------------------------------------------|
| ↑↓ Ctrl+N/P 選ぶ  Enter 開く  Shift+Enter 場所を表示  Esc 閉じる |
+---------------------------------------------------+
```

## 4. 表示項目

| 項目 | 表示内容・形式 | 取得元（API ID） | 備考 |
|---|---|---|---|
| ロゴ | アイコンと「ari-docs」（`sm` 未満はアイコンだけ）。押すとホーム | - | - |
| メニュー | Home・Folder・Note・Wiki・Docs・Setting（Docs は「Docs を使う」設定のときだけ。FN0902-BR06）。表示中の画面に差し色の下線（FN0001-BR01）。`lg` 未満は文字を隠す（FN0001-BR02）。マウスを乗せるとショートカット（例: `Home（Alt+1）`） | - | - |
| 探して開く | 虫めがねと「探して開く」・`Ctrl+P`（`md` 未満は虫めがねだけ）。押すと探して開くを開く（FN0003） | - | - |
| 探して開くの入力欄・候補 | 打つ前は最近開いたもの（8 件）と画面・操作。打つと点数の高い順に 50 件まで。各行はアイコン・名前・場所（薄く）・種類（Note・Wiki・フォルダ・ファイル・画面・操作・設定）かキー。一致した文字を太字にする（FN0003-BR02〜BR04）。問い合わせ中は入力欄の右に回る印 | API0207 | 合うものが無ければ MSG0010、探せなければ MSG0011 |
| 配色 | 今の配色のアイコン（ライト・ダーク・OS に合わせる）。押すと次の配色に切り替える（FN0001-BR09） | - | - |
| ショートカット一覧 | `?` のアイコン。押すと一覧のダイアログを開く（FN0001-BR08） | - | - |
| ユーザー名・ログアウト | 共有モードのときだけ表示 | API0101 | - |

## 5. 操作

| 操作 | 条件 | 処理 | 呼ぶ API | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| メニューを押す | 未保存の変更がある | 確認ダイアログ MSG0001 を表示 | - | OK なら移動 | キャンセルなら移動しない |
| メニューを押す | 未保存の変更が無い | その画面へ移動 | - | - | - |
| 配色を押す | - | ライト → ダーク → OS に合わせる の順に切り替え、ブラウザに保存 | - | - | - |
| ショートカット一覧を押す | - | 一覧のダイアログを開く | - | - | - |
| 探して開くで打つ | - | 画面・操作・設定はすぐ、Note・Wiki・ノードは 0.12 秒待ってから探して並べる（FN0003-BR05） | API0207 | 候補を並べ直す | MSG0011 |
| 探して開くで `Enter` | - | 選んだものを開く（FN0003-BR08）。最近開いたものに残す | - | その画面へ移る | ファイル・フォルダが無ければ MSG0009 |

## 6. ショートカットキー

| キー | 動作 |
|---|---|
| Alt+1 | ホームへ移動し、検索欄にフォーカス |
| Alt+2 | Folder へ移動 |
| Alt+3 | Note へ移動 |
| Alt+4 | Wiki へ移動 |
| Alt+5 | Setting へ移動（Docs を使う設定のときは Docs へ移動） |
| Alt+6 | Docs を使う設定のときだけ、Setting へ移動（FN0001-BR03） |
| ? | ショートカット一覧を開く・閉じる（入力中以外） |
| Ctrl+P | 探して開くを開く（入力欄の中からも。FN0003-BR01）。開いている間は前の候補へ |
| ↑ / ↓、Ctrl+N / Ctrl+P、Ctrl+J / Ctrl+K、Tab | 探して開くで候補を選ぶ（FN0003-BR07） |
| Enter / Shift+Enter / Esc | 探して開くで開く / ファイル・フォルダの場所を表示 / 閉じる |
| Alt+H / J / K / L | 画面内のフォーカスを左・下・上・右へ移す（FN0001-BR04） |
