# SCR0201 ホーム

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | `/` |
| 目的 | Note・Wiki・ノードの検索と、お気に入り・検索結果からの移動 |
| 表示できる人 | 利用者 |
| 実装 | `front/src/pages/home/` |

## 2. 画面遷移

| 方向 | 画面 | きっかけ |
|---|---|---|
| 遷移先 | SCR0301 フォルダ | ノードのお気に入り・検索結果をクリック |
| 遷移先 | SCR0401 Note | Note のお気に入り・検索結果をクリック |
| 遷移先 | SCR0501 Wiki | Wiki のお気に入り・検索結果をクリック |

## 3. レイアウト

```text
+-----------+------------------------------------+
| ★お気に入り|  [🔍 ファイル、Wiki、Noteを検索 ×][すべて▾]|
| 📁 test21 |   Alt+数字 画面の移動  ? 一覧 …     |
|    test2  |   最近更新されたもの                 |
| 📄 メモ    |   [Wiki …]        [ファイル …]       |
+-----------+------------------------------------+
  検索後:
|           |  [🔍 設計                       ×]  |
|           |  「設計」の検索結果 n 件             |
|           |  Note (2)   [📄 設計メモ        ]   |
|           |  ファイル・フォルダ (1)              |
|           |             [📁 設計 folder/a   ]   |
```

## 4. 表示項目

| 項目 | 表示内容・形式 | 取得元（API ID） | 備考 |
|---|---|---|---|
| お気に入り | アイコン（Wiki: 本、Note: 書類、ノード: 拡張子があれば書類、無ければフォルダ）と名前。ノードはパスの最後の部分と、その下に親フォルダ（FN0601-BR05）。0 件のときは「お気に入りはまだありません」 | API0601 | - |
| ショートカット | 検索前だけ表示。主なショートカット | - | 挨拶（「こんにちは、{表示名}さん」）とロゴは出さない。検索欄は上に置く（ホームにいろいろな情報を並べるため。2026-11-08） |
| 検索欄 | プレースホルダー「ファイル、Wiki、Noteを検索（Enter）」。検索中は読み込み中の印、入力があればクリアボタン | - | 開いたときにフォーカスする |
| 探す種類 | 検索欄の右のボタン。選んだ種類（「すべて」「PDF・Wiki」、3 つ以上は「3 種類」）。すべて以外のときは差し色。押すと「すべて」と各種類（名前と拡張子）のチェックを出す（FN0201-BR09） | - | 外を押す・Esc で閉じる |
| 検索結果 | 件数と、種類（Note・Wiki・ファイル・フォルダ）ごとの一覧。ノードは名前と `folder/{親フォルダ}`。中身で見つかったファイルには「中身に一致」を付ける（FN0202-BR07）。ファイル・フォルダが 2 つ以上の場所にまたがるときは「ファイルの場所」のボタン（すべて・各フォルダ）で絞り込める（FN0201-BR08）。0 件のときは MSG0201 と、探す対象（ファイル・フォルダは名前と中身。中身は数分前までに置いた・更新したファイル）の案内 | API0201 | - |

| 最近更新されたもの | 検索していないとき、Wiki・ファイル・自分の Note の最近更新されたものを種類ごとの枠で（名前・場所や更新した人・「n 分前」）。クリックで各画面で開く（FN0201-BR07）。枠は置き場所の幅に応じて並べる（768px 以上で 3 列、576px 以上で 2 列。ノート PC でも 3 列）。検索欄・検索結果は幅 672px で中央、最近更新されたものは最大 1152px | API0206 | 無ければ出さない |

## 5. 操作

| 操作 | 条件 | 処理 | 呼ぶ API | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| 検索欄で Enter | 空白以外の入力がある | 検索する（FN0201-BR04）。ari-docs のリンク（`ari://…`）なら探さずにそこへ移る（FN0004-BR03） | API0201 | 結果を表示 | MSG0202 |
| 検索欄で Esc・クリアボタン | - | 入力と結果を消す | - | - | - |
| 探す種類のチェックを変える | - | この PC に覚える。結果を出しているときは選んだ種類で探し直す（FN0201-BR09） | API0201 | 結果を表示 | MSG0202 |
| お気に入り・検索結果をクリック | - | 種類に応じて移動（FN0201 の 5.2） | - | 移動先で対象を開く | - |

## 6. ショートカットキー

| キー | 動作 |
|---|---|
| Enter（検索欄） | 検索 |
| Esc（検索欄） | 入力と結果を消す |
