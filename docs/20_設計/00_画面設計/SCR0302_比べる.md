# SCR0302 比べる

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | `/compare?mode=files|folders&left=<パス>&right=<パス>` |
| 目的 | 2 つのファイル・フォルダの違いを見る（FN0304） |
| 実装 | `front/src/pages/compare/`（`ComparePage.tsx`・`TextCompare.tsx`・`SheetCompare.tsx`・`compareBase.ts`） |
| 遷移元 | SCR0301 フォルダの右クリック（「2 つを比べる」「「名前」と比べる」）、この画面のフォルダの結果 |

## 2. レイアウト

```
| 比べる  📄 左のパス と 右のパス              [左右を入れ替える] [戻る] |
| 違うところが 3 か所あります  変わった 2・左だけ 1・右だけ 0            |
|                    [変わった][左だけ][右だけ] □違うところだけ [前][次] |
| 左: a/見積.docx            | 右: b/見積.docx                         |
| 1  見積書                  | 1  見積書                               |
| 2  金額 1,000円（黄）       | 2  金額 1,200円（黄・変わった文字が濃い）|
```

## 3. 表示項目

| 項目 | 内容 | API | 備考 |
|---|---|---|---|
| 見出し | 種類のアイコン・左右のパス・「左右を入れ替える」・「戻る」 | - | - |
| 文字の結果 | 違いの数・凡例・「違うところだけ」・前の違い / 次の違い、左右の行番号と文字（FN0304-BR03） | API0317 | 違いが無ければ「同じです」 |
| Excel の結果 | 違いのあるシートの数、シートのタブ（同じ・違う・左だけ・右だけ）、表（左・右の行番号、列 A〜、変わったセルは黄で左の値を消し線で添える。FN0304-BR02。数式が変わったセルは紫と ƒ の印で、左の数式を消し線で・右の数式を添える。FN0304-BR07）。200 行を超えるシートは「違う行だけ」から始める | API0317 | 3000 行・100 列を超えたらその旨 |
| そのほかの結果 | 中身が同じか・左右の大きさ（FN0304-BR04） | API0317 | - |
| フォルダの結果 | 違いの数、「違うものだけ」、名前・結果・左右の大きさの一覧（FN0304-BR05） | API0318 | 5000 件を超えたらその旨 |

## 4. 操作

| 操作 | 条件 | 処理 | API | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| 「次の違い」「前の違い」・`Alt+↓`・`Alt+↑` | 違いがある | その違いの行へスクロールし、枠で示す | - | - | - |
| 「左右を入れ替える」 | - | 左右を入れ替えて比べ直す | API0317・API0318 | - | - |
| フォルダの結果の違うファイルを押す | 両方にあるファイル | そのファイルどうしを比べる | API0317 | - | - |
| 「戻る」 | - | 前の画面に戻る | - | - | - |
