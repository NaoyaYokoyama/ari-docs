# SCR0301 フォルダ

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | `/folder` |
| 目的 | `folder/` 以下のノードの閲覧と操作 |
| 表示できる人 | 利用者 |
| 実装 | `front/src/pages/node/` |

## 2. 画面遷移

| 方向 | 画面 | きっかけ |
|---|---|---|
| 遷移元 | SCR0201 ホーム | ノードのお気に入り・検索結果（`state.nodePath`） |

## 4. 表示項目

| アップロード | 押すと「ファイルをアップロード」「フォルダをアップロード」を選ぶメニュー。アップロード中はボタンに進み具合（%）を帯と数字で出し、押せない | - | - |

| フォルダをダブルクリック / Enter | - | そのフォルダを開く | API0301 | 一覧を表示 | - |
| ファイルをダブルクリック / Enter | ローカルモード | OS の既定アプリで開く（FN0301-BR05） | API0305 | - | MSG0313 |
| ファイルをダブルクリック / Enter | 共有モード | ダウンロードして一時フォルダから開く（FN0301-BR21） | API0310、API0006 | MSG0315 | MSG0313 |
| ツリー・パンくずをクリック | - | その階層を開く | API0301 | - | - |
| 右クリック / ︙ | - | メニューを開く（FN0301-BR24） | - | - | - |
| ↻（再読み込み） | - | 一覧とツリーを読み込み直す | API0301 | - | - |
| ◫（プレビュー）/ Alt+P | ゴミ箱を開いていない | 右のプレビューを出す・しまう（FN0301-BR31。Folder を開いている間だけ。開いたときは設定に従う） | - | - | - |
| 「新しいフォルダ」「新しいファイル」→「作成」 | 名前が正しい（FN0301-BR12） | 作成する | API0302 | MSG0309、一覧を再読み込みして作ったものを選ぶ | ダイアログに MSG0310 |
| 「アップロード」→ ファイル・フォルダを選ぶ | - | 同じ名前を確かめて（FN0301-BR23）表示中のフォルダへアップロード | API0301、API0304 | MSG0311、再読み込み | MSG0312 |
| OS のファイル・フォルダをドロップ | 空いているところ・フォルダの行・パンくず | 同じ名前を確かめて、表示中のフォルダかドロップしたフォルダへアップロード（FN0301-BR06） | API0301、API0304 | MSG0311（別のフォルダなら「「{名前}」に」を付ける）、再読み込み | MSG0312 |
| 行をフォルダの行・パンくずへドラッグ | 自分自身・自分の中以外 | 移動（Ctrl・Option を押しながらならコピー） | API0308 / API0309 | MSG0318 / MSG0319 | サーバーの文言 |

| 「貼り付け」（Ctrl+V） | 切り取り・コピーしたものがある | 表示中のフォルダ（フォルダの行のメニューならそのフォルダ）へ移動・コピー | API0308 / API0309 | MSG0318 / MSG0319 | サーバーの文言 |
| 「名前の変更」（F2） | 1 件だけ選んでいる | 行の中で名前を変える（FN0301-BR18） | API0307 | MSG0317、変えたものを選ぶ | サーバーの文言 |

## 6. ショートカットキー

| キー | 動作 |
|---|---|
| Alt+↑ / Backspace | 1 つ上の階層へ移動 |
| Ctrl+N | 新規作成（フォルダ） |
| Enter | 選んだものを開く（1 件のとき） |
| ↑ / ↓（Shift） | 選ぶものを動かす（範囲を広げる） |
| Ctrl+A | すべて選択（絞り込み中は表示しているものだけ） |
| Ctrl+C / Ctrl+X / Ctrl+V | コピー / 切り取り / 貼り付け |
| F2 | 名前の変更 |
| Ctrl+Shift+C | リンクをコピー（選んでいなければ表示中のフォルダ。FN0004） |
| Alt+P | 右のプレビューを出す・しまう |
| Delete | ゴミ箱に移動 |
| Ctrl+F | 絞り込みの入力欄へ |
| Esc | 選択を外す（切り取りも取り消す）。メニュー・ダイアログ・名前の変更では閉じる・取り消す |
| Enter（作成ダイアログ・名前の変更） | 決定 |
