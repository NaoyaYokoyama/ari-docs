# SCR0003 初回起動

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | （デスクトップアプリで exe のフォルダに `config.toml` が無いとき、どの URL でも表示） |
| 目的 | 使い方（個人用 / 共有サーバーに接続）を選ばせる（FN0002-BR05） |
| 表示できる人 | 利用者（デスクトップアプリのみ） |
| 実装 | `front/src/pages/setup/FirstRun.tsx`、`front/src/pages/setup/ModeChooser.tsx`、`front/src/app/DesktopGate.tsx` |

## 2. 画面遷移

| 方向 | 画面 | きっかけ |
|---|---|---|
| 遷移元 | （起動） | `config.toml` が無い（API0001 の `mode` が空文字でエラーも無い） |
| 遷移先 | （アプリの再起動） | 「保存して再起動」の成功 |

## 3. レイアウト

```text
+--------------------------------------------------+
| [ロゴ] ari-docs へようこそ                         |
|        使い方を選んでください。あとから設定画面でも… |
| (●) 個人用                                        |
|     この PC だけで使います。ログインは不要です…     |
| ( ) 共有サーバーに接続                             |
|     複数人で使う ari-docs のサーバーに接続します…   |
| サーバーの URL [http://ari-server:8080      ]      |
| (エラー)                                          |
|                                 [保存して再起動]   |
+--------------------------------------------------+
```

## 4. 表示項目

| 項目 | 表示内容・形式 | 取得元（API ID） | 備考 |
|---|---|---|---|
| 使い方 | 「個人用」「共有サーバーに接続」の 2 択と説明。初期値は個人用 | - | - |
| サーバーの URL | 入力欄。初期値は `http://` | - | 「共有サーバーに接続」のときだけ表示 |
| エラー | MSG0005〜MSG0008。赤枠 | API0104、API0004 | 無ければ表示しない |

## 5. 操作

| 操作 | 条件 | 処理 | 呼ぶ API | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| 使い方を選ぶ | - | 選んだ方を強調する | - | - | - |
| 「保存して再起動」 / Enter | 共有サーバーのときは URL を入力済み | 共有サーバーなら接続を確かめてから（FN0002-BR14）、使い方を保存する。処理中は「確認中...」で押せない | API0104、API0004 | アプリが再起動する | エラーを表示 |

## 6. ショートカットキー

| キー | 動作 |
|---|---|
| Enter | 「保存して再起動」（URL の入力欄で） |
