# SCR0501 Wiki

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | `/wiki` |
| 目的 | Wiki の一覧・編集 |
| 表示できる人 | 利用者 |
| 実装 | `front/src/pages/wiki/Wiki.tsx`（画面の本体は Note と共通の `front/src/pages/content/`） |

## 2. 画面遷移

| 方向 | 画面 | きっかけ |
|---|---|---|
| 遷移元 | SCR0201 ホーム | Wiki のお気に入り・検索結果（`state.wikiId`） |

## 3. レイアウト

```text
SCR0401 Note と同じ構成（「Note」を「Wiki」に読み替え）
```

## 4. 表示項目

| 項目 | 表示内容・形式 | 取得元（API ID） | 備考 |
|---|---|---|---|
| Wiki 一覧 | SCR0401 と同じ（フォルダは全員で共有。FN0403）。最大 30 件（FN0501-BR03） | API0501、API0408 | - |
| タイトル | 編集中は 25 文字まで。作成ダイアログは 20 文字まで（FN0501-BR02） | API0502 | - |
| その他 | SCR0401 と同じ（本文の書式のボタン・画像の貼り付け（FN0404）も同じ。Wiki の画像は全員が見られる） | - | - |

| 最後に更新した人 | 「更新: 日時」の横に（表示名）。まだ誰も更新していなければ作成者（FN0501-BR09） | API0502 | - |

## 5. 操作

| 操作 | 条件 | 処理 | 呼ぶ API | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| 作成ダイアログの「作成」 / Enter | タイトルあり | 作成する | API0503 | MSG0501、作った Wiki を開く | ダイアログに MSG0510（文字数違反）または MSG0502 |
| 💾 / Ctrl+S | Wiki を選択中。タイトルが空なら MSG0513 | 保存する。ほかの人が更新していたら MSG0516 で確認し、OK なら上書き（FN0501-BR10） | API0505 | MSG0503。「更新」の横の名前を自分にする | MSG0504・キャンセルなら MSG0416 |
| 🕘（変更履歴） | Wiki を選択中 | SCR0401 と同じ（FN0402） | API0506、API0407 | MSG0415 | - |
| 🗑 / Delete | Wiki を選択中 | 確認 MSG0505 のあと削除 | API0504 | MSG0506 | MSG0507 |
| ★ | 未登録 / 登録済み | お気に入り登録 / 解除 | API0604 / API0605 | MSG0508 / MSG0509 | MSG0511 / MSG0512 |
| その他 | - | SCR0401 と同じ | - | - | - |
