# SCR0701 設定

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | `/setting` |
| 目的 | 表示名・パスワードとログイン中の端末（共有モード）・この PC の表示と操作・ショートカットの一覧・検索の辞書・検索の対象外・対応するファイル・ユーザー管理（共有モードの管理者）・管理者の PC（共有モードの管理者）・サーバーの設定とバックアップ（管理）・場所とこの PC の公開と作業フォルダ（デスクトップアプリのみ）・Docs の初期フォルダ（ローカルモード）・設定の書き出しと初期化・アプリの情報 |
| 表示できる人 | 利用者 |
| 実装 | `front/src/pages/setting/` |

## 2. 画面遷移

| 方向 | 画面 | きっかけ |
|---|---|---|
| 遷移元 | SCR0801 Markdown ビューア | 「初期フォルダを変更」（「Docs の初期フォルダ」を表示する。FN0701-BR05） |
| 遷移先 | SCR0701 設定 | 表示名の変更成功時に再読み込み |
| 遷移先 | （アプリの再起動） | 作業フォルダの「このフォルダで再起動」の成功（FN0002-BR08）、この PC の公開・公開の切り替えの成功（FN0005）。場所の保存では再起動しない（FN0002-BR15） |
