# SCR0701 設定

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | `/setting` |
| 目的 | 表示名・パスワードとログイン中の端末（共有モード）・この PC の表示と操作・ショートカットの一覧・検索の辞書・対応するファイル・ユーザー管理（共有モードの管理者）・サーバーの設定とバックアップ（管理）・使い方と作業フォルダ（デスクトップアプリのみ）・Docs の初期フォルダ（ローカルモード）・設定の書き出しと初期化・アプリの情報 |
| 表示できる人 | 利用者 |
| 実装 | `front/src/pages/setting/` |

## 2. 画面遷移

| 方向 | 画面 | きっかけ |
|---|---|---|
| 遷移元 | SCR0801 Markdown ビューア | 「初期フォルダを変更」（「Docs の初期フォルダ」を表示する。FN0701-BR05） |
| 遷移先 | SCR0701 設定 | 表示名の変更成功時に再読み込み |
| 遷移先 | （アプリの再起動） | 作業フォルダの「このフォルダで再起動」、使い方の「保存して再起動」の成功（FN0002-BR08・BR15） |

## 5. 操作

| 操作 | 条件 | 処理 | 呼ぶ API | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| ユーザー名の「変更」 / Enter | 空白以外の入力があり、今の表示名と違う（FN0701-BR08） | 表示名を変更 | API0701 | 再読み込みして MSG0701 | MSG0706 |
| 表示の配色を選ぶ | - | 配色を切り替え、ブラウザに保存する | - | すぐ切り替わる | - |
| 設定を探す欄に入力 / Enter / Esc | - | 一致するメニューに絞る / 最初に一致したものを開く / 入力を消す | - | - | - |
| メニューを選ぶ | - | その項目を表示し、URL の `?section=` を変える（履歴は増やさない） | - | - | - |
| 表示・操作の項目を変える / 「既定に戻す」 | - | この PC に保存し、すぐ反映する | - | すぐ切り替わる | - |
| 「この端末をログアウトさせる」 | 今の端末でない | その端末のセッションを消す | API0706 | MSG0108、一覧を更新 | サーバーの文言 |
| 「ほかの端末をすべてログアウト」 | ほかの端末がある | MSG0109 で確認してから消す | API0706 | MSG0108、一覧を更新 | サーバーの文言 |
| サーバーの設定の「保存」 | 変更があり、範囲の中 | 設定を保存 | API0909 | MSG0907 | サーバーの文言 |
| サーバーの設定の「初期値に戻す」 | 入力が既定と違う | 入力欄を既定の値にする（保存はしない） | - | - | - |
| 「書き出す」 | - | `ari-docs-settings.json` を保存先を選んで保存 | API0005（デスクトップアプリ） | MSG0707 | - |
| 「読み込む」 | - | ファイルを選び、その設定に置き換える | - | MSG0708 | MSG0709 |
| 「戻す」 | - | MSG0710 で確認してから、この PC の画面の設定を消す | - | MSG0711 | - |
| 「情報をコピー」 | - | 表の内容を文字でクリップボードに写す | - | MSG0910 | MSG0911 |
| Docs の初期フォルダの「保存」 | 入力があり、今の設定と違う（それ以外は押せない） | 初期フォルダを変更 | API0703 | MSG0702、「現在」を更新 | MSG0703 / MSG0705 |
| Docs の初期フォルダの「解除」 | 設定済み（未設定なら押せない） | 初期フォルダを解除 | API0703 | MSG0704、「現在」を未設定に | MSG0705 |
| 作業フォルダの「フォルダを選択」 | - | OS のフォルダ選択ダイアログを開き、選んだフォルダを調べる（FN0002-BR02） | API0002 | 選んだフォルダと作るものを表示 | - |
| 作業フォルダの「このフォルダで再起動」 | フォルダを選択済み（それ以外は押せない） | 作業フォルダを変えて再起動する。処理中は「再起動中...」で押せない | API0003 | アプリが再起動する | MSG0004 を表示 |
| バックアップの「設定を保存」 | - | 設定を保存 | API0902 | MSG0901 | サーバーの文言 |
| 「今すぐバックアップ」 | 実行中でない | バックアップを作る（その間は操作できない） | API0904 | MSG0902、一覧を更新 | サーバーの文言 |
| バックアップの「ダウンロード」 | ファイルがある | 保存先を選んで保存 | API0907、API0005 | ダウンロードした旨 | サーバーの文言 |
| 「この時点に戻す」 | ファイルがあり、実行中でない | MSG0903 で確認してから復元 | API0906 | 画面を読み込み直して MSG0904 | サーバーの文言 |
| バックアップの「削除」 | 実行中でない | MSG0905 で確認してから削除 | API0905 | 一覧を更新 | サーバーの文言 |
| 検索の辞書の「登録」 / Enter | 登録・削除できて、空白以外の入力がある | 単語を登録 | API0203 | MSG0211、一覧と取り込み状況を再読み込み | サーバーの文言 |
| 検索の辞書の「削除」 | 登録・削除できる | MSG0213 で確認してから削除 | API0204 | MSG0212、再読み込み | サーバーの文言 |
| 取り込み状況の「更新」 | - | 辞書と取り込み状況を読み込み直す | API0202、API0205 | 表示を更新 | - |
| パスワードの「変更」 | すべて入力済みで、確認用が一致する | パスワードを変更 | API0704 | 再読み込みしてサーバーの文言を表示 | サーバーの文言（「現在のパスワードが違います」など） |

| 使い方の「保存して再起動」 | 今と違う選択 | SCR0003 と同じ | API0104、API0004 | アプリが再起動する | MSG0005〜MSG0008 |
