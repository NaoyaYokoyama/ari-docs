# SCR0002 起動エラー

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | （デスクトップアプリでバックエンドを起動できなかったとき、どの URL でも表示） |
| 目的 | 起動できなかった原因を伝え、作業フォルダ・使い方を選び直せるようにする |
| 表示できる人 | 利用者（デスクトップアプリのみ） |
| 実装 | `front/src/pages/setup/Setup.tsx`、`front/src/pages/setup/ServerUnreachable.tsx`（9 章）、`front/src/pages/setup/serverCheck.ts`、`front/src/pages/setup/WorkspacePicker.tsx`、`front/src/pages/setup/ModeChooser.tsx`、`front/src/app/DesktopGate.tsx` |

## 2. 画面遷移

| 方向 | 画面 | きっかけ |
|---|---|---|
| 遷移元 | （起動） | 起動に失敗（FN0002-BR01、FN0002-BR06、FN0002-BR07） |
| 遷移先 | （アプリの再起動） | 「このフォルダで再起動」「保存して再起動」の成功（FN0002-BR08・BR15） |

## 3. レイアウト

```text
+--------------------------------------------------+
| ari-docs を起動できませんでした                     |
| (エラー: 作業フォルダで起動できませんでした…)        |
| 作業フォルダ: /mnt/share/ari                       |
| 別のフォルダを作業フォルダにする場合は、…            |
| [ /home/user/ari          ] [フォルダを選択]       |
| このフォルダの中に次のフォルダを作ります。           |
|   ・folder/（ファイルの置き場所）                  |
|   ・.ari-docs/（ari-docs のデータ）                |
|                           [このフォルダで再起動]   |
+--------------------------------------------------+
```

## 4. 表示項目

| 項目 | 表示内容・形式 | 取得元（API ID） | 備考 |
|---|---|---|---|
| エラー | 起動に失敗した原因（MSG0003、MSG0005）。赤枠 | API0001 | - |
| 作業フォルダ | 起動しようとした作業フォルダの絶対パス | API0001 | 分からないとき（MSG0005）は表示しない |
| 選んだフォルダ | 選んだフォルダの絶対パス。未選択なら「未選択」 | - | 作業フォルダを変えられるときだけ表示（FN0002-BR06） |
| 作るもの | `folder/` と `.ari-docs/`。既に `.ari-docs/` があれば MSG0002 | API0002 | フォルダを選んだあとに表示 |
| 変更のエラー | 作業フォルダの変更に失敗した原因（MSG0004）。赤枠 | API0003 | 無ければ表示しない |

## 5. 操作

作業フォルダを変えられないとき（API0001 の `canChangeWorkspace` が `false`）は、操作できるものは無い。

| 操作 | 条件 | 処理 | 呼ぶ API | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| 「フォルダを選択」 | - | OS のフォルダ選択ダイアログを開き、選んだフォルダを調べる | API0002 | 選んだフォルダと作るものを表示 | - |
| 「このフォルダで再起動」 | フォルダを選択済み（それ以外は押せない） | 作業フォルダを変えて再起動する。処理中は「再起動中...」で押せない | API0003 | アプリが再起動する | MSG0004 を表示 |
| 使い方の選択と「保存して再起動」 | 使い方を変えられる（`canChangeMode`）とき。今と同じ選択では押せない | SCR0003 と同じ（FN0002 の 5.3） | API0104、API0004 | アプリが再起動する | MSG0005〜MSG0008 を表示 |

## 9. 共有サーバーに接続できないとき（FN0002-BR19）

共有サーバーに接続する使い方で起動し、サーバーが答えないときに出す。

```text
+--------------------------------------------------+
| ⊘ 共有サーバーに接続できません                     |
| 接続先: http://ari-server:8080                    |
| (サーバーに接続できません。URL と、…)               |
| サーバーが止まっている・…もう一度試してください。    |
| [↻ もう一度試す]                                  |
| ------------------------------------------------ |
| 接続先の URL を直すか、個人用に切り替えられます。    |
| (使い方の選択: SCR0003 と同じ)                     |
+--------------------------------------------------+
```

| 操作 | 条件 | 処理 | 呼ぶ API | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| 「もう一度試す」 | - | もう一度確かめる（5 秒まで）。確認中は押せない | API0104 | ログイン画面などいつもの画面へ | 理由を出し直す |
| 使い方の選択と「保存して再起動」 | 使い方を変えられる（`canChangeMode`） | SCR0003 と同じ | API0104、API0004 | アプリが再起動する | MSG0005〜MSG0008 |
