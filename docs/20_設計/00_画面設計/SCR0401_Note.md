# SCR0401 Note

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | `/note` |
| 目的 | Note の一覧・編集 |
| 表示できる人 | 利用者 |
| 実装 | `front/src/pages/note/Note.tsx`（画面の本体は Wiki と共通の `front/src/pages/content/`） |

## 2. 画面遷移

| 方向 | 画面 | きっかけ |
|---|---|---|
| 遷移元 | SCR0201 ホーム | Note のお気に入り・検索結果（`state.noteId`） |

## 3. レイアウト

```text
+-------------------+------------------------------------------------------+
| Note (3)    📁＋ ＋ | タイトル                  [編集|分割|プレビュー] ★ 💾 🕘 🗑 |
| [🔍絞り込み] [⇅]  | ● 未保存 / ✓ 保存済   更新: 2026/10/15 09:30          |
| ▾ 📂 議事録     2 | +--------------------------------------------------+ |
|   ▸ 📁 2026年  1 | | Markdown エディタ / プレビュー                     | |
|    ▌📄 定例  5分前 | +--------------------------------------------------+ |
|  📄 設計メモ  昨日 |                                                      |
+-------------------+------------------------------------------------------+
未選択のとき: 「Noteを選択してください」と [＋ 新しいNote]
作成ダイアログ: タイトル（n / 25）、[キャンセル] [作成]
```

## 4. 表示項目

| 項目 | 表示内容・形式 | 取得元（API ID） | 備考 |
|---|---|---|---|
| 見出し | 「Note」と件数、「📁＋」（新しいフォルダ）、「＋」（新規作成）。どちらも今の場所に作る（FN0403-BR03） | API0401 | - |
| 絞り込み・並べ替え | タイトルの絞り込み欄と、並び（更新日の新しい順 / 名前順）の切り替え（FN0401-BR11） | - | - |
| Note 一覧 | フォルダの木（FN0403）。フォルダ（開け閉めの印・名前・中の数。今の場所は差し色）を先に、その後に Note（タイトル（空なら「（無題）」）と更新日時の短い表示）。選んだものは強調し、左に差し色の線。Note もフォルダも無ければ「Noteはまだありません」。絞り込み中はフォルダを使わず、一致した Note を場所と並べる（FN0403-BR07）。絞り込みで 0 件なら「該当するNoteはありません」 | API0401、API0408 | 最大 30 件（FN0401-BR01） |
| タイトル | 大きめの文字で、そのまま編集できる。25 文字まで（FN0401-BR03） | API0402 | - |
| 保存状態・更新日時 | 未保存なら「● 未保存」（橙）、保存済みなら「保存済」。端末の時刻での更新日時（FN0401-BR14） | API0402 | - |
| 表示の切り替え | 編集・分割・プレビュー（FN0401-BR09） | - | - |
| ボタンの説明 | 書式のボタン・表示の切り替え・★・💾・🔗・🕘・🗑 にマウスを乗せて少し待つか、キーで選ぶと、下に名前と一言の説明（例: 分割「左で書き、右で仕上がりを見ながら書きます」）。画面の端ではみ出さないよう寄せる。設定でオフにできる（FN0701-BR11） | - | `components/common/Hint.tsx` |
| 本文 | Markdown エディタ。改行はそのまま改行として表示（remark-breaks）。配色は画面に合わせる（FN0001-BR09）。「編集」「分割」では上に書式のボタン（見出し・太字・斜体・取り消し線／リンク・コード・コードブロック・引用・区切り線・画像／箇条書き・番号付き・チェックリスト／表を入れる・表を整える。FN0404-BR01）。字体は等幅（FN0404-BR03）。貼り付けた画像はログインして読み込んで表示する | API0402 | - |
| 作成ダイアログ | タイトルと文字数（n / 25）。エラーはダイアログ内に表示 | - | - |

## 5. 操作

| 操作 | 条件 | 処理 | 呼ぶ API | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| 一覧で選ぶ（クリック / Enter） | 未保存の変更がある | 確認 MSG0001 | API0402 | 選んだ Note を表示 | MSG0414 |
| ＋ / Ctrl+N / 「新しいNote」 | 未保存の変更があれば確認 MSG0001 | 作成ダイアログを開く（FN0401-BR10） | - | - | - |
| 作成ダイアログの「作成」 / Enter | タイトルが空白のみなら押せない（FN0401-BR02） | 作成する | API0403 | MSG0401、作った Note を開く | ダイアログに MSG0402 またはサーバーのメッセージ |
| 💾 / Ctrl+S | Note を選択中。タイトルが空なら MSG0412 | 保存する。ほかの画面（PC）で更新されていたら確認し、OK なら上書き（FN0402-BR05） | API0405 | MSG0403、保存済に戻す | MSG0404・キャンセルなら MSG0416 |
| 🔗（リンクをコピー） | Note を選択中 | `ari://note/{noteId}` をコピーする（FN0004-BR02。Note は本人だけが開ける） | - | MSG0013 | MSG0014 |
| 本文に `ari://…` だけを貼る | 「編集」「分割」 | 名前を付けたリンク `[名前](ari://…)` にして入れる（FN0004-BR05） | API0402・API0502（名前を引く） | - | - |
| 本文の `ari://…` のリンクを押す | - | ari-docs の中でそこへ移る（FN0004-BR03・BR04） | - | - | - |
| 🕘（変更履歴） | Note を選択中 | 変更履歴のダイアログ（版の一覧と中身）を開く。「この版にする」で編集中の内容にする（FN0402-BR03・BR04） | API0406、API0407 | MSG0415 | - |
| 🗑 / Delete | Note を選択中 | 確認 MSG0405 のあと削除 | API0404 | MSG0406、一覧を再読み込み | MSG0407 |
| ★ | 未登録 | お気に入り登録 | API0603 | MSG0408、★を塗る | MSG0410 |
| ★ | 登録済み | お気に入り解除 | API0605 | MSG0409、★を戻す | MSG0411 |
| 書式のボタン / Ctrl+B など | 「編集」「分割」 | 選んでいる文字・行に書式を付ける・外す（FN0404-BR01・BR04）。表を整えるはカーソルのある表（FN0404-BR03） | - | 本文を書き換える | 表の外なら MSG0427 |
| 画像を貼り付け（Ctrl+V）・ドロップ・「画像」のボタン | 「編集」「分割」 | 縮小して保存し、カーソルの所に `![説明](URL)` を入れる（FN0404-BR02） | API0413 | MSG0423 → MSG0424 | MSG0425・MSG0426 |
| 編集 / 分割 / プレビュー | - | 表示を切り替え、ブラウザに保存する | - | - | - |
| 並べ替え | - | 更新日の新しい順 ↔ 名前順。ブラウザに保存する | - | - | - |
| フォルダをクリック / Enter | - | 開け閉めし、今の場所にする（FN0403-BR03・BR04） | - | - | - |
| 📁＋ / 右クリックの「新しいフォルダ」 | - | 名前のダイアログのあと作る | API0409 | MSG0417 | ダイアログに MSG0418 など |
| 右クリックの「名前の変更」（フォルダ） | - | 名前のダイアログのあと変える | API0410 | 一覧を読み直す | ダイアログに MSG0418 など |
| 右クリックの「削除」（フォルダ） | 確認のあと | 中が空なら削除（FN0403-BR05） | API0411 | 一覧を読み直す | MSG0419 |
| 行をフォルダの行・Note の行・空いているところへドラッグ / 右クリックの「移動...」 | フォルダを自分の中へは移せない | 移す（FN0403-BR06） | API0412 | MSG0420 | MSG0421 など |

## 6. ショートカットキー

| キー | 動作 |
|---|---|
| j / ↓（一覧） | 次の行 |
| k / ↑（一覧） | 前の行 |
| Enter（一覧） | Note を開く・フォルダを開け閉め |
| l / →（一覧） | フォルダを開く（開いていれば中へ）（FN0403-BR08） |
| h / ←（一覧） | フォルダを閉じる（閉じていれば入っているフォルダへ） |
| Ctrl+N | 新規作成 |
| Ctrl+S | 保存 |
| Ctrl+B / Ctrl+I / Ctrl+Shift+X / Ctrl+E / Ctrl+K（本文） | 太字 / 斜体 / 取り消し線 / コード / リンク（Vim のエディタは挿入モードのときだけ。FN0404-BR04） |
| Alt+Shift+F（本文） | 表を整える |
| F2 | タイトルを編集（全選択） |
| Delete | 削除（入力中以外） |
| Enter（タイトル） | 本文へ移る |
| Enter（絞り込み欄） | 先頭の Note を開く |
| Esc（絞り込み欄） | 絞り込みを消す |
| Alt+H | 一覧へフォーカス |
| Alt+L / Alt+K | タイトルへフォーカス |
| Alt+J | 本文へフォーカス |
