# SCR0801 Markdown ビューア

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | `/docs?root=<フォルダ>&path=<文書>` |
| 目的 | 指定フォルダの Markdown の閲覧とチェック |
| 表示できる人 | 利用者 |
| 実装 | `front/src/pages/docs/` |

## 2. 画面遷移

| 方向 | 画面 | きっかけ |
|---|---|---|
| 遷移先 | SCR0801（別の文書） | ツリー・ID リンク・関連 ID のクリック |

## 3. レイアウト

```text
+---------------------------------------------------------------+
| 📂 [表示するフォルダのパス                         ] [表示]     |
+-------------+-------------------------------------------------+
| 一覧・チェック | (一覧) ID / 名称 / 種類 / 状態 / 更新日 / 警告     |
| 🔍 [検索    ] |                                                 |
| ▼ フォルダ   |   または                                        |
|   📄 文書 ⚠2 | (文書) front matter のカード / 警告 / 本文         |
+-------------+-------------------------------------------------+
```

## 4. 表示項目

| 項目 | 表示内容・形式 | 取得元（API ID） | 備考 |
|---|---|---|---|
| フォルダ入力 | 表示中のフォルダの絶対パス。右に「初期フォルダを変更」（設定画面を開く） | API0801 | - |
| お知らせ | 設定の初期フォルダが見つからないときに表示（FN0801-BR14） | API0801 | - |
| 検索欄 | プレースホルダー「ファイル名・ID で検索（/）」。検索中は件数または「該当なし」を表示（FN0801-BR11） | - | - |
| フォルダツリー | フォルダは開閉できる。警告のある文書に ⚠ と件数。検索中は該当する文書だけを、フォルダを開いて表示（FN0801-BR12） | API0801 | - |
| 一覧・チェック結果 | 全文書の ID・名称・種類・状態・更新日・警告 | API0801 | - |
| front matter のカード | ID・名称・種類・状態（色分け）・更新日・関連 ID（存在しない ID は赤） | API0801 | - |
| 警告 | FN0801-BR07 の結果 | - | - |
| 本文 | Markdown。ID はリンク（FN0801-BR08）。記入ガイドの表示切り替え（FN0801-BR09）。mermaid は図として描画（FN0801-BR13） | API0802 | - |

## 5. 操作

| 操作 | 条件 | 処理 | 呼ぶ API | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| 「表示」 | 入力が表示中と同じ | 何もしない | - | - | - |
| 「表示」 | 入力あり | そのフォルダに切り替える | API0801 | 一覧を表示 | MSG0801 |
| 「表示」 | 入力が空 | 初期フォルダに戻す（FN0801-BR01） | API0801 | - | - |
| 「初期フォルダを変更」 | - | 設定画面の「Docs の初期フォルダ」を開く | - | - | - |
| ツリー・一覧の文書をクリック | - | 文書を開く | API0802 | 本文を表示 | MSG0802 |
| ID・関連 ID をクリック | - | その ID の文書を開く | API0802 | - | - |
| 検索欄に入力 | - | ツリーを絞り込む（FN0801-BR11） | - | - | - |

## 6. ショートカットキー

| キー | 動作 |
|---|---|
| Alt+5 | この画面へ移動（どの画面からでも。この画面は Docs を使う設定のときだけ使える。FN0001-BR03、FN0902-BR06） |
| / | 検索欄にフォーカス（入力欄の外で押したとき） |
| Enter（検索欄） | 先頭の結果を開く |
| Esc（検索欄） | 検索をやめる |
