# SCR0004 ログイン

## 1. 概要

| 項目 | 値 |
|---|---|
| URL | （共有モードで未ログインのとき、どの URL でも表示） |
| 目的 | ログインする。ユーザーが 1 人もいなければ最初の管理者を登録する。サーバーに接続できなければ原因と、ほかの場所への切り替えを出す |
| 表示できる人 | 未ログインの利用者 |
| 実装 | `front/src/pages/common/Login.tsx` |

## 2. 画面遷移

| 方向 | 画面 | きっかけ |
|---|---|---|
| 遷移元 | （起動） | API0101 が失敗（FN0101-BR04） |
| 遷移元 | 全画面 | 「ログアウト」、API の 401 |
| 遷移先 | SCR0201 ホーム | ログイン・管理者の登録の成功 |
| 遷移先 | ほかの場所のホーム | 接続エラーでほかの場所を押す（FN0002-BR20） |

## 3. レイアウト

開いたときに API0104 を呼び、結果で次の 3 つのどれかを表示する（FN0101-BR11）。

```text
(ログイン)                         (最初の管理者の登録)              (接続エラー)
+---------------------------+     +---------------------------+     +---------------------------+
| [ロゴ] ari-docs            |     | [ロゴ] ari-docs            |     | [ロゴ] ari-docs            |
|   ログインしてください      |     |   最初に管理者を登録…      |     |   サーバーに接続できません  |
| ユーザーID [         ]     |     | (説明)                    |     | (MSG0102)                 |
| パスワード [         ]     |     | 登録用のコード [       ]   |     | [        再接続        ]  |
| (MSG0101)                 |     | ユーザーID [         ]     |     | ほかの場所に切り替える     |
| [      ログイン      ]     |     | 表示名・パスワード・確認用 |     | (SCR0003 と同じ選択)       |
| ユーザーの登録は管理者に…  |     |                           |     +---------------------------+
+---------------------------+     | [管理者を登録してログイン]  |
                                  +---------------------------+
```

## 4. 表示項目

| 項目 | 表示内容・形式 | 取得元（API ID） | 備考 |
|---|---|---|---|
| ログイン | ユーザー ID・パスワードの入力欄、エラー（MSG0101 またはサーバーの文言）、管理者に依頼する旨の案内 | - | API0104 の `needsAdmin` が false のとき |
| 最初の管理者の登録 | 説明（管理者の操作はこの PC からだけできる旨も）、登録用のコード（`setupCodeRequired` のときだけ。サーバーを起動した画面か `setup-code.txt` の `XXXX-XXXX`）・ユーザー ID・表示名・パスワード・確認用の入力欄。確認用が一致しなければその場で知らせる | - | `needsAdmin` が true のとき（FN0102-BR02）。登録すると、この PC を管理者の PC にする（FN0102-BR12） |
| 接続エラー | 接続先の URL を含む MSG0102、「再接続」。デスクトップアプリでは、ほかの場所のボタン（SCR0002 の 9 章と同じ） | API0001 | API0104 が失敗したとき |

## 5. 操作

| 操作 | 条件 | 処理 | 呼ぶ API | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| 「ログイン」 / Enter | ユーザー ID を入力済み | ログインしてトークンを保存する（FN0101-BR08） | API0102 | ホームを表示 | MSG0101 |
| 「管理者を登録してログイン」 / Enter | すべて入力済みで確認用が一致 | 最初の管理者を登録してログインする | API0105 | ホームを表示 | サーバーの文言 |
| 「再接続」 | 接続エラーのとき | もう一度 API0104 を呼ぶ | API0104 | 結果の表示に切り替える | 接続エラーのまま |
| ほかの場所を押す | 接続エラーのとき（デスクトップアプリ） | その場所に切り替える（FN0002-BR20） | - | 画面を読み込み直す | - |
