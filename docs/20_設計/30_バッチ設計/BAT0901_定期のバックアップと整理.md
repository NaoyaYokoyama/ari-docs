# BAT0901 定期のバックアップと整理

## 1. 概要

| 項目 | 値 |
|---|---|
| 目的 | 設定の間隔でバックアップを取り、保存期間を過ぎたバックアップとゴミ箱のもの・使われなくなった Note・Wiki の画像を消す |
| 起動方式 | 自動 |
| 実行タイミング | 毎分 45 秒（cron: `45 */1 * * * *`）。画像の整理（手順 5）だけは毎時 15 分（cron: `0 15 * * * *`。本文をすべて見るので毎分は動かさない）。バックエンドの起動中のみ |
| 実装 | `back/src/service/backup.rs` の `run_scheduled`、画像は `back/src/service/content_image.rs` の `purge_unused`（登録は `back/src/batch/scheduler.rs`） |

## 2. 処理

1. バックアップ・復元の実行中なら何もしない（FN0901-BR07）。
2. 設定（TBL0002）を読む。間隔が「しない」以外で、今の時刻が設定の時刻以降、かつその期間（毎日・毎週・毎月）の定期のバックアップが無ければ、バックアップを作る（FN0901-BR04）。
3. 保存期間を過ぎた定期・復元の前のバックアップを消す（手動のものは消さない）。
4. ゴミ箱の保存期間を過ぎたものを完全に削除する（FN0302-BR05）。期限切れのセッション（FN0101-BR09）を消す。
5. （毎時 15 分）Note・Wiki の本文・変更履歴のどこからも使われていない画像のうち、貼り付けてから 1 日たったものを消す（FN0404-BR05）。バックアップ・復元の実行中は動かさない。

## 3. 入出力

| 種類 | 対象 | 内容 |
|---|---|---|
| 入力 | TBL0002 `system_setting` | 設定 |
| 入力 | DB・`folder/` | バックアップする内容 |
| 入出力 | TBL0901 `backup`・保存先のフォルダ | バックアップ |
| 入出力 | TBL0302 `trash`・`<データのフォルダ>/trash` | ゴミ箱 |
| 入力 | TBL0401 `note`・TBL0501 `wiki`・TBL0402 `content_history` | 画像を使っているか |
| 入出力 | TBL0405 `content_image` | Note・Wiki の画像 |

## 4. エラー時の動き

- バックアップに失敗したら `backup: <原因>` を標準エラーに出す。その期間のバックアップが無いままなので、次の回（1 分後）にもう一度取る。
- 削除に失敗したものは次の回にもう一度消す。
