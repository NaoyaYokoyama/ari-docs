# API0611 タスクのWBSの中での移動

## 1. 概要

WBS の中でタスクを動かす（親を変える・同じ親の中の並びを変える。FN0602-BR14）

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/tasks/move` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者（本人のものだけ） |
| 実装 | `back/src/api/task/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| taskId | body | string | ○ | 動かすタスク |
| parentId | body | string | - | 新しい親（空なら一番上） |
| index | body | number | ○ | 新しい親の子の中の位置（0 から） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 204 | 動かした |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 自分・自分の子孫の下へ動かす、深さの上限を超える |
| 401 | 未ログイン |
| 404 | タスク・親が無い |

## 5. 処理

1. 自分・子孫の下でないこと、動かしたあとの深さを確かめる。
2. 元の親の並びから抜き、新しい親の `index` 番目に入れて `wbs_order` を振り直す。
