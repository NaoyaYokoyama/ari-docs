# API0011 この PC の公開

## 1. 概要

この PC を共有サーバーとして公開する（Tauri コマンド。FN0005）。最初の管理者を登録してユーザー local のデータを移し、`config.toml` に公開の設定を書いてアプリを再起動する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `publish_host` |
| 認証 | -（デスクトップアプリの画面から呼ぶ） |
| 権限 | 共有 PC の利用者（ローカルモード） |
| 実装 | `desktop/src-tauri/src/lib.rs`・`back/src/service/host.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| userId | 引数 | string | ○ | 管理者のユーザー ID（FN0102 と同じ。`local` は使えない） |
| displayName | 引数 | string | ○ | 表示名（前後の空白を除いて 1〜30 文字） |
| password | 引数 | string | ○ | パスワード（8〜128 文字） |
| port | 引数 | number | ○ | 待ち受けるポート（1024〜65535。画面の既定は 8080。FN0005-BR10） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| - | なし（アプリが再起動する） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| エラー（文字列） | 自分の PC のバックエンドが動いていない・設定ファイルに書き込めない、もう共有サーバーとして使っている、入力の誤り、もうユーザーがいる（MSG0017） |

## 5. 処理

1. 自分の PC のバックエンドが動いていて、設定ファイルに書き込めることを確かめる。`shared_host` がもう `true` ならエラー。
2. `config.toml` に `shared_host = true`・`publish = true` を書く。
3. 起動しているバックエンドの DB で、1 つのトランザクションで管理者を登録し、ユーザー local を指す列を管理者に書き換えて、ユーザー local を消す（FN0005-BR03）。失敗したら 2 の設定を元に戻してエラーを返す。
4. アプリを再起動する。再起動したら、バックエンドは共有モードで `0.0.0.0:<port>` に待ち受ける（FN0005-BR04・BR10）。
