# API0901 バックアップの設定取得

## 1. 概要

バックアップの設定を返す（FN0901-BR02）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/backup/settings` |
| 認証 | 要。ローカルモードは利用者、共有モードは管理者だけ |
| 権限 | 管理者（共有モード） |
| 実装 | `back/src/api/backup/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功（無ければ既定値） |

| 名前 | 型 | 説明 |
|---|---|---|
| interval | string | `off` / `daily` / `weekly` / `monthly` |
| hour | number | 時刻（0〜23） |
| retentionDays | number | 定期のバックアップを残す日数 |
| dir | string | 保存先（空なら既定） |
| trashRetentionDays | number | ゴミ箱に残す日数 |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 403 | 共有モードで管理者でない（「バックアップは管理者だけが扱えます」） |

## 5. 処理

1. TBL0002 の `backup_settings` を返す。
