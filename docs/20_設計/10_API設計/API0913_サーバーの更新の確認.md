# API0913 サーバーの更新の確認

## 1. 概要

サーバーの今の版と、GitHub Releases の新しい版（あれば）を返す。設定の「情報」の「サーバーの更新」と、管理者がログインしたときのお知らせ（FN0904-BR15）が呼ぶ。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/server-update` |
| 認証 | 必要 |
| 権限 | 管理者（共有モード・登録した PC。FN0102-BR12） |
| 実装 | `back/src/api/server_update.rs`、`back/src/service/server_update.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| refresh | クエリ | boolean | - | `true` なら GitHub に聞き直す。無ければ 10 分は前の結果を使う |

## 4. レスポンス

### 4.1 成功時

| 名前 | 型 | 説明 |
|---|---|---|
| currentVersion | string | サーバーの今の版 |
| unsupported | string | 画面から更新できないときの理由（FN0904-BR14。できるなら無し） |
| latest | object | GitHub Releases の新しい版（`version`・`notes`。今の版より新しくなければ無し） |
| checkError | string | GitHub に聞けなかったときの理由（インターネットにつながらないなど。無ければ無し） |

例:

```json
{
  "currentVersion": "0.1.0",
  "latest": { "version": "0.2.0", "notes": "## What's Changed\n..." }
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | ログインしていない |
| 403 | ローカルモード・管理者でない（登録していない PC の管理者も） |

## 5. 処理

1. 画面から更新できるかを調べる（FN0904-BR14）。できなければ `unsupported` だけを返す。
2. GitHub Releases の `releases/latest/download/latest.json` を読み、版が今の版より新しく、`platforms` に `server-linux-x86_64` があれば `latest` に入れる。
