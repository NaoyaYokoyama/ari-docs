# API0909 サーバーの設定変更

## 1. 概要

ログインと保存の設定を保存する（FN0902）。次のリクエストから効く。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/system/settings/update` |
| 認証 | 要。ローカルモードは利用者、共有モードは管理者だけ |
| 権限 | 管理者（共有モード） |
| 実装 | `back/src/api/system/handler.rs` |

## 3. リクエスト

| 名前 | 型 | 必須 | 説明 |
|---|---|---|---|
| sessionDays | number | - | セッションの有効期限（最後に使ってからの日数。1〜365、既定 30） |
| maxFailures | number | - | ロックするまでの続けての失敗の回数（3〜20、既定 5） |
| lockMinutes | number | - | ロックする分数（1〜1440、既定 15） |
| historyKeep | number | - | Note・Wiki 1 つに残す版の数（1〜1000、既定 100） |
| docsEnabled | boolean | - | Docs（Markdown ビューア）を使う（既定 false。FN0902-BR06） |

省いた項目は既定値になる。

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 保存成功。`message` は「サーバーの設定を保存しました」、`data` は保存した設定 |

-

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 範囲の外（例:「セッションの有効期限は 1〜365 日で指定してください」） |
| 401 | 未ログイン |
| 403 | 共有モードで管理者でない |

## 5. 処理

1. それぞれの値が範囲の中かを確かめる。
2. TBL0002 の `server_settings` に JSON で保存する。
