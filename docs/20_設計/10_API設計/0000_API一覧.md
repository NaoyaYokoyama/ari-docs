# 0000_API一覧 API一覧

バックエンド（`back/src/router.rs`）の全 API。ベース URL は `http://localhost:8080`。

## 共通仕様

- リクエスト・レスポンスの本文は JSON。項目名は camelCase
- 共有モードのセッションは DB に保存し、最後に使ってから 30 日で切れる（FN0101-BR09）。受け取る大きさの上限は 1 GB（FN0301-BR29）
- ローカルモードはログインが無く、すべての API をユーザー `local` として処理する（FN0101-BR01）。共有モードはログイン（API0102）したユーザーとして処理し、セッションは `Authorization: Bearer <トークン>` か Cookie で送る（FN0101-BR08）
- 「Tauri コマンド」はデスクトップアプリだけで使う、画面から `invoke` で呼ぶ処理（`desktop/src-tauri/src/lib.rs`）。それ以外は HTTP の API
- パスの説明にある `folder/` は、ノードのルート（`config.toml` の `folder_root`。FN0301-BR11）を表す
- CORS は `http://localhost:5173`・`tauri://localhost`・`http://tauri.localhost` からの `GET`・`POST` のみ許可し、`Content-Type`・`Authorization` ヘッダーと Cookie を送れるようにしている
- メッセージを返す API は `{"message": string, "data": T | null}` の形で返す
