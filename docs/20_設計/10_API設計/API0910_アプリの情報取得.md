# API0910 アプリの情報取得

## 1. 概要

バージョン・動作モード・データの量などを返す（FN0903）。置き場所は管理できる人にだけ返す。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/system/info` |
| 認証 | 要 |
| 権限 | 利用者（`paths` はローカルモード、または共有モードの管理者だけ） |
| 実装 | `back/src/api/system/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| version | string | サーバー（`back`）のバージョン |
| mode | string | `local` / `shared` |
| os | string | サーバーの OS（`linux` / `windows` / `macos` など） |
| https | boolean | HTTPS で待ち受けている（FN0101-BR14） |
| startedAt | string | サーバーを起動した日時（ローカル時刻） |
| counts.users / notes / wikis / nodes | number | ユーザー・Note（全員）・Wiki・ノードの行の数 |
| counts.indexedFiles / keywords | number | 中身を取り込んだファイルと単語の数（FN0202） |
| paths | object / null | `folderRoot`・`dataDir`・`databasePath`・`databaseBytes`（DB のファイルの大きさ）。管理できない人には null |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |

## 5. 処理

1. 設定と各テーブルの行数を集めて返す。
