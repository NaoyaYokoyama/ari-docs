# API0915 ファイルからサーバーの更新

## 1. 概要

管理者が上げたサーバー一式（`.tar.gz`）と署名（`.sig`）で入れ替え、サーバーを起動し直す。サーバーがインターネットにつながらないとき用（FN0904-BR17）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/server-update/upload` |
| 認証 | 必要 |
| 権限 | 管理者（共有モード・登録した PC。FN0102-BR12） |
| 実装 | `back/src/api/server_update.rs`、`back/src/service/server_update.rs` |

## 3. リクエスト

`multipart/form-data`。

| 名前 | 型 | 必須 | 説明・制約 |
|---|---|---|---|
| file | ファイル | ○ | GitHub Releases の `ari-docs-server_<版>_linux-x86_64.tar.gz` |
| signature | string | ○ | 同じ名前の `.sig` のファイルの中身 |

## 4. レスポンス

API0914 と同じ。版は展開した `back --version` で決める。

## 5. 処理

1. `<データのフォルダ>/tmp/server-update/` に受け取る（メモリに読まない）。
2. API0914 の 2・3 と同じ。
