# API0608 タスクの作成

## 1. 概要

タスクを作る（FN0602-BR02・BR03）。状態の列の一番上、WBS では同じ親の一番下に入れる

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/tasks/create` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/task/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| title | body | string | ○（作成） | 100 文字まで。前後の空白を除いて空は不可 |
| description | body | string | - | メモ。10000 文字まで |
| priority | body | string | - | `high` / `medium` / `low`（既定 `medium`） |
| dueDate | body | string | - | 期限（YYYY-MM-DD。空は期限なし） |
| status | body | string | - | `todo` / `doing` / `done`（既定 `todo`） |
| repeat | body | string | - | `''`（なし）/ `daily` / `weekdays` / `weekly` / `monthly`（FN0602-BR10） |
| startDate | body | string | - | 開始日（YYYY-MM-DD。WBS。FN0602-BR14） |
| parentId | body | string | - | WBS の親のタスク ID（FN0602-BR14）。親は本人のもので、深さは上限まで |

## 4. レスポンス

### 4.1 成功時

| 名前 | 型 | 説明 |
|---|---|---|
| taskId・title・description・priority・dueDate・status・repeat | string | リクエストと同じ |
| sortOrder | number | 状態の列の中の並び（小さいほど上） |
| parentId | string | WBS の親（空なら一番上） |
| startDate | string | 開始日 |
| wbsOrder | number | 同じ親の中の並び |
| createdAt・updatedAt・completedAt | string | 作った・変えた・完了にした日時（UTC。完了でなければ completedAt は空） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | タイトルが空・長すぎる、値が決まりの外、WBS の深さの上限を超える |
| 401 | 未ログイン |
| 404 | 親のタスクが無い |

## 5. 処理

1. 値を確かめる。
2. `tk_` で始まる ID を作り、状態の列の一番上・同じ親の一番下に入れる。
3. 作ったタスクを返す。
