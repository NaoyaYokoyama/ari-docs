# API0323 ファイルの以前の版の一覧取得

## 1. 概要

ari-docs で上書きする前に残した、ファイルの以前の版の一覧（FN0301-BR39）。新しい順

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/nodes/versions?path={path}` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| path | query | string | ○ | ファイルのパス |

## 4. レスポンス

### 4.1 成功時

| 名前 | 型 | 説明 |
|---|---|---|
| [].versionId | string | 版の ID |
| [].size | number | 大きさ（バイト） |
| [].modifiedAt | string | その版の中身の更新日時（YYYY/MM/DD HH:MM） |
| [].replacedBy | string | 上書きした人の表示名 |
| [].replacedAt | string | 上書きした日時 |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 404 | ファイルが無い |

## 5. 処理

1. ファイルの `node_id` で `node_version` を引き、上書きした日時の新しい順に返す。
