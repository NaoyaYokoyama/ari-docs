# API0319 ノードの説明の変更

## 1. 概要

ファイル・フォルダの説明を書く・消す（FN0301-BR33）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/nodes/description` |
| 認証 | 要（ローカルモードはユーザー `local`。FN0301-BR13） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| path | body | string | ○ | ファイル・フォルダのパス（FN0301-BR01） |
| description | body | string | ○ | 説明。前後の空白を除いて 200 文字まで。空なら説明を消す |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 204 | 保存成功（本文なし） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | パスに `..`・絶対パスを含む（FN0301-BR10）、説明が 200 文字を超える（「説明は 200 文字までにしてください」） |
| 401 | 未ログイン |
| 404 | 対象が無い・ノードのルートそのもの（「ファイル・フォルダが見つかりません」） |
| 500 | DB の失敗 |

## 5. 処理

1. パスを検証し、実体があるかを確かめる。
2. `node` の行が無ければ作り（見張り・同期がまだ登録していないとき）、`description` を書き換える。
