# API0107 ユーザー登録

## 1. 概要

管理者がユーザーを登録する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/users/create` |
| 認証 | 要（共有モードの管理者だけ。FN0102-BR01） |
| 権限 | 管理者 |
| 実装 | `back/src/api/user/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| userId | body | string | ○ | ユーザー ID（FN0102-BR03） |
| displayName | body | string | ○ | 表示名（FN0102-BR04） |
| password | body | string | ○ | 初期パスワード（FN0102-BR05） |
| isAdmin | body | boolean | - | 管理者にするか（既定は false） |

例:

```json
{
  "userId": "taro",
  "displayName": "山田太郎",
  "password": "password1",
  "isAdmin": false
}
```

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 登録成功 |

例:

```json
{
  "message": "ユーザーを登録しました",
  "data": null
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 入力の誤り |
| 401 | 未ログイン |
| 403 | ローカルモード、または管理者でない（「ユーザーの管理は管理者だけができます」） |
| 409 | 同じユーザー ID がある（「ユーザーID「{ID}」は既に使われています」） |

## 5. 処理

1. 管理者かを確かめ、入力を検証する。
2. パスワードを Argon2 でハッシュにして登録する。
