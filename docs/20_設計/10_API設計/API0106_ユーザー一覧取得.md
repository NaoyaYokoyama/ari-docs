# API0106 ユーザー一覧取得

## 1. 概要

共有モードのユーザーの一覧を返す。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/users` |
| 認証 | 要（共有モードの管理者だけ。FN0102-BR01） |
| 権限 | 管理者 |
| 実装 | `back/src/api/user/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功（ユーザー ID の昇順。ユーザー `local` は含めない） |

| 名前 | 型 | 説明 |
|---|---|---|
| [].userId | string | ユーザー ID |
| [].displayName | string | 表示名 |
| [].isAdmin | boolean | 管理者か |
| [].updatedAt | string | 更新日時（UTC） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 403 | ローカルモード、または管理者でない（「ユーザーの管理は管理者だけができます」） |

## 5. 処理

1. 管理者かを確かめ、ユーザーの一覧を返す。
