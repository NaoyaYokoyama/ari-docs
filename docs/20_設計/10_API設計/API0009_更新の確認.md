# API0009 更新の確認

## 1. 概要

デスクトップアプリの新しい版があるかを調べる（Tauri コマンド）。見つけた版はアプリの中に覚えておき、API0010 で入れる。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `check_update` |
| 認証 | -（デスクトップアプリの画面から呼ぶ） |
| 権限 | 利用者 |
| 実装 | `desktop/src-tauri/src/lib.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| serverUrl | 引数 | string | ○ | 今の場所の共有サーバーの URL。自分の PC のときは空文字（FN0904-BR02） |

## 4. レスポンス

### 4.1 成功時

| 名前 | 型 | 説明 |
|---|---|---|
| (全体) | object \| null | 新しい版が無ければ null |
| version | string | 新しい版の番号 |
| currentVersion | string | 今の版の番号 |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| エラー（文字列） | アプリに署名の公開鍵が入っていない、URL の形が正しくない、取り先につながらない・30 秒で応えない、応えの形が正しくない |

## 5. 処理

1. 取り先を決める。`serverUrl` が空なら `https://github.com/NaoyaYokoyama/ari-docs-releases/releases/latest/download/latest.json`、空でなければ `<serverUrl>/api/app-update/{target}/{arch}/{current_version}`（API0911）。
2. Tauri の updater（`tauri-plugin-updater`）で調べる。今の版より新しい版だけを新しい版とする（FN0904-BR08）。
3. 見つけた版を覚えておく（API0010 で使う）。
