# API0103 ログアウト

## 1. 概要

セッションを破棄する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/logout` |
| 認証 | 要（共有モード） |
| 権限 | 利用者 |
| 実装 | `back/src/api/auth.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 204 | 成功（本文なし） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | トークン（Cookie）が無い |

## 5. 処理

1. トークン（無ければ Cookie）のセッションをメモリから消す。
