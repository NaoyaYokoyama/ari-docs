# API0906 バックアップから復元

## 1. 概要

バックアップの時点の状態に戻す（FN0901-BR05・BR06）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/backups/restore` |
| 認証 | 要。ローカルモードは利用者、共有モードは管理者だけ |
| 権限 | 管理者（共有モード） |
| 実装 | `back/src/api/backup/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| backupId | body | string | ○ | ID |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 復元成功（MSG0904） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 実行中・見つからない・ari-docs のバックアップでない・入れ替えに失敗（元に戻した旨） |
| 401 | 未ログイン |
| 403 | 共有モードで管理者でない（「バックアップは管理者だけが扱えます」） |

## 5. 処理

1. 一時フォルダに展開し、DB を確かめる。
2. 今の状態をバックアップする（`before_restore`）。
3. バックアップの記録・設定・ゴミ箱の今の中身を控える。
4. `folder/` の中身を入れ替える（失敗したら元に戻す）。
5. DB を SQLite のバックアップ機能で置き換え、マイグレーションを実行し、控えた表を戻す。中身の検索の取り込みの状態を消す（取り込み直す）。
