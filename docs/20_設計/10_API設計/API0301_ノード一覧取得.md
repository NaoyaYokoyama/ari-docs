# API0301 ノード一覧取得

## 1. 概要

指定フォルダ直下のノードを、お気に入りの状態付きで返す。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/nodes` |
| 認証 | 不要（ユーザー `local` として処理する。FN0101-BR01） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| path | query | string | ○ | フォルダのパス。ルートは空文字または `/` |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| currentPath | string | 表示しているフォルダのパス（先頭の `/` を除いたもの） |
| nodes[] | array | ノード（並び順はファイルシステム依存） |
| nodes[].nodeId | string | 常に空文字 |
| nodes[].path | string | ノードのパス（FN0301-BR01） |
| nodes[].name | string | 名前 |
| nodes[].nodeType | string | `folder` / `file` |
| nodes[].status | string | 常に `working` |
| nodes[].description | string | 常に空文字 |
| nodes[].updatedBy | string | 常に空文字 |
| nodes[].updatedAt | string | ファイルの更新日時（`YYYY/MM/DD HH:MM`、ローカル時刻） |
| nodes[].favoriteId | string | お気に入り ID。未登録なら空文字（FN0301-BR08） |
| nodes[].size | number | ファイルのサイズ（バイト）。フォルダは 0（FN0301-BR07） |

例:

```json
{
  "currentPath": "test2",
  "nodes": [
    {
      "nodeId": "",
      "path": "test2/test21",
      "name": "test21",
      "nodeType": "folder",
      "status": "working",
      "description": "",
      "updatedBy": "",
      "updatedAt": "2026/10/11 09:00",
      "favoriteId": "fv_XXXX"
    }
  ]
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | `path` が無い |
| 401 | ユーザー `local` が DB に無い（FN0101-BR02） |
| 400 | `path` が正しくない（FN0301-BR10） |
| 404 | `path` のフォルダが無い（「フォルダが見つかりません」。FN0301-BR14） |
| 500 | お気に入りの取得に失敗 |

## 5. 処理

1. `path` を検証し（FN0301-BR10）、`folder/<path>` がフォルダでなければ 404 にする。
2. `folder/<path>` 直下を読み、ノードの一覧を作る。
3. 一覧のパスに対応するお気に入りを TBL0301・TBL0601 から取得し、`favoriteId` を付ける。
