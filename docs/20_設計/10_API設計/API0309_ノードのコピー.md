# API0309 ノードのコピー

## 1. 概要

ファイル・フォルダを別のフォルダへ複製する（FN0301-BR20）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/nodes/copy` |
| 認証 | 要（ローカルモードはユーザー `local`。FN0301-BR13） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| paths | body | string[] | ○ | コピーするもののパス |
| destPath | body | string | ○ | コピー先のフォルダのパス |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | コピー成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| names | string[] | できた名前（同じ名前があれば「 - コピー」「 - コピー (2)」…を付けたもの） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | パスに `..`・絶対パス・ドライブ指定を含む（FN0301-BR10） |
| 400 | フォルダを自分の中へコピーする |
| 401 | 未ログイン |
| 404 | コピーするもの・コピー先が無い |

## 5. 処理

1. すべてを先に確かめる。
2. 1 つずつ、同じ名前を避けた名前でコピーする（フォルダは中身ごと）。`node` テーブルへは次のノード同期（BAT0301）で登録される。
