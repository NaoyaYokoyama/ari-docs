# API0317 ファイルを比べる

## 1. 概要

Folder の 2 つのファイルを比べる（FN0304）。Excel などはシートごとに行をそろえたセルの違い、Word・PowerPoint・PDF・テキストは取り出した文字、そのほかは同じかどうかを返す。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/compare/files` |
| 認証 | 必要（未ログインは 401） |
| 権限 | 利用者 |
| 実装 | `back/src/api/compare.rs`・`back/src/service/compare.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| left | body | string | ○ | 左のファイル（`folder/` からの相対パス） |
| right | body | string | ○ | 右のファイル |

## 4. レスポンス

### 4.1 成功時

| 名前 | 型 | 説明 |
|---|---|---|
| kind | string | `sheets`（表計算）/ `text`（文字）/ `binary`（そのほか） |
| sheets | object[] | `sheets` のとき。シートの名前・`status`（same / changed / onlyLeft / onlyRight）・`columns`・`rows`（`kind` が same / changed / removed / added、左右の行番号とセルの値、`changed` は値の違う列、`formulas` は数式の違うセル（`column`・`left`・`right`。先頭に `=`。値が同じでも数式が違えば行は changed。FN0304-BR07））・`truncated` |
| left・right | string | `text` のとき。取り出した文字（文字認識はしない） |
| same・leftSize・rightSize | boolean・number | `binary` のとき |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | パスに `..` などがある、読めない（壊れたファイルなど） |
| 401 | 未ログイン |
| 404 | ファイルが無い |

## 5. 処理

1. 2 つとも表計算（xlsx・xlsm・xlsb・xls・ods）なら、シートを名前で組にし、行（3000 行・100 列まで。セルは 200 文字まで）を違いの少ない並び（Myers の方法）でそろえる。消えた行と足した行が続くところは同じ数だけ組にして「変わった行」にし、値の違う列を返す。
2. 2 つとも文字を取り出せる形式（FN0202 のテキスト・Word・PowerPoint・PDF）なら、文字を返す（行と文字の違いは画面で求める。`front/src/lib/lineDiff.ts`）。
3. それ以外は、大きさと中身が同じかを返す。
