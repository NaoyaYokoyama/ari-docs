# API0102 ログイン

## 1. 概要

共有モードで、ユーザー ID とパスワードでログインし、セッションのトークンを返す。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/login` |
| 認証 | 不要 |
| 権限 | 利用者 |
| 実装 | `back/src/api/auth.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| userId | body | string | ○ | ユーザー ID |
| password | body | string | ○ | パスワード |
| client | body | string | - | 端末の名前（例: `Windows・デスクトップアプリ`）。無ければ User-Agent を残す。200 文字まで（FN0101-BR15） |

例:

```json
{
  "userId": "taro",
  "password": "password1"
}
```

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 成功。`Set-Cookie: session_id=...`（ブラウザ用）も返す |

| 名前 | 型 | 説明 |
|---|---|---|
| userId | string | ユーザー ID |
| displayName | string | 表示名 |
| mode | string | 動作モード（`shared`） |
| isAdmin | boolean | 管理者か（FN0102-BR01） |
| docsEnabled | boolean | Docs を使う設定か（FN0902-BR06） |
| token | string | セッションのトークン。以後 `Authorization: Bearer <token>` で送る（FN0101-BR08） |

例:

```json
{
  "userId": "taro",
  "displayName": "山田太郎",
  "mode": "shared",
  "isAdmin": false,
  "docsEnabled": false,
  "token": "01878f26-b481-4ee0-b8ca-6f135ae16d54"
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | ユーザー ID かパスワードが違う（「ユーザーIDまたはパスワードが違います」）。ユーザー `local` ではログインできない（パスワードを持たないため） |
| 429 | 続けて失敗したためロック中（MSG0107。FN0101-BR12） |

## 5. 処理

1. ロック中なら 429 にする（FN0101-BR12）。
2. ユーザーを取得し、パスワードを Argon2 のハッシュと照合する。違えば失敗を数え（FN0902 の回数に達したら、FN0902 の分数だけロック）、401 にする。合えば失敗の数を消す。
3. セッション ID（UUID v4）を発行し、端末の名前（`client`。無ければ User-Agent）と一緒に TBL0103 に保存する（FN0101-BR09・BR15）。Cookie には FN0902 の有効期限（既定 30 日）の `Max-Age` を付ける。
4. ユーザー情報とトークンを返す。
