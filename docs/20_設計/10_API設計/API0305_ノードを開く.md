# API0305 ノードを開く

## 1. 概要

ファイルを OS の既定アプリで開く（FN0301-BR05）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/nodes/open` |
| 認証 | 要（ローカルモードではユーザー `local` として処理する。FN0101-BR01、FN0301-BR13） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| path | body | string | ○ | ファイルのパス |

例:

```json
{
  "path": "test/test1.md"
}
```

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 開いた |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | パスに `..`・絶対パス・ドライブ指定を含む（「パスが正しくありません」。FN0301-BR10） |
| 400 | 共有モード（「共有サーバーのファイルはアプリから開けません」。FN0301-BR17。画面は API0310 でダウンロードして開く） |
| 401 | 未ログイン |
| 404 | ファイルが無い（「ファイルが見つかりません」） |
| 500 | OS で開けなかった（「ファイルを開けませんでした」） |

## 5. 処理

1. ログインを確認し（FN0301-BR13）、`path` を検証する（FN0301-BR10）。
2. 共有モードなら 400 にする（FN0301-BR17）。
3. `folder/<path>` が無ければ 404 にする。あれば OS の既定アプリで開く。
