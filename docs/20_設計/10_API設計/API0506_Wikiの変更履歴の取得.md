# API0506 Wiki の変更履歴の取得

## 1. 概要

Wiki の版の一覧を返す。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/wiki/{wikiId}/history` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/history.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| wikiId | path | string | ○ | Wiki の ID |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功（新しい版から） |

| 名前 | 型 | 説明 |
|---|---|---|
| [].historyId | number | 版の ID |
| [].title | string | タイトル |
| [].updatedBy | string | 保存した人の表示名 |
| [].savedAt | string | その版の更新日時（UTC） |
| [].length | number | 本文の文字数 |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 404 | Wiki が無い |

## 5. 処理

1. 版を新しい順に返す。
