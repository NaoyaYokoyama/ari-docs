# API0208 対応するファイルの形式

## 1. 概要

中身で検索できるファイルの形式（FN0202-BR02）と、取り込む大きさの上限（FN0202-BR04）を返す。設定画面の「対応するファイル」に表示する（[対応するファイル](../../10_要件定義/0030_対応するファイル.md)）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/search/formats` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/search/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| groups | array | 形式のまとまり（`name` 種類の名前、`extensions` 拡張子の配列。`.` は付けない） |
| maxFileBytes | number | これを超えるファイルは取り込まない（バイト） |
| maxChars | number | 取り出した文字のうち使う文字数 |
| ocr | object | 文字認識を使えるか（モデルがあるか。FN0202-BR15）。`available` 使えるか、`message` 使えるときはモデルの名前・使えないときは理由 |
| ocrImageExtensions | string[] | 文字認識する画像ファイルの拡張子（使えるときだけ中身の検索の対象。FN0202-BR14） |

例:

```json
{
  "groups": [
    { "name": "Excel", "extensions": ["xlsx", "xlsm", "xlsb", "xls"] },
    { "name": "PDF", "extensions": ["pdf"] }
  ],
  "maxFileBytes": 104857600,
  "maxChars": 5000000,
  "ocr": { "available": true, "message": "PaddleOCR PP-OCRv6 small" },
  "ocrImageExtensions": ["png", "jpg", "jpeg", "bmp", "gif", "tif", "tiff", "webp"]
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |

## 5. 処理

1. `back/src/search/extract.rs` の `FORMAT_GROUPS`（取り込むかどうかの判定にも使う定義）をそのまま返す。
2. 起動時に調べた文字認識の状態（`back/src/search/ocr.rs`）を返す。
