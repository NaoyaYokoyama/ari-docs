# API0008 場所の保存

## 1. 概要

場所（自分の PC の名前・色、共有サーバー、起動したときの場所。FN0002-BR20）を `config.toml` に保存する（Tauri コマンド）。再起動はしない。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `save_places` |
| 認証 | -（デスクトップアプリの画面から呼ぶ） |
| 権限 | 利用者 |
| 実装 | `desktop/src-tauri/src/lib.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| places.localName | 引数 | string | ○ | 自分の PC の名前。20 文字まで。空なら「自分の PC」と表示する |
| places.localColor | 引数 | string | ○ | 色。空・`gray`・`blue`・`green`・`amber`・`red`・`violet` |
| places.startPlace | 引数 | string | ○ | 起動したときの場所。`last`（前回の場所）・`local`（自分の PC）・登録する共有サーバーの URL |
| places.servers | 引数 | array | ○ | 共有サーバー（5 つまで。並びのとおりに表示する）。それぞれ `name`（1〜20 文字）・`url`（FN0002-BR13）・`color` |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| - | 保存したあとの起動の状態（API0001 と同じ形） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| エラー（文字列） | 共有サーバーが 6 つ以上・同じ URL が 2 つ・URL の形が正しくない・名前が空か 20 文字超え・知らない色・登録していない起動したときの場所、設定ファイルに書き込めない（MSG0005） |

## 5. 処理

1. 値を確かめて整える（前後の空白、URL の末尾の `/`）。共有サーバーに接続できるかは、画面が追加・URL の変更のときに API0104 で確かめる（つながらなくても、利用者が確認すれば保存できる）。
2. `config.toml` の `workspace` を残したまま、場所を書き換えて保存する。古い書き方（`mode`・`server_url`）は消す（FN0002-BR21）。デバッグビルドは `back/data/desktop.toml` に保存する（FN0002-BR17）。
