# API0113 管理者のPCを登録するコードの発行

## 1. 概要

ほかの PC を管理者の PC にするためのコードを発行する（共有モード。FN0102-BR12）。登録する PC で API0114 に入れる。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/admin-devices/pairing` |
| 認証 | 要（共有モード） |
| 権限 | 管理者（登録した PC から） |
| 実装 | `back/src/api/admin_device.rs` の `create_pairing`・`back/src/service/admin_device.rs` の `issue_pairing` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| userId | body | string | ○ | PC を登録する管理者（自分か、ほかの管理者） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | `{"code": "XXXX-XXXX"}`。0・O・1・I を除いた英大文字と数字 8 文字 |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 相手が管理者でない |
| 401 | 未ログイン |
| 403 | ローカルモード、管理者でない、登録していない PC から使っている |
| 404 | ユーザーが無い |

## 5. 処理

1. 管理者（登録した PC から）であることを確かめる。
2. 相手が管理者であることを確かめ、コードを作ってサーバーのメモリに覚える（その人あて・10 分・1 回だけ。サーバーを止めると消える）。
