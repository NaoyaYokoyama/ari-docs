# API0912 アプリの更新ファイルの取得

## 1. 概要

共有サーバーに置いた更新ファイル（インストーラー・AppImage）を返す。デスクトップアプリの更新の部品が API0911 の `url` から取ってくる。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/app-update/files/{file_name}` |
| 認証 | 不要（API0911 と同じ理由） |
| 権限 | 利用者 |
| 実装 | `back/src/api/app_update/handler.rs`、`back/src/service/app_update.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| file_name | パス | string | ○ | 更新ファイルの名前（API0911 の 5 章の形） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | ファイルの中身（`application/octet-stream`、`Content-Length` 付き） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 404 | 名前が更新ファイルの形でない（`..`・`/` を含むものも）、`<データのフォルダ>/app-update/` に無い |

## 5. 処理

1. 名前が更新ファイルの形のときだけ、`<データのフォルダ>/app-update/` のそのファイルを返す（ほかのファイルを読ませないため）。
