# API0603 お気に入り登録（Note）

## 1. 概要

Note をお気に入り登録する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/favorite/note/create` |
| 認証 | 不要（ユーザー `local` として処理する。FN0101-BR01） |
| 権限 | 利用者 |
| 実装 | `back/src/api/favorite/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| id | body | string | ○ | Note の ID |

例:

```json
{
  "id": "nt_XXXX"
}
```

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 登録成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| message | string | `お気に入りに登録しました。` |
| data.favoriteId | string | 登録したお気に入り ID |

例:

```json
{
  "message": "お気に入りに登録しました。",
  "data": {
    "favoriteId": "fv_XXXX"
  }
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | ユーザー `local` が DB に無い（FN0101-BR02） |
| 500 | DB・ファイル操作の失敗 |

## 5. 処理

1. 同じユーザー・同じ対象のお気に入りが既にあれば、新しく作らずにその ID を返す（FN0601-BR07）。それ以外はお気に入りを登録して ID を返す。
