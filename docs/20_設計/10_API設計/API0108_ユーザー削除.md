# API0108 ユーザー削除

## 1. 概要

管理者がユーザーを削除する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/users/delete` |
| 認証 | 要（共有モードの管理者だけ。FN0102-BR01） |
| 権限 | 管理者 |
| 実装 | `back/src/api/user/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| userId | body | string | ○ | 削除するユーザー ID |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 削除成功（「ユーザーを削除しました」） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 自分を削除しようとした（「自分は削除できません」。FN0102-BR07） |
| 401 | 未ログイン |
| 403 | ローカルモード、または管理者でない（「ユーザーの管理は管理者だけができます」） |
| 404 | ユーザーが無い（`local` も 404） |

## 5. 処理

1. 管理者かを確かめる。
2. 1 つのトランザクションで、そのユーザーのお気に入り・その Note を指すお気に入り・Note・ユーザー設定・ユーザーを削除する。Wiki は残す（FN0102-BR06）。
3. そのユーザーのセッションを消す。
