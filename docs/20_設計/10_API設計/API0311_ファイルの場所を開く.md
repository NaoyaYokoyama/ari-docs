# API0311 ファイルの場所を開く

## 1. 概要

エクスプローラーなどでファイル・フォルダの場所を開く（FN0301-BR22。ローカルモードだけ）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/nodes/reveal` |
| 認証 | 要（ローカルモードはユーザー `local`。FN0301-BR13） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| path | body | string | ○ | ファイル・フォルダのパス |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 204 | 成功（本文なし） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | パスに `..`・絶対パス・ドライブ指定を含む（FN0301-BR10） |
| 400 | 共有モード（「共有サーバーのファイルの場所は開けません」） |
| 401 | 未ログイン |
| 404 | 対象が無い |
| 500 | 開けなかった（「場所を開けませんでした」） |

## 5. 処理

1. Windows は `explorer /select,<パス>`、macOS は `open -R <パス>`、それ以外は入っているフォルダを OS の既定のアプリで開く。
