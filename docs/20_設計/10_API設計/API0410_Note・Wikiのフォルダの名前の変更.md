# API0410 Note・Wiki のフォルダの名前の変更

## 1. 概要

フォルダの名前を変える（FN0403-BR01）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/content-folders/rename` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者（Note のフォルダは本人のものだけ） |
| 実装 | `back/src/api/content_folder/handler.rs` の `rename_folder` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| kind | body | string | ○ | `note` / `wiki`。ほかは 400 |
| folderId | body | string | ○ | フォルダの ID |
| name | body | string | ○ | 前後の空白を除いて 1〜25 文字 |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| message | string | 結果の文言 |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 400 | kind が正しくない・名前が空・25 文字超 |
| 404 | フォルダが無い・本人の Note のフォルダでない（MSG0422） |
| 409 | 同じ場所に同じ名前がある（MSG0418） |

## 5. 処理

1. フォルダがあるか、同じ場所にほかの同じ名前が無いかを確かめて変える。
