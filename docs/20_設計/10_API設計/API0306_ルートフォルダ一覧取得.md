# API0306 ルートフォルダ一覧取得

## 1. 概要

`folder/` 直下のノードの名前と種類を返す。現行の画面からは使っていない。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/folders` |
| 認証 | 要（ローカルモードではユーザー `local` として処理する。FN0101-BR01、FN0301-BR16） |
| 権限 | 利用者 |
| 実装 | `back/src/api/folder.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| [] | array | ノード |
| [].type | string | `folder` / `file` |
| [].name | string | 名前 |

例:

```json
[
  {
    "type": "folder",
    "name": "test"
  }
]
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| - | `folder/` が読めないとパニックし、応答が返らない |

## 5. 処理

1. ログインを確認する（FN0301-BR16）。
2. `folder/` 直下を読み、種類と名前を返す。
