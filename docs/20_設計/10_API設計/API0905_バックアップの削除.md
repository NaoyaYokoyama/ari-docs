# API0905 バックアップの削除

## 1. 概要

バックアップを削除する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/backups/delete` |
| 認証 | 要。ローカルモードは利用者、共有モードは管理者だけ |
| 権限 | 管理者（共有モード） |
| 実装 | `back/src/api/backup/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| backupId | body | string | ○ | ID |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 削除成功 |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 実行中・見つからない・消せない |
| 401 | 未ログイン |
| 403 | 共有モードで管理者でない（「バックアップは管理者だけが扱えます」） |

## 5. 処理

1. 実体（あれば）と記録を消す。
