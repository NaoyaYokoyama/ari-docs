# API0307 ノードの名前の変更

## 1. 概要

ファイル・フォルダの名前を変える（FN0301-BR18）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/nodes/rename` |
| 認証 | 要（ローカルモードはユーザー `local`。FN0301-BR13） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| parentPath | body | string | ○ | 親フォルダのパス |
| name | body | string | ○ | 今の名前 |
| newName | body | string | ○ | 新しい名前（前後の空白は除く。FN0301-BR12 と同じ制約） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 204 | 変更成功（本文なし） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | パスに `..`・絶対パス・ドライブ指定を含む（FN0301-BR10） |
| 400 | 名前が正しくない（FN0301-BR12） |
| 401 | 未ログイン |
| 404 | 対象が無い |
| 409 | 新しい名前が既にある（「「{名前}」は既にあります」。大文字・小文字だけの違いは除く） |

## 5. 処理

1. 名前とパスを検証する。
2. 名前を変える。
3. `node` テーブルのパス（フォルダなら中のものも）を新しいパスに変える。新しいパスに実体の無い古い行があれば先に消す。失敗してもログに出すだけにする。
