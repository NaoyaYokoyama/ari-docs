# API0004 使い方の変更

## 1. 概要

デスクトップアプリの使い方（個人用 / 共有サーバーに接続）を `config.toml` に保存し、アプリを再起動する（Tauri コマンド）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `change_mode` |
| 認証 | -（デスクトップアプリの画面から呼ぶ） |
| 権限 | 利用者 |
| 実装 | `desktop/src-tauri/src/lib.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| mode | 引数 | string | ○ | `local`（個人用）/ `server`（共有サーバーに接続） |
| serverUrl | 引数 | string | ○ | 共有サーバーの URL。`local` のときは空文字 |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| - | 成功するとアプリが再起動する（応答は返らない） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| エラー（文字列） | デバッグビルド（「使い方を変えられません」）、URL が `http://` / `https://` で始まらない・パスを含む、exe のフォルダに書き込めない |

## 5. 処理

1. URL の前後の空白と末尾の `/` を取り除き、形を確かめる（FN0002-BR13）。接続できるかは画面が API0104 で先に確かめる（FN0002-BR14）。
2. 今の `config.toml` の `workspace` を残したまま `mode`（と `server_url`）を書き換えて保存する。
3. アプリを再起動する。
