# API0324 ファイルの以前の版のダウンロード

## 1. 概要

以前の版の中身をダウンロードする（FN0301-BR39）。名前にその版の更新日時を付ける（今のファイルと見分けるため）

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/nodes/versions/download?path={path}&versionId={versionId}` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| path | query | string | ○ | ファイルのパス |
| versionId | query | string | ○ | 版の ID |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 中身（`Content-Disposition` に「名前_YYYYMMDD-HHMM.拡張子」（その版の中身の更新日時。PC の時刻）） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 404 | ファイル・版が無い（ほかのファイルの版を指定したときも） |

## 5. 処理

1. 版がそのファイルのものかを確かめ、`<データのフォルダ>/versions/<versionId>` を返す。
