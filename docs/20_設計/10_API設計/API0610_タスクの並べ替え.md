# API0610 タスクの並べ替え

## 1. 概要

ボードの列（状態）の中の並びを変える（カードのドラッグ・Alt+↑↓。FN0602-BR04）

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/tasks/order` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者（本人のものだけ） |
| 実装 | `back/src/api/task/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| status | body | string | ○ | 列（`todo` / `doing` / `done`） |
| taskIds | body | string[] | ○ | その列のタスク ID を上から順に |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 204 | 並べ替えた |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 状態が正しくない |
| 401 | 未ログイン |

## 5. 処理

1. 送られた順に `sort_order` を振る（本人のタスクだけ）。
