# API0109 パスワード再設定

## 1. 概要

管理者がユーザーのパスワードを再設定する（パスワードを忘れたとき）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/users/reset-password` |
| 認証 | 要（共有モードの管理者だけ。FN0102-BR01） |
| 権限 | 管理者 |
| 実装 | `back/src/api/user/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| userId | body | string | ○ | ユーザー ID |
| password | body | string | ○ | 新しいパスワード（FN0102-BR05） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 成功（「パスワードを再設定しました」） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | パスワードの誤り |
| 401 | 未ログイン |
| 403 | ローカルモード、または管理者でない（「ユーザーの管理は管理者だけができます」） |
| 404 | ユーザーが無い |

## 5. 処理

1. 管理者かを確かめ、入力を検証する。
2. パスワードを更新し、そのユーザーのセッションを消す（FN0102-BR08）。
