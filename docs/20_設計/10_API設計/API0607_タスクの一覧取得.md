# API0607 タスクの一覧取得

## 1. 概要

ログインした本人のタスクをすべて返す（FN0602-BR01）。並べ替え・絞り込みは画面で行う

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/tasks` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者（本人のものだけ） |
| 実装 | `back/src/api/task/handler.rs` |
