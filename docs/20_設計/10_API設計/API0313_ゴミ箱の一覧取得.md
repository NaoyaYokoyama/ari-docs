# API0313 ゴミ箱の一覧取得

## 1. 概要

ゴミ箱の中身を返す。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/trash` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/trash/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| items | array | 新しく削除したものから |
| items[].trashId | string | ゴミ箱の ID（`tr_` で始まる） |
| items[].originalPath | string | 元の場所（`folder/` からの相対パス） |
| items[].name | string | 名前 |
| items[].nodeType | string | `folder` / `file` |
| items[].size | number | サイズ（フォルダは中身の合計） |
| items[].deletedBy | string | 削除した人の表示名 |
| items[].deletedAt | string | 削除した日時（UTC） |
| canDelete | boolean | 完全に削除・空にできる（FN0302-BR04） |
| retentionDays | number | 自動で消すまでの日数（FN0302-BR05） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |

## 5. 処理

1. 一覧と、完全に削除できるか・保存期間を返す。
