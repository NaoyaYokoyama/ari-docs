# API0002 作業フォルダの確認

## 1. 概要

選んだフォルダに、既に ari-docs のデータ（`.ari-docs/`）があるかを返す。Tauri のコマンド。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `inspect_workspace` |
| 認証 | 不要 |
| 権限 | 利用者（デスクトップアプリのみ） |
| 実装 | `desktop/src-tauri/src/lib.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| path | 引数 | string | ○ | 調べるフォルダの絶対パス |

例:

```json
{
  "path": "/home/user/ari"
}
```

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| - | 常に返す |

| 名前 | 型 | 説明 |
|---|---|---|
| hasAriDocs | boolean | `<path>/.ari-docs/` がある（FN0002-BR04） |

例:

```json
{
  "hasAriDocs": false
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| - | - |

## 5. 処理

1. `<path>/.ari-docs/` がフォルダとしてあるかを返す。
