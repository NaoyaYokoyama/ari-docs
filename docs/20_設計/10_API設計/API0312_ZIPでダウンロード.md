# API0312 ZIP でダウンロード

## 1. 概要

選んだファイル・フォルダを 1 つの ZIP にして返す（FN0301-BR27）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/nodes/download-zip` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| paths | body | string[] | ○ | 対象のパス（1 件以上） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 成功。本文は ZIP（`Content-Type: application/zip`、`Content-Disposition` はファイル名。1 件はその名前、2 件以上は入っているフォルダの名前） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | パスが正しくない（FN0301-BR10）・対象が空・合計が 2 GB を超える |
| 401 | 未ログイン |
| 404 | 対象が無い |

## 5. 処理

1. パスを検証し、合計の大きさを確かめる。
2. フォルダは中身ごと、構成を保って ZIP にする（名前は UTF-8）。メモリの上で作って返す。
