# API0916 利用規約と同梱のライセンスの取得

## 1. 概要

設定の「情報」で見せる利用規約（`LICENSE`）と、同梱の部品のライセンス（`back/licenses/THIRD_PARTY_NOTICES.txt`）を返す（FN0903）

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/system/licenses` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/system/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| 名前 | 型 | 説明 |
|---|---|---|
| terms | string | 利用規約の全文 |
| notices | string | 同梱の部品のライセンスの全文 |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |

## 5. 処理

1. 実行ファイルに埋め込んだ文を返す。
