# API0907 バックアップのダウンロード

## 1. 概要

バックアップの ZIP を返す（FN0901-BR09）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/backups/download` |
| 認証 | 要。ローカルモードは利用者、共有モードは管理者だけ |
| 権限 | 管理者（共有モード） |
| 実装 | `back/src/api/backup/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| backupId | query | string | ○ | ID |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 成功。本文は ZIP（少しずつ送る） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 404 | 見つからない・ファイルが無い |
| 401 | 未ログイン |
| 403 | 共有モードで管理者でない（「バックアップは管理者だけが扱えます」） |

## 5. 処理

1. ファイルを少しずつ読んで返す。
