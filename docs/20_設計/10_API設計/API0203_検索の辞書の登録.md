# API0203 検索の辞書の登録

## 1. 概要

検索の辞書に単語を登録する。次の取り込み（BAT0302）から、すべてのファイルを順に取り込み直す（FN0202-BR11）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/search/dictionary/create` |
| 認証 | 要。ローカルモードは利用者、共有モードは管理者だけ（FN0202-BR10） |
| 権限 | 管理者（共有モード） |
| 実装 | `back/src/api/search/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| word | body | string | ○ | 単語（FN0202-BR09） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 登録成功（MSG0211。正規化した表記を含む） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 単語の誤り（「単語は1文字以上50文字以内で入力してください」「単語に空白・カンマ（,）・ダブルクォート（"）は使えません」「記号だけの単語は登録できません」） |
| 401 | 未ログイン |
| 403 | 共有モードで管理者でない（「検索の辞書は管理者だけが変更できます」） |
| 409 | 登録済み（「「{単語}」は登録済みです」） |

## 5. 処理

1. 単語を正規化して検証する（FN0202-BR09）。
2. 登録する。単語の区切りは、次に使うときに新しい辞書で作り直す。
