# API0004 初回起動の使い方の保存

## 1. 概要

初回起動の画面（SCR0003）で選んだ使い方（自分の PC だけ / 共有サーバーにも接続）を `config.toml` に保存し、アプリを再起動する（Tauri コマンド）。再起動すると自分の PC のバックエンドを起動する（FN0002-BR20）。起動したあとの場所の変更は API0008。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `complete_first_run` |
| 認証 | -（デスクトップアプリの画面から呼ぶ） |
| 権限 | 利用者 |
| 実装 | `desktop/src-tauri/src/lib.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| serverUrl | 引数 | string | ○ | 共有サーバーの URL。自分の PC だけなら空文字 |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| - | 成功するとアプリが再起動する（応答は返らない） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| エラー（文字列） | exe のフォルダを取れない（「設定を保存できません」）、URL が `http://` / `https://` で始まらない・パスを含む、exe のフォルダに書き込めない（MSG0005） |

## 5. 処理

1. URL があれば整えて確かめ（FN0002-BR13）、共有サーバー「共有サーバー」として登録し、起動したときの場所にする。接続できるかは画面が API0104 で先に確かめる（FN0002-BR14）。
2. 今の `config.toml` の `workspace` を残したまま保存する。
3. アプリを再起動する。
