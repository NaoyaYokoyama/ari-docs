# API0302 ノード作成

## 1. 概要

フォルダまたは空のファイルを作成する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/nodes/create` |
| 認証 | 要（ローカルモードではユーザー `local` として処理する。FN0101-BR01、FN0301-BR13） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| parentPath | body | string | ○ | 作成先フォルダのパス |
| nodeType | body | string | ○ | `folder` / `file` |
| name | body | string | ○ | 名前 |

例:

```json
{
  "parentPath": "test2",
  "nodeType": "folder",
  "name": "新しいフォルダ"
}
```

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 201 | 作成成功（本文なし） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | パスに `..`・絶対パス・ドライブ指定を含む（「パスが正しくありません」。FN0301-BR10） |
| 400 | `name` が使えない名前（FN0301-BR12。例: 「名前に / \ : * ? " < > | は使えません」） |
| 401 | 未ログイン |
| 404 | `parentPath` のフォルダが無い（「作成先のフォルダが見つかりません」） |
| 409 | 同じ名前のファイル・フォルダが既にある（「「{name}」は既にあります」。FN0301-BR12） |
| 500 | 作成に失敗 |

エラーの本文は `{ "message": "…", "data": null }`。

## 5. 処理

1. ログインを確認する（FN0301-BR13）。
2. `name`（FN0301-BR12）と `parentPath`（FN0301-BR10）を検証する。
3. 同じ名前が既にあれば 409 にする（上書きしない。FN0301-BR12）。
4. `folder/<parentPath>/<name>` に、`nodeType` に応じてフォルダまたは空ファイルを作る。
