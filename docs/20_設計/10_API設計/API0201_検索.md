# API0201 検索

## 1. 概要

Note と Wiki をキーワードで部分一致検索する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/home/search` |
| 認証 | 不要（ユーザー `local` として処理する。FN0101-BR01） |
| 権限 | 利用者 |
| 実装 | `back/src/api/home/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| keyword | body | string | ○ | 検索キーワード。空文字なら全件（画面は空では呼ばない。FN0201-BR04） |
| types | body | string[] | - | 探す種類（`excel` `word` `powerpoint` `pdf` `text` `image` `other` `folder` `note` `wiki`。`back/src/search/kind.rs`）。省略・空ならすべて（FN0201-BR09）。種類で絞るときも、中身で見つかったファイルは最大 200 件 |

例:

```json
{
  "keyword": "設計",
  "types": ["excel", "pdf"]
}
```

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 検索成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| searchItems[] | array | 検索結果 |
| searchItems[].viewType | string | `note` / `wiki` / `node` |
| searchItems[].name | string | Note・Wiki はタイトル、ノードは `folder/` からの相対パス |
| searchItems[].nodeId | string | ノードの ID（Note・Wiki のときは空文字） |
| searchItems[].noteId | string | Note の ID（それ以外は空文字） |
| searchItems[].wikiId | string | Wiki の ID（それ以外は空文字） |
| searchItems[].nodeType | string | ノードの種類 `folder` / `file`（Note・Wiki のときは空文字） |
| searchItems[].matchType | string | ノードの一致した場所。`name`（パス）/ `content`（ファイルの中身。FN0202）。Note・Wiki のときは空文字 |

例:

```json
{
  "searchItems": [
    {
      "viewType": "note",
      "name": "設計メモ",
      "nodeId": "",
      "noteId": "nt_XXXX",
      "wikiId": "",
      "nodeType": ""
    },
    {
      "viewType": "node",
      "name": "設計/基本設計.md",
      "nodeId": "nd_XXXX",
      "noteId": "",
      "wikiId": "",
      "nodeType": "file",
      "matchType": "content"
    }
  ]
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | ユーザー `local` が DB に無い（FN0101-BR02） |
| 500 | DB・ファイル操作の失敗 |

## 5. 処理

1. Note を `user_id` がユーザー `local` かつ タイトルまたは本文がキーワードを含む条件で検索する（FN0201-BR01）。
2. Wiki をタイトルまたは本文がキーワードを含む条件で検索する（FN0201-BR01）。
3. ノードを `node.path` がキーワードを含む条件で検索し、`folder/` に実体があるものだけを残す（FN0201-BR02）。種類は実体がフォルダかどうかで決める。
4. Note、Wiki、ノードの順に結合して返す（FN0201-BR03）。
