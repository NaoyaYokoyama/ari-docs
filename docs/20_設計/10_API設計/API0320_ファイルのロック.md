# API0320 ファイルのロック

## 1. 概要

ファイルをロックする。すでに自分がロックしていれば期限を変える（FN0301-BR38）。ロック中は、ロックした人のほかは上書き・名前の変更・移動・削除ができない

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/nodes/lock` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| path | body | string | ○ | ファイルのパス（`folder/` からの相対パス）。フォルダは不可 |
| expiresAt | body | string | ○ | 期限（RFC 3339）。今より後で、サーバーの設定の `fileLockMaxDays`（既定 7 日。FN0902）日後まで |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 204 | ロックした（期限を変えた） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 期限の形が正しくない・過去・上限より後。フォルダを指定した |
| 401 | 未ログイン |
| 404 | ファイルが無い |
| 409 | ほかの人がロックしている（`message` にその人と期限） |

## 5. 処理

1. パスを確かめ（`folder/` の外は不可）、ファイルの `node_id` を引く。
2. ほかの人の期限内のロックがあれば 409。
3. `node_lock` に本人・ロックした日時・期限を書く（あれば置き換える）。
