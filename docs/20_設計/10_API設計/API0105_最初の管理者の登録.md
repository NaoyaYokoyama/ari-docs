# API0105 最初の管理者の登録

## 1. 概要

共有モードでユーザーが 1 人もいないときに、最初の管理者を登録してログインする。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/setup/admin` |
| 認証 | 不要（ユーザーが 1 人もいないときだけ使える） |
| 権限 | 利用者 |
| 実装 | `back/src/api/auth.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| userId | body | string | ○ | ユーザー ID（FN0102-BR03） |
| displayName | body | string | ○ | 表示名（FN0102-BR04） |
| password | body | string | ○ | パスワード（FN0102-BR05） |
| client | body | string | - | 端末の名前（例: `Windows・デスクトップアプリ`）。無ければ User-Agent を残す。200 文字まで（FN0101-BR15） |

例:

```json
{
  "userId": "admin",
  "displayName": "管理者",
  "password": "password1"
}
```

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 成功。`Set-Cookie: session_id=...`（ブラウザ用）も返す |

| 名前 | 型 | 説明 |
|---|---|---|
| userId | string | ユーザー ID |
| displayName | string | 表示名 |
| mode | string | 動作モード（`shared`） |
| isAdmin | boolean | 管理者か（FN0102-BR01） |
| docsEnabled | boolean | Docs を使う設定か（FN0902-BR06） |
| token | string | セッションのトークン。以後 `Authorization: Bearer <token>` で送る（FN0101-BR08） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 入力の誤り（FN0102-BR03〜BR05 の文言） |
| 403 | ローカルモード |
| 409 | 既にユーザーがいる（「管理者は登録済みです。ログインしてください」） |

## 5. 処理

1. 入力を検証する。
2. ユーザーが 1 人もいないときだけ、管理者（`role_id = admin`）として登録する。同時に呼ばれても 1 人しか登録されないよう、1 つの SQL（`INSERT ... WHERE NOT EXISTS`）で行う（FN0102-BR02）。
3. API0102 と同じくセッションを作って返す。
