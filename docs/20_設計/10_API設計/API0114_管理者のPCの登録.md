# API0114 管理者のPCの登録

## 1. 概要

ログインした管理者が、この PC を管理者の PC にする（共有モード。FN0102-BR12）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/admin-devices/register` |
| 認証 | 要（共有モード） |
| 権限 | 管理者（登録していない PC から使っている管理者も） |
| 実装 | `back/src/api/admin_device.rs` の `register_device`・`back/src/service/admin_device.rs` の `register_with_code` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| code | body | string | ○ | API0113 で発行したコード（その人あて）か、サーバーの登録用のコード（サーバーを起動した画面・`setup-code.txt`。FN0102-BR02）。大文字・小文字、`-` と空白は問わない。サーバーの PC の中（127.0.0.1）からは何でもよい |
| client | body | string | - | 端末の名前（例: Windows・デスクトップアプリ。200 文字まで） |
| X-Ari-Device | header | string | ○ | この PC の鍵（32〜128 文字。画面が作って送る） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | `{"message": "この PC を管理者の PC にしました", "data": null}` |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 鍵が無い |
| 401 | 未ログイン |
| 403 | ローカルモード、管理者でない、コードが違うか 10 分を過ぎた |

## 5. 処理

1. ログインした人が管理者（DB の `role_id`）であることを確かめる。
2. 発行したコード（その人あて）を使い済みにする。違えばサーバーの登録用のコードと比べる（無ければ作って、サーバーの起動画面と `setup-code.txt` に出す）。
3. 鍵の SHA-256 を `admin_device`（TBL0106）に登録する。登録用のコードを使ったときは、そのコードを消す（次に要るときに作り直す）。
