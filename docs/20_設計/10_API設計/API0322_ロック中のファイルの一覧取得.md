# API0322 ロック中のファイルの一覧取得

## 1. 概要

期限内のロックの一覧（設定の「ロック中のファイル」。FN0301-BR38）。だれでも見られる（Folder の一覧の鍵の印と同じ情報）

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/nodes/locks` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| 名前 | 型 | 説明 |
|---|---|---|
| [].path | string | ファイルのパス |
| [].userName | string | ロックした人の表示名 |
| [].mine | boolean | 自分のロック |
| [].expiresAt | string | 期限（YYYY/MM/DD HH:MM。サーバーの時刻） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |

## 5. 処理

1. 期限が過ぎたものを除いて、期限の近い順（同じならパスの順）に返す。
