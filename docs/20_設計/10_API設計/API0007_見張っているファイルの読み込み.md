# API0007 見張っているファイルの読み込み

## 1. 概要

共有サーバーから開いて見張っているファイル（API0006）の今の中身を返す（Tauri コマンド。FN0301-BR28）。保存されると `ari-docs://file-changed` イベント（値は見張りの ID）で画面に知らせる。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `read_watched` |
| 認証 | -（デスクトップアプリの画面から呼ぶ） |
| 権限 | 利用者 |
| 実装 | `desktop/src-tauri/src/lib.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| watchId | 引数 | number | ○ | API0006 が返した見張りの ID |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| - | ファイルの中身（バイト列） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| エラー（文字列） | 見張りが終わっている（24 時間を過ぎた・ファイルが消えた）・読めない |

## 5. 処理

1. ID のファイルを読んで返す。
