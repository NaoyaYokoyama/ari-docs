# API0110 管理者・利用者の切り替え

## 1. 概要

管理者が、ほかのユーザーを管理者・利用者に切り替える（共有モード。FN0102-BR10）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/users/role` |
| 認証 | 要（共有モード） |
| 権限 | 管理者 |
| 実装 | `back/src/api/user/handler.rs` の `change_role`・`back/src/service/user.rs` の `change_role` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| userId | body | string | ○ | 切り替えるユーザー（自分・`local` は不可） |
| isAdmin | body | boolean | ○ | `true` で管理者、`false` で利用者 |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | `{"message": "管理者にしました" / "利用者にしました", "data": null}` |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 自分を切り替えようとした（「自分の管理者・利用者は変えられません」） |
| 401 | 未ログイン |
| 403 | ローカルモード、管理者でない |
| 404 | ユーザーが無い（`local` も） |

## 5. 処理

1. 管理者であることを確かめる。
2. 自分なら 400。`user.role_id` を `admin` / `user` に書き換え、`updated_at` を今にする。利用者にしたら、その人の管理者の PC（TBL0106）を消す。管理者にした人は、自分の PC を登録する（コードは API0113。FN0102-BR12）まで管理者の操作ができない。権限は要求ごとに DB から読むので、ログインし直さなくてもすぐに効く。
