# API0303 ノード削除

## 1. 概要

フォルダ（中身ごと）またはファイルを削除する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/nodes/delete` |
| 認証 | 要（ローカルモードではユーザー `local` として処理する。FN0101-BR01、FN0301-BR13） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| parentPath | body | string | ○ | 対象の親フォルダのパス |
| nodeType | body | string | ○ | `folder` / `file` |
| name | body | string | ○ | 対象の名前。空・`.`・`..`・`/`・`\` を含むものは不可（FN0301-BR03） |

例:

```json
{
  "parentPath": "test2",
  "nodeType": "file",
  "name": "memo.txt"
}
```

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 204 | 削除成功（本文なし） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | `name` が不正（FN0301-BR03） |
| 400 | パスに `..`・絶対パス・ドライブ指定を含む（「パスが正しくありません」。FN0301-BR10） |
| 401 | 未ログイン |
| 404 | 対象が無い |
| 500 | 削除に失敗 |

## 5. 処理

1. ログインを確認する（FN0301-BR13）。`name` と `parentPath` を検証する（FN0301-BR03・BR10）。
2. `folder/<parentPath>/<name>` をゴミ箱（`<データのフォルダ>/trash/<trash_id>/`）へ移し、TBL0302 に記録する（FN0302-BR01）。フォルダは中身ごと移す（FN0301-BR04）。
3. 移したノード（フォルダなら中のノードも）の `node` テーブルの行と、それを指す全ユーザーのお気に入りを削除する。失敗してもログに出すだけで 204 を返す（FN0301-BR15）。
