# API0101 ユーザー情報取得

## 1. 概要

処理に使うユーザー（ローカルモードは `local`、共有モードはログイン中のユーザー）の情報を返す。フロントの起動時に使う（FN0101-BR04）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/me` |
| 認証 | ローカルモードは不要（ユーザー `local` として処理する。FN0101-BR01）。共有モードは要（FN0101-BR07） |
| 権限 | 利用者 |
| 実装 | `back/src/api/auth.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| userId | string | ユーザー ID（ローカルモードでは `local`） |
| displayName | string | 表示名 |
| mode | string | 動作モード（`local` / `shared`） |
| isAdmin | boolean | 共有モードの管理者か（FN0102-BR01）。ローカルモードは常に false |
| docsEnabled | boolean | Docs を使う設定か（FN0902-BR06）。ヘッダーのメニュー・`Alt+数字` に Docs を出すかを決める |

例:

```json
{
  "userId": "local",
  "displayName": "NAOYA YOKOYAMA",
  "mode": "local",
  "isAdmin": false,
  "docsEnabled": false
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | ローカルモードでユーザー `local` が DB に無い（FN0101-BR02）。共有モードで未ログイン |

## 5. 処理

1. ユーザーを取得する（ローカルモードは `local`、共有モードはセッションのユーザー。FN0101-BR08）。
2. ユーザー情報と動作モードを返す。
