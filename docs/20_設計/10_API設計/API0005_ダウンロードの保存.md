# API0005 ダウンロードの保存

## 1. 概要

ダウンロードしたファイルを、保存先を選ばせて保存する（Tauri コマンド。FN0301-BR21）。ブラウザ（開発時）では `<a download>` で保存する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `save_download` |
| 認証 | -（デスクトップアプリの画面から呼ぶ） |
| 権限 | 利用者 |
| 実装 | `desktop/src-tauri/src/lib.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| （本文） | 本文 | バイト列 | ○ | ファイルの中身 |
| x-file-name | ヘッダー | string | ○ | ファイル名（URL エンコード）。パスを含んでいても名前の部分だけを使う |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| - | 保存したら true、キャンセルしたら false |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| エラー（文字列） | 保存先に書き込めない |

## 5. 処理

1. OS の保存ダイアログを、ファイル名を入れた状態で開く。
2. 選んだ場所に書く。
