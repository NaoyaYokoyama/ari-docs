# API0207 探して開く

## 1. 概要

探して開く（FN0003）の Note・Wiki・ノードを、名前と入っている場所のあいまい検索で探す（FN0003-BR03〜BR06）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/home/quick-open` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/home/handler.rs`、`back/src/service/quick_open.rs`、`back/src/search/fuzzy.rs` |

## 3. リクエスト

| 名前 | 型 | 必須 | 説明 |
|---|---|---|---|
| keyword | string | ○ | 打った文字。空白で区切ると、どの語も含むものを探す。先頭の 100 文字だけ使う |
| showHidden | boolean | - | 隠しファイル（`.` で始まる名前）とその中のものも返す（既定 false） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功（語が無ければ `items` は空） |

| 名前 | 型 | 説明 |
|---|---|---|
| items[] | array | 点数の高い順に 50 件まで |
| items[].kind | string | `note` / `wiki` / `folder` / `file` |
| items[].id | string | `note_id` / `wiki_id` / `node_id` |
| items[].name | string | タイトル・ファイル名 |
| items[].location | string | Note・Wiki は入っているフォルダの名前を `/` でつないだもの（FN0403）、ノードは親のパス。一番上は空文字 |
| items[].path | string | ノードの `folder/` からの相対パス（Note・Wiki は空文字） |
| items[].score | number | 点数（高いほど打った文字に近い） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 500 | DB の読み込みに失敗 |

## 5. 処理

1. 打った文字をそろえ（NFKC・小文字・カタカナをひらがなに）、空白で語に分ける。
2. 本人の Note・全員の Wiki（入っているフォルダの場所を付ける）・`node` のすべての行を、「場所/名前」に語が順に含まれるかで調べ、点数を付ける（FN0003-BR04）。隠しファイルは `showHidden` のときだけ。
3. 点数の高い順（同じなら名前・場所の短い順）に並べ、ノードは実体があるものだけを、フォルダかファイルかを実体で決めて、50 件まで返す。
