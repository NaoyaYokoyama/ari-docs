# API0701 表示名変更

## 1. 概要

ユーザー `local` の表示名を変更する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/setting/update/display-name` |
| 認証 | 不要（ユーザー `local` として処理する。FN0101-BR01） |
| 権限 | 利用者 |
| 実装 | `back/src/api/setting/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| displayName | body | string | ○ | 新しい表示名 |

例:

```json
{
  "displayName": "山田 太郎"
}
```

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 変更成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| message | string | `ユーザー名を変更しました` |
| data | object | 空オブジェクト |

例:

```json
{
  "message": "ユーザー名を変更しました",
  "data": {}
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | ユーザー `local` が DB に無い（FN0101-BR02） |
| 500 | 更新対象のユーザーが無い、DB の失敗 |

## 5. 処理

1. ユーザー `local` の `display_name` を更新する。
