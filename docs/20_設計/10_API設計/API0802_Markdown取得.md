# API0802 Markdown 取得

## 1. 概要

指定フォルダ以下の `.md` を 1 件返す。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/doc` |
| 認証 | 不要（ユーザー `local` として処理する。FN0101-BR01） |
| 権限 | 利用者 |
| 実装 | `back/src/api/docs/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| root | query | string | ✕ | フォルダ。API0801 と同じ（省略時は設定の初期フォルダ → `docs/`） |
| path | query | string | ○ | `root` からの相対パス。`..`・絶対パス・`.md` 以外は不可（FN0801-BR03、FN0801-BR04） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| path | string | リクエストの `path` |
| content | string | ファイルの内容（front matter を含む） |

例:

```json
{
  "path": "00_概要/0090_ドキュメントルール.md",
  "content": "---\nid: 0090_ドキュメントルール\n..."
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | `path` が不正、または `root` の外（シンボリックリンク経由を含む） |
| 401 | ユーザー `local` が DB に無い（FN0101-BR02） |
| 404 | ファイルが存在しない。Docs を使わない設定（FN0902-BR06、FN0801-BR15） |
| 500 | DB・ファイル操作の失敗 |

## 5. 処理

1. 表示するフォルダを API0801 と同じ順で決める。
2. `path` を検証し、`root` の外でないことを確認する。
3. ファイルを読んで返す。
