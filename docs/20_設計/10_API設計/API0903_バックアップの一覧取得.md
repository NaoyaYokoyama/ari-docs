# API0903 バックアップの一覧取得

## 1. 概要

バックアップの一覧を返す（FN0901-BR08）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/backups` |
| 認証 | 要。ローカルモードは利用者、共有モードは管理者だけ |
| 権限 | 管理者（共有モード） |
| 実装 | `back/src/api/backup/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| backups | array | 新しいものから |
| backups[].backupId | string | ID（`bk_` で始まる） |
| backups[].fileName | string | ファイル名 |
| backups[].size | number | サイズ |
| backups[].kind | string | `auto` / `manual` / `before_restore` |
| backups[].createdBy | string | 作った人の表示名（定期は `system`） |
| backups[].createdAt | string | 作った日時（UTC） |
| backups[].exists | boolean | ファイルがある |
| busy | boolean | バックアップ・復元の実行中（FN0901-BR07） |
| defaultDir | string | 既定の保存先 |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 403 | 共有モードで管理者でない（「バックアップは管理者だけが扱えます」） |

## 5. 処理

1. 一覧と、実体があるかを返す。
