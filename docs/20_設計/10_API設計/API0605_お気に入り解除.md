# API0605 お気に入り解除

## 1. 概要

お気に入りを解除する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/favorite/delete` |
| 認証 | 不要（ユーザー `local` として処理する。FN0101-BR01） |
| 権限 | 利用者 |
| 実装 | `back/src/api/favorite/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| favoriteId | body | string | ○ | お気に入り ID |

例:

```json
{
  "favoriteId": "fv_XXXX"
}
```

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 解除成功（存在しない ID でも 200） |

| 名前 | 型 | 説明 |
|---|---|---|
| message | string | 処理結果のメッセージ |
| data | null | なし |

例:

```json
{
  "message": "お気に入りを解除しました。",
  "data": null
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | ユーザー `local` が DB に無い（FN0101-BR02） |
| 500 | DB・ファイル操作の失敗 |

## 5. 処理

1. `user_id` がユーザー `local` かつ `favorite_id` が一致する行を削除する。
