# API0318 フォルダを比べる

## 1. 概要

Folder の 2 つのフォルダの中を比べ、ファイル・フォルダを同じ・違う・片方だけに分けて返す（FN0304）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/compare/folders` |
| 認証 | 必要（未ログインは 401） |
| 権限 | 利用者 |
| 実装 | `back/src/api/compare.rs`・`back/src/service/compare.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| left | body | string | ○ | 左のフォルダ（`folder/` からの相対パス。空は一番上） |
| right | body | string | ○ | 右のフォルダ |

## 4. レスポンス

### 4.1 成功時

| 名前 | 型 | 説明 |
|---|---|---|
| entries | object[] | `path`（比べたフォルダからの相対パス）・`status`（same / changed / onlyLeft / onlyRight）・`isDir`・`leftSize`・`rightSize` |
| truncated | boolean | 5000 件を超えて、比べていないものがある |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | パスに `..` などがある、フォルダとその中のフォルダを比べようとした |
| 401 | 未ログイン |
| 404 | フォルダが無い |

## 5. 処理

1. 2 つのフォルダの中を、シンボリックリンクはたどらずに 5000 件まで調べる。
2. 相対パスで組にし、ファイルは大きさが同じなら中身を少しずつ読んで比べる。片方だけにあるフォルダの中身は、フォルダの行だけにする。
3. パスの順に返す。
