# API0613 完了したタスクの削除

## 1. 概要

完了したタスクをまとめて消す（FN0602-BR07）。未完了の子は繰り上げて残す

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/tasks/delete-done` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者（本人のものだけ） |
| 実装 | `back/src/api/task/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 204 | 消した |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |

## 5. 処理

1. 本人の完了したタスクを 1 つずつ API0612 と同じく消す。
