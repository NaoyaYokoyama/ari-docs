# API0013 公開のポートの変更

## 1. 概要

共有サーバーとして使っている PC の待ち受けポートを変える（Tauri コマンド。FN0005-BR10）。`config.toml` の `host_port` を書き換えてアプリを再起動する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `set_host_port` |
| 認証 | -（デスクトップアプリの画面から呼ぶ。画面は共有 PC の管理者だけに出す） |
| 権限 | 共有 PC の管理者 |
| 実装 | `desktop/src-tauri/src/lib.rs` の `set_host_port` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| port | 引数 | number | ○ | 1024〜65535 |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| - | なし（アプリが再起動する） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| エラー（文字列） | 共有サーバーとして使っていない、ポートが 1024 未満、設定ファイルに書き込めない |

## 5. 処理

1. `shared_host` が `true` で、ポートが 1024〜65535 であることを確かめる。
2. `host_port` を書き換えて保存し、アプリを再起動する。起動したときにそのポートが使われていれば、起動エラーの画面にその旨を出す（FN0002-BR22）。
