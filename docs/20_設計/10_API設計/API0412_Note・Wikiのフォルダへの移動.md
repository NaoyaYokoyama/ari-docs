# API0412 Note・Wiki のフォルダへの移動

## 1. 概要

フォルダと Note・Wiki を、指定したフォルダ（または一番上）へ移す（FN0403-BR06）。1 つでも移せなければ何も移さない。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/content-folders/move` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者（Note のフォルダは本人のものだけ） |
| 実装 | `back/src/api/content_folder/handler.rs` の `move_to_folder` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| kind | body | string | ○ | `note` / `wiki`。ほかは 400 |
| folderIds | body | string[] | - | 移すフォルダ |
| itemIds | body | string[] | - | 移す Note・Wiki（`note_id` / `wiki_id`） |
| destId | body | string | - | 移動先のフォルダ。空・無しなら一番上 |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| message | string | 結果の文言 |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 400 | kind が正しくない・フォルダを自分の中へ移そうとした（MSG0421） |
| 404 | 移動先・移すフォルダ・Note・Wiki が無い（Note は本人のものでない）（MSG0422） |
| 409 | 移動先に同じ名前のフォルダがある（MSG0418） |

## 5. 処理

1. 移動先・移すものがあるかと、フォルダを自分の中へ移していないか・同じ名前が無いかを確かめる。
2. まとめて（1 つのトランザクションで）親・入れ場所を書き換える。一番上へ移す Note・Wiki は入れ場所の行を消す。
