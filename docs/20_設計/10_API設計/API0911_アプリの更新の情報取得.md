# API0911 アプリの更新の情報取得

## 1. 概要

共有サーバーに置いた更新ファイルの中から、デスクトップアプリの今の版より新しい版を返す。デスクトップアプリの更新の部品（Tauri の updater）が呼ぶ。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/app-update/{target}/{arch}/{current_version}` |
| 認証 | 不要（更新の部品はログインのトークンを持たないため。返すのはアプリのファイルの情報だけで、利用者のデータは返さない） |
| 権限 | 利用者 |
| 実装 | `back/src/api/app_update/handler.rs`、`back/src/service/app_update.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| target | パス | string | ○ | OS（`windows` / `linux`） |
| arch | パス | string | ○ | CPU（`x86_64`） |
| current_version | パス | string | ○ | デスクトップアプリの今の版 |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 新しい版がある |
| 204 | 新しい版が無い（更新ファイルが無い・今の版より新しくない） |

| 名前 | 型 | 説明 |
|---|---|---|
| version | string | 新しい版 |
| url | string | 取ってくる URL（API0912）。呼ばれたときの `Host` と、HTTPS で待ち受けているかで作る |
| signature | string | `.sig` のファイルの中身 |

例:

```json
{
  "version": "0.2.0",
  "url": "http://ari-server:8080/api/app-update/files/ari-docs_0.2.0_x64-setup.exe",
  "signature": "dW50cnVzdGVkIGNvbW1lbnQ6..."
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | `Host` が無い |

## 5. 処理

1. `<データのフォルダ>/app-update/` のファイルの名前から版と OS を読み、`{target}-{arch}` に合い、同じ名前の `.sig` があるものの中で一番新しい版を選ぶ（FN0904-BR11）。

| OS | ファイルの名前 |
|---|---|
| `windows-x86_64` | `ari-docs_<版>_x64-setup.exe` |
| `linux-x86_64` | `ari-docs_<版>_amd64.AppImage` |

2. 今の版より新しければ返し、そうでなければ 204 を返す（FN0904-BR08）。
