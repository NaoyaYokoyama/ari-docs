# API0206 最近更新されたもの

## 1. 概要

ホームの「最近更新されたもの」を返す（FN0201-BR07）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/home/recent` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/home/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| wikis[] | array | 新しい順に 8 件（`id`・`title`・`updatedAt`（UTC）・`updatedBy`） |
| notes[] | array | 本人の Note を新しい順に 5 件（`updatedBy` は空文字） |
| files[] | array | 新しい順に 10 件（`path`・`updatedAt`（`YYYY/MM/DD HH:MM`、サーバーの現地時刻））。フォルダと消えたものは除く |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |

## 5. 処理

1. Wiki・本人の Note を更新日時の新しい順に取る。
2. `node.modified_at`（BAT0301 が記録）の新しい順にファイルを取り、実体のあるものだけを返す。
