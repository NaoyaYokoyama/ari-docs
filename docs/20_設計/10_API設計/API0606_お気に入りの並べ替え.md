# API0606 お気に入りの並べ替え

## 1. 概要

ホームのお気に入りの並び順を変える（FN0601-BR08）。画面はドラッグか `Alt+↑`・`Alt+↓` で並べ替えたあとに、上からの順をすべて送る。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/favorite/order` |
| 認証 | 必要（未ログインは 401） |
| 権限 | 利用者（本人のお気に入りだけ） |
| 実装 | `back/src/api/favorite/handler.rs` の `update_favorite_order`・`back/src/repository/favorite.rs` の `update_order` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| favoriteIds | body | string[] | ○ | お気に入り ID を上からの順に。ほかの人のもの・無い ID は無視する |

例:

```json
{
  "favoriteIds": ["fv_XXXX", "fv_YYYY"]
}
```

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 並べ替えた（`message`・`data` は null） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 500 | DB の失敗 |

## 5. 処理

1. 1 つのトランザクションで、本人のお気に入りの `sort_order` を、送られた順に 0, 1, 2… にする。
2. 送られなかった本人のお気に入りは、今の並びのまま後ろに回す。
