# API0308 ノードの移動

## 1. 概要

ファイル・フォルダを別のフォルダへ移す（FN0301-BR19）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/nodes/move` |
| 認証 | 要（ローカルモードはユーザー `local`。FN0301-BR13） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| paths | body | string[] | ○ | 移すもののパス |
| destPath | body | string | ○ | 移動先のフォルダのパス（`""` はルート） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 204 | 移動成功（本文なし）。同じフォルダへの移動は何もしない |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | パスに `..`・絶対パス・ドライブ指定を含む（FN0301-BR10） |
| 400 | フォルダを自分の中へ移す（「「{名前}」をその中のフォルダへは移動できません」） |
| 401 | 未ログイン |
| 404 | 移すもの・移動先が無い |
| 409 | 移動先に同じ名前がある（「移動先に「{名前}」が既にあります」） |

## 5. 処理

1. すべてを先に確かめ、1 つでも移せなければ何も移さない。
2. 1 つずつ移し、`node` テーブルのパスを API0307 と同じく変える。
