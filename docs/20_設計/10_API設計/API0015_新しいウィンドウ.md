# API0015 新しいウィンドウ

## 1. 概要

デスクトップアプリの新しいウィンドウを開く・ほかのウィンドウの数を返す（Tauri コマンド。FN0301-BR36）。窓は同じバックエンド・設定を使う

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `open_window / other_window_count` |
| 認証 | -（デスクトップアプリの画面から呼ぶ） |
| 権限 | この PC の利用者 |
| 実装 | `desktop/src-tauri/src/lib.rs`・`front/src/app/windows.ts` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| url | 引数（open_window） | string | ○ | 画面の中のパス（`/?page=…&state=…&place=…`）。`/` で始まり `//` で始まらないもの |

## 4. レスポンス

### 4.1 成功時

| 名前 | 型 | 説明 |
|---|---|---|
| （open_window） | - | 開いた |
| （other_window_count の戻り値） | number | ほかに開いているウィンドウの数（最後の窓を閉じるかの判断に使う） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| （エラーの文字） | url が正しくない・窓を作れない |

## 5. 処理

1. `win-<番号>` の名前で、1200×800 の窓を作り、`url` の画面を開く（`start.tsx` が描く前にその画面にする）。
