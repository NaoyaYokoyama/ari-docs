# API0803 Markdown の画像の取得

## 1. 概要

Markdown ビューアの本文の画像を返す（FN0801-BR16）。表示しているフォルダの中の画像だけを読む。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/doc-image` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/docs/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| root | query | string | ✕ | フォルダ。API0801 と同じ（省略時は設定の初期フォルダ → `docs/`） |
| path | query | string | ○ | `root` からの相対パス。`..`・絶対パス・シンボリックリンクで外へ出るものは不可（FN0801-BR03）。拡張子は png・jpg・jpeg・gif・webp・svg（大文字・小文字は問わない） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 画像の中身。`Content-Type` は拡張子から決める。`X-Content-Type-Options: nosniff`・`Content-Security-Policy: sandbox`（SVG の中のスクリプトを動かさない） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | パスが正しくない・画像の形式でない・20 MB を超える |
| 401 | 未ログイン |
| 403 | 共有モードで `root` を指定した（FN0801-BR02） |
| 404 | 画像が無い・Docs を使わない設定（FN0801-BR15） |

## 5. 処理

1. フォルダを決め（API0802 と同じ）、パスと拡張子を確かめる。
2. 画像を読んで返す。
