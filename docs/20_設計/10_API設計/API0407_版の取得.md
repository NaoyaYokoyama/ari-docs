# API0407 版の取得

## 1. 概要

Note・Wiki の 1 つの版の中身を返す（FN0402-BR03）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/history/{historyId}` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/history.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| historyId | path | number | ○ | 版の ID |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| historyId | number | 版の ID |
| title | string | タイトル |
| content | string | 本文 |
| updatedBy | string | 保存した人の表示名 |
| savedAt | string | その版の更新日時（UTC） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 404 | 無い・本人の Note でない |

## 5. 処理

1. 版を取り、Note なら本人のものかを確かめて返す。
