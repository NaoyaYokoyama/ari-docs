# API0104 サーバー情報取得

## 1. 概要

接続先が ari-docs のサーバーかと、動作モード・最初の管理者の登録が必要かを返す。デスクトップアプリが共有サーバーの URL を確かめるのと、ログイン画面で管理者の登録を出すかを決めるのに使う。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/server-info` |
| 認証 | 不要 |
| 権限 | 利用者 |
| 実装 | `back/src/api/auth.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| app | string | 常に `ari-docs` |
| mode | string | 動作モード（`local` / `shared`） |
| needsAdmin | boolean | 共有モードで、ユーザー（`local` を除く）が 1 人もいない（FN0102-BR02） |

例:

```json
{
  "app": "ari-docs",
  "mode": "shared",
  "needsAdmin": false
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 500 | DB の失敗 |

## 5. 処理

1. `local` を除くユーザーの数を数え、共有モードで 0 なら `needsAdmin` を true にする。
