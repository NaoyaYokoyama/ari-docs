# API0006 ダウンロードして開く

## 1. 概要

共有サーバーのファイルを一時フォルダに保存し、OS の既定のアプリで開く（Tauri コマンド。FN0301-BR21）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `open_download` |
| 認証 | -（デスクトップアプリの画面から呼ぶ） |
| 権限 | 利用者 |
| 実装 | `desktop/src-tauri/src/lib.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| （本文） | 本文 | バイト列 | ○ | ファイルの中身 |
| x-file-name | ヘッダー | string | ○ | ファイル名（URL エンコード） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| - | 見張りの ID（number）。保存されると `ari-docs://file-changed` で知らせる（API0007。FN0301-BR28） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| エラー（文字列） | 一時フォルダに書けない・開けない |

## 5. 処理

1. OS の一時フォルダの `ari-docs/<時刻>/` に保存する（開くたびにフォルダを分け、前に開いたものを上書きしない）。
2. ファイルを見張りに加え（2 秒ごとに更新日時とサイズを確かめ、変わって 2 秒落ち着いたら知らせる。24 時間で終わる）、OS の既定のアプリで開く。
