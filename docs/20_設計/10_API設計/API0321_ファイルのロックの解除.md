# API0321 ファイルのロックの解除

## 1. 概要

ファイルのロックを外す（FN0301-BR38）。外せるのはロックした人と管理者だけ

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/nodes/unlock` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | ロックした人・管理者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| path | body | string | ○ | ファイルのパス |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 204 | 外した（もともとロックが無いときも） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 403 | ほかの人のロックで、管理者でない（`message` にロックした人） |
| 404 | ファイルが無い |

## 5. 処理

1. ロックを引き、本人か管理者（`auth::is_admin`）なら `node_lock` の行を消す。
