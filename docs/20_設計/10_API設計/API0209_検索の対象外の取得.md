# API0209 検索の対象外の取得

## 1. 概要

全員の検索の対象外と、本人だけの検索の対象外を返す（FN0202-BR16・BR17）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/search/exclusions` |
| 認証 | 要 |
| 権限 | ログインユーザー |
| 実装 | `back/src/api/search/handler.rs` |

## 3. リクエスト

なし

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | `all`（全員の対象外）・`mine`（本人だけの対象外）。それぞれ `exclusionId`・`kind`（`path` / `name`）・`value`・`createdBy`（登録した人の表示名）・`createdAt`。`canEditAll`（全員の対象外を変えられる。ローカルモード、または共有モードの管理者）・`personal`（本人だけの対象外を使う。共有モード） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |

## 5. 処理

1. 全員の対象外と本人の対象外を、種類・値の順に返す。ほかの人の対象外は返さない。
