# API0204 検索の辞書の削除

## 1. 概要

検索の辞書から単語を削除する。次の取り込みから、すべてのファイルを順に取り込み直す。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/search/dictionary/delete` |
| 認証 | 要。ローカルモードは利用者、共有モードは管理者だけ（FN0202-BR10） |
| 権限 | 管理者（共有モード） |
| 実装 | `back/src/api/search/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| word | body | string | ○ | 削除する単語（API0202 の `word` のまま） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 削除成功（MSG0212） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 403 | 共有モードで管理者でない |
| 404 | 単語が無い（「単語が見つかりません」） |

## 5. 処理

1. 単語を削除する。
