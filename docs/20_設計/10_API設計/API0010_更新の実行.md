# API0010 更新の実行

## 1. 概要

API0009 で見つけた新しい版を取ってきて、署名を確かめ、入れ替えて再起動する（Tauri コマンド）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `install_update` |
| 認証 | -（デスクトップアプリの画面から呼ぶ） |
| 権限 | 利用者 |
| 実装 | `desktop/src-tauri/src/lib.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

戻らない（アプリが再起動する）。取ってくる間は、イベント `ari-docs://update-progress`（`downloaded`: 取ってきたバイト数、`total`: 全体のバイト数か null）を 1% ごとに送る。

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| エラー（文字列） | 開発用のビルド（FN0904-BR12）、先に API0009 で新しい版を見つけていない、取ってこられない、署名が合わない（FN0904-BR06）、入れ替えられない |

## 5. 処理

1. ファイルを取ってくる（共有サーバーなら API0912、自分の PC なら GitHub Releases）。
2. アプリに入れた公開鍵（`tauri.conf.json` の `plugins.updater.pubkey`）で署名を確かめる。
3. 入れ替える。
   - Windows: NSIS のインストーラーを画面を出さずに動かす（`installMode: passive`）。アプリは閉じ、入れ終わると新しい版が起動する。`config.toml` があるのでインストーラーは使い方のページを出さない
   - Linux: `.AppImage` のファイルを入れ替える
4. 再起動する。
