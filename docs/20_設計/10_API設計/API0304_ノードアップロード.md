# API0304 ノードアップロード

## 1. 概要

ファイルを指定フォルダへ保存する。フォルダの構成は `paths` で再現する（FN0301-BR06）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/nodes/upload` |
| 認証 | 要（ローカルモードではユーザー `local` として処理する。FN0101-BR01、FN0301-BR13） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| parentPath | body（multipart） | string | ○ | 保存先フォルダのパス |
| files | body（multipart） | file（複数） | ○ | ファイル |
| paths | body（multipart） | string（複数） | ○ | 各ファイルの保存先の相対パス。`files` と同じ数・同じ順 |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 保存成功（本文なし） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | `parentPath` が無い、`files` と `paths` の数が違う、multipart が不正 |
| 400 | `parentPath` と `paths` をつないだパスが正しくない（FN0301-BR10）。1 件でも正しくなければ、どのファイルも書き込まない |
| 413 | 合計が 1 GB を超える（FN0301-BR29） |
| 401 | 未ログイン |
| 500 | フォルダの作成・ファイルの書き込みに失敗 |

## 5. 処理

1. ログインを確認する（FN0301-BR13）。
2. multipart から `parentPath`・`files`・`paths` を読む。
3. すべての `folder/<parentPath>/<paths[i]>` が `folder/` の中かを確かめる（FN0301-BR10）。1 件でも外を指せば 400 にして、何も書き込まない。
4. 親フォルダを作り、ファイルを書き込む（同名は上書き）。
