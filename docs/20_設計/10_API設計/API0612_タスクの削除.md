# API0612 タスクの削除

## 1. 概要

タスクを消す（元に戻せない。FN0602-BR07）。子は消さず、消したものの位置へ繰り上げる

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/tasks/delete` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者（本人のものだけ） |
| 実装 | `back/src/api/task/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| taskId | body | string | ○ | 消すタスク |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 204 | 消した |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 404 | タスクが無い |

## 5. 処理

1. 子を消したものの親の、消したものの位置へ移してから、行を消す。
