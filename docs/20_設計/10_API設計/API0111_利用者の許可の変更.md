# API0111 利用者の許可の変更

## 1. 概要

管理者が、管理者でない利用者に許可（検索の辞書・全員の検索の対象外・バックアップ）を付ける・外す（共有モード。FN0102-BR11）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/users/permissions` |
| 認証 | 要（共有モード） |
| 権限 | 管理者（登録した PC から。FN0102-BR12） |
| 実装 | `back/src/api/user/handler.rs` の `update_permissions`・`back/src/service/user.rs` の `set_permissions` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| userId | body | string | ○ | 許可を変える利用者（管理者・`local` は不可） |
| permissions | body | string[] | ○ | 付ける許可の全部（`dictionary`・`exclusion`・`backup`）。空なら全部外す。同じものは 1 つにまとめる |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | `{"message": "許可を変えました", "data": null}` |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 管理者に付けようとした（「管理者は許可を付けなくてもすべてできます」）、知らない許可 |
| 401 | 未ログイン |
| 403 | ローカルモード、管理者でない、登録していない PC から使っている |
| 404 | ユーザーが無い（`local` も） |

## 5. 処理

1. 管理者（登録した PC から）であることを確かめる。
2. 相手が管理者なら 400。許可の名前を確かめ、`user_permission`（TBL0105）のその人の行を入れ替える。許可は要求ごとに DB から読むので、ログインし直さなくてもすぐに効く。
