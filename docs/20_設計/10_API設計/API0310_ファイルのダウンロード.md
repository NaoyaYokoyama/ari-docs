# API0310 ファイルのダウンロード

## 1. 概要

ファイルの中身を返す（FN0301-BR21）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/nodes/download` |
| 認証 | 要（ローカルモードはユーザー `local`。FN0301-BR13） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| path | query | string | ○ | ファイルのパス |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 成功。本文はファイルの中身（`Content-Type: application/octet-stream`、`Content-Disposition: attachment; filename*=UTF-8''<URL エンコードした名前>`） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | パスに `..`・絶対パス・ドライブ指定を含む（FN0301-BR10） |
| 401 | 未ログイン |
| 404 | ファイルが無い・フォルダ |

## 5. 処理

1. パスを検証し、ファイルを読んで返す。
