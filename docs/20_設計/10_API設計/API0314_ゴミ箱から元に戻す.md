# API0314 ゴミ箱から元に戻す

## 1. 概要

ゴミ箱のものを元の場所に戻す（FN0302-BR03）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/trash/restore` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/trash/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| trashIds | body | string[] | ○ | 戻すものの ID |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 成功。`message` に件数、`data` に戻した場所（`folder/` からのパス）の配列 |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 404 | ゴミ箱に無い・中の実体が無い |

## 5. 処理

1. 1 件ずつ、元のフォルダ（無ければ作る）に、同じ名前があれば「名前 (2)」などにして戻し、記録を消す。
