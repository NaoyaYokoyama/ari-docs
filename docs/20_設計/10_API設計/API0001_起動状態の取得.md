# API0001 起動状態の取得

## 1. 概要

デスクトップアプリの起動の状態（自分の PC の作業フォルダの準備ができ、バックエンドが動いているか）と、場所（FN0002-BR20）を返す。HTTP の API ではなく、Tauri のコマンド（画面から `invoke` で呼ぶ）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `setup_status` |
| 認証 | 不要 |
| 権限 | 利用者（デスクトップアプリのみ） |
| 実装 | `desktop/src-tauri/src/lib.rs` |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| - | 常に返す |

| 名前 | 型 | 説明 |
|---|---|---|
| configured | boolean | 自分の PC の作業フォルダの準備ができ、バックエンドが動いている |
| firstRun | boolean | 初回起動（`config.toml` が無い。FN0002-BR05） |
| workspace | string | 作業フォルダの絶対パス。起動に失敗したときは起動しようとした作業フォルダ。デバッグビルドと、`config.toml` を読めないときは空文字 |
| error | string | 起動に失敗したときの原因（MSG0003、MSG0005）。無ければ空文字 |
| canChangeWorkspace | boolean | 作業フォルダを変えられる（exe のフォルダの `config.toml` を読めた）。デバッグビルドでは `false` |
| places | object | 場所（`localName`・`localColor`・`startPlace`・`servers`。API0008 と同じ形）。古い書き方（`mode`・`server_url`）は読み替えたもの（FN0002-BR21） |
| canChangePlaces | boolean | 場所を変えられる（API0008）。exe のフォルダを取れなかったときは `false` |
| apiPort | number | 自分の PC のバックエンドの待ち受けポート（ふつうは 8080。ほかのアプリが使っていれば 8081〜8099。FN0002-BR22） |
| host | object | この PC の公開（FN0005）。`shared`（共有サーバーとして使っている）・`published`（ほかの PC からつなげる）・`port`（8080）・`urls`（公開しているときにほかの PC に伝える URL。PC の名前と IP アドレス） |

例:

```json
{
  "configured": false,
  "workspace": "/mnt/share/ari",
  "error": "作業フォルダで起動できませんでした。フォルダが見つかりません: /mnt/share/ari",
  "canChangeWorkspace": true,
  "firstRun": false,
  "places": {
    "localName": "",
    "localColor": "",
    "startPlace": "last",
    "servers": [{ "name": "開発部", "url": "http://ari-server:8080", "color": "green" }]
  },
  "canChangePlaces": true,
  "host": { "shared": false, "published": false, "port": 8080, "urls": [] },
  "apiPort": 8080
}
```
