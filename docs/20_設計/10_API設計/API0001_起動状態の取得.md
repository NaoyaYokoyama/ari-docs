# API0001 起動状態の取得

## 1. 概要

デスクトップアプリの起動の状態（作業フォルダの準備ができ、バックエンドが動いているか）を返す。HTTP の API ではなく、Tauri のコマンド（画面から `invoke` で呼ぶ）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `setup_status` |
| 認証 | 不要 |
| 権限 | 利用者（デスクトップアプリのみ） |
| 実装 | `desktop/src-tauri/src/lib.rs` |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| - | 常に返す |

| 名前 | 型 | 説明 |
|---|---|---|
| configured | boolean | 作業フォルダの準備ができ、バックエンドが動いている |
| workspace | string | 作業フォルダの絶対パス。起動に失敗したときは起動しようとした作業フォルダ。デバッグビルドと、`config.toml` を読めないときは空文字 |
| error | string | 起動に失敗したときの原因（MSG0003、MSG0005）。無ければ空文字 |
| canChangeWorkspace | boolean | 作業フォルダを変えられる（exe のフォルダの `config.toml` を読めた、かつ個人用）。デバッグビルドと、共有サーバーに接続する使い方のときは `false` |
| mode | string | 使い方。`local`（個人用）/ `server`（共有サーバーに接続）。初回起動（`config.toml` が無い）は空文字（FN0002-BR05） |
| serverUrl | string | 共有サーバーの URL（`mode` が `server` のとき。FN0002-BR13 で整えたもの）。それ以外は空文字 |
| canChangeMode | boolean | 使い方を変えられる（API0004）。デバッグビルドでは `false` |

例:

```json
{
  "configured": false,
  "workspace": "/mnt/share/ari",
  "error": "作業フォルダで起動できませんでした。フォルダが見つかりません: /mnt/share/ari",
  "canChangeWorkspace": true,
  "mode": "local",
  "serverUrl": "",
  "canChangeMode": true
}
```
