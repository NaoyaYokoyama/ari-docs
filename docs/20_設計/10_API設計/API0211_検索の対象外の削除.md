# API0211 検索の対象外の削除

## 1. 概要

検索の対象外を削除し、検索の対象に戻す（FN0202-BR16・BR17）。全員の対象外だったファイルは、次の取り込み（BAT0302）から順に取り込む。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/search/exclusions/delete` |
| 認証 | 要 |
| 権限 | 全員の対象外は、ローカルモードの利用者か共有モードの管理者・許可（`exclusion`。FN0102-BR11）を付けた利用者。本人だけの対象外は本人 |
| 実装 | `back/src/api/search/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| exclusionId | body | string | ○ | API0209 で返した ID |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 削除成功（MSG0216） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 403 | 共有モードで管理者でも許可を付けた人でもない人が全員の対象外を削除した |
| 404 | 無い・ほかの人の対象外（「検索の対象外が見つかりません」） |

## 5. 処理

1. 対象の人を確かめて削除する。
