# API0003 作業フォルダの変更

## 1. 概要

選んだフォルダを作業フォルダにする。`folder/`・`.ari-docs/` を作り、exe のフォルダの `config.toml` に保存して、アプリを再起動する。Tauri のコマンド。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `change_workspace` |
| 認証 | 不要 |
| 権限 | 利用者（デスクトップアプリで、API0001 の `canChangeWorkspace` が `true` のときだけ） |
| 実装 | `desktop/src-tauri/src/lib.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| path | 引数 | string | ○ | 作業フォルダの絶対パス。存在するフォルダであること |

例:

```json
{
  "path": "/mnt/share/ari"
}
```

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| - | 成功。直後にアプリが再起動するため、画面は結果を使わない |

### 4.2 エラー時

エラーの内容（文字列。MSG0004）を返す。

| ステータス | 条件 |
|---|---|
| - | 作業フォルダを変えられない（「作業フォルダを変えられません」） |
| - | フォルダが見つからない（「フォルダが見つかりません: {path}」） |
| - | `folder/`・`.ari-docs/` を作れない |
| - | 設定ファイルを保存できない |

## 5. 処理

1. 作業フォルダを変えられないときはエラーにする。
2. `path` を正規化した絶対パスにする。
3. `folder/`・`.ari-docs/` を作る（既にあればそのまま使う。FN0002-BR03）。
4. exe のフォルダの `config.toml` に `workspace` を保存する。exe のフォルダなら `"."`、それ以外は絶対パス（FN0002-BR08）。
5. アプリを再起動する。再起動後は FN0002 の 5.1 の流れで起動し、起動できなければ SCR0002 を表示する。
