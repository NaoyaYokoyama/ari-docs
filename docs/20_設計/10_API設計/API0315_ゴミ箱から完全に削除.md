# API0315 ゴミ箱から完全に削除

## 1. 概要

ゴミ箱のものを完全に削除する（FN0302-BR04）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/trash/delete` |
| 認証 | 要。ローカルモードは利用者、共有モードは管理者だけ |
| 権限 | 管理者（共有モード） |
| 実装 | `back/src/api/trash/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| trashIds | body | string[] | ○ | 削除するものの ID |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 成功（「{件数} 件を完全に削除しました」） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 403 | 共有モードで管理者でない |
| 404 | ゴミ箱に無い |

## 5. 処理

1. 実体と記録を消す。
