# API0014 個人の設定の読み込みと保存

## 1. 概要

個人の設定（配色・文字の大きさ・Vim・一覧の並びなど）を、この PC の ari-docs に読み書きする（Tauri コマンド。FN0701-BR15）。保存先は設定ファイル（`config.toml`）と同じフォルダの `preferences.json`（デバッグビルドは `back/data/preferences.json`）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `load_preferences / save_preferences` |
| 認証 | -（デスクトップアプリの画面から呼ぶ） |
| 権限 | この PC の利用者 |
| 実装 | `desktop/src-tauri/src/lib.rs`・`front/src/app/personalSettings.ts` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| values | 引数（save_preferences） | object（キー → 文字列） | ○ | 画面の localStorage の値。ログインのトークン（`ari-docs-token…`）と最近開いたもの（`recent-opened:…`）は含めない。1 MB まで |

## 4. レスポンス

### 4.1 成功時

| 名前 | 型 | 説明 |
|---|---|---|
| （load_preferences の戻り値） | object | 保存した値。ファイルが無ければ空 |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| エラー（文字列） | 保存先が分からない・書き込めない、1 MB を超える |

## 5. 処理

1. load_preferences: ファイルを読んで返す。読めなければ空を返す。画面は起動したときに 1 回呼び、値を localStorage に戻してから画面を描く（`main.tsx`）。空なら今の localStorage を保存する（前の版からの引き継ぎ）。
2. save_preferences: 別の名前（`preferences.json.partial`）に書いてから置き換える。画面は設定を変えたら 0.5 秒待ってまとめて呼ぶ。
