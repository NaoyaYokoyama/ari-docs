# API0210 検索の対象外の登録

## 1. 概要

フォルダ・ファイルを検索の対象から外す（FN0202-BR16・BR17）。全員の対象外は、次の取り込み（BAT0302）でその中のファイルの単語と状態を消す。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/search/exclusions/create` |
| 認証 | 要 |
| 権限 | 全員の対象外は、ローカルモードの利用者か共有モードの管理者・許可（`exclusion`。FN0102-BR11）を付けた利用者。本人だけの対象外はログインユーザー |
| 実装 | `back/src/api/search/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| forAll | body | boolean | ○ | 全員の対象外にする。ローカルモードは常に全員として扱う |
| kind | body | string | ○ | `path`（Folder の一番上からのパス）/ `name`（名前の型） |
| value | body | string | ○ | FN0202-BR16 |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 登録成功（MSG0215。そろえた値を含む） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 値の誤り（空・一番上のフォルダ・`.` `..` を含むパス・ドライブ名・`/` を含む名前の型・`*` `?` だけの型・200 文字超え・知らない種類） |
| 401 | 未ログイン |
| 403 | 共有モードで管理者でも許可を付けた人でもない人が全員の対象外を登録した（「全員の検索の対象外は管理者（と許可を付けられた人）だけが変更できます」） |
| 409 | 登録済み（「「{値}」はもう対象外にしています」） |

## 5. 処理

1. 値をそろえて検証する（前後の空白を除く。パスは `\` を `/` にし、前後の `/` を除く。FN0202-BR16）。
2. 登録する。検索・探して開くでは、次の呼び出しから外す。
