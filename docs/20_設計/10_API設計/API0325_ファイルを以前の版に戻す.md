# API0325 ファイルを以前の版に戻す

## 1. 概要

ファイルの中身を以前の版に戻す（FN0301-BR39）。今の中身も以前の版として残すので、戻したことも戻せる

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/nodes/versions/restore` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/node/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| path | body | string | ○ | ファイルのパス |
| versionId | body | string | ○ | 版の ID |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 204 | 戻した |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 404 | ファイル・版が無い |
| 423 | ほかの人がロックしている（FN0301-BR38） |

## 5. 処理

1. ほかの人のロックを確かめる（`node_lock::ensure_unlocked`）。
2. 今の中身を以前の版として残してから（`keep_before_overwrite`）、版の中身で上書きする。
3. 更新者と更新日時を記録する（FN0301-BR34）。
