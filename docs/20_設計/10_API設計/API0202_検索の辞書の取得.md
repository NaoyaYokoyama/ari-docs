# API0202 検索の辞書の取得

## 1. 概要

検索の辞書の単語の一覧と、登録・削除できるかを返す。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/search/dictionary` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/search/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| words | array | 単語（表記の昇順） |
| words[].word | string | 表記 |
| words[].createdBy | string | 登録したユーザーの表示名（ユーザーが消えていればユーザー ID） |
| words[].createdAt | string | 登録日時（UTC） |
| canEdit | boolean | 登録・削除できる（FN0202-BR10） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 500 | DB の失敗 |

## 5. 処理

1. 単語の一覧を返す。
