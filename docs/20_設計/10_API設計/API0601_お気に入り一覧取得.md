# API0601 お気に入り一覧取得

## 1. 概要

お気に入りを、名称付きで返す。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/home/favorites` |
| 認証 | 不要（ユーザー `local` として処理する。FN0101-BR01） |
| 権限 | 利用者 |
| 実装 | `back/src/api/home/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| favoriteList[] | array | お気に入り。ノード・Note・Wiki の順（FN0201-BR05） |
| favoriteList[].favoriteId | string | お気に入り ID（解除に使う） |
| favoriteList[].name | string | 名称。ノードはパス、Note・Wiki はタイトル |
| favoriteList[].nodeId | string | ノード ID（ノード以外は空文字） |
| favoriteList[].noteId | string | Note ID（Note 以外は空文字） |
| favoriteList[].wikiId | string | Wiki ID（Wiki 以外は空文字） |

例:

```json
{
  "favoriteList": [
    {
      "favoriteId": "fv_XXXX",
      "name": "test2/test21",
      "nodeId": "nd_XXXX",
      "noteId": "",
      "wikiId": ""
    }
  ]
}
```

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | ユーザー `local` が DB に無い（FN0101-BR02） |
| 500 | DB・ファイル操作の失敗 |

## 5. 処理

1. ユーザーのお気に入りをすべて取得する（TBL0601。FN0601-BR04）。
2. 種類ごとに ID を集め、ノード・Note・Wiki の名称を取得する。
3. 各行に `favoriteId` を付けて返す（FN0601-BR03）。
