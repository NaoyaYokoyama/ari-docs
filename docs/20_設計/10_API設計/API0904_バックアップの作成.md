# API0904 バックアップの作成

## 1. 概要

今すぐバックアップを作る（FN0901-BR03）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/backups/create` |
| 認証 | 要。ローカルモードは利用者、共有モードは管理者だけ |
| 権限 | 管理者（共有モード） |
| 実装 | `back/src/api/backup/handler.rs` |

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 作成成功（MSG0902） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 実行中（MSG0906）・保存先に書けない・作れなかった（原因の文言） |
| 401 | 未ログイン |
| 403 | 共有モードで管理者でない（「バックアップは管理者だけが扱えます」） |
