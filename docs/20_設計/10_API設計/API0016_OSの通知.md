# API0016 OSの通知

## 1. 概要

OS の通知を出す（Tauri コマンド。タスクの期限の通知。FN0602-BR13）

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | Tauri コマンド |
| パス | `notify` |
| 認証 | -（デスクトップアプリの画面から呼ぶ） |
| 権限 | この PC の利用者 |
| 実装 | `desktop/src-tauri/src/lib.rs`・`front/src/app/taskNotice.ts` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| title | 引数 | string | ○ | 通知の見出し |
| body | 引数 | string | ○ | 通知の本文 |

## 4. レスポンス

### 4.1 成功時

| 名前 | 型 | 説明 |
|---|---|---|
| （戻り値なし） | - | 通知を出した |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| （エラーの文字） | 通知を出せない（OS の設定で止めているなど） |

## 5. 処理

1. `tauri-plugin-notification` で通知を出す。
