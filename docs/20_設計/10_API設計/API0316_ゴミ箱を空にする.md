# API0316 ゴミ箱を空にする

## 1. 概要

ゴミ箱のものをすべて完全に削除する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/trash/empty` |
| 認証 | 要。ローカルモードは利用者、共有モードは管理者だけ |
| 権限 | 管理者（共有モード） |
| 実装 | `back/src/api/trash/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 成功（「ゴミ箱を空にしました（{件数} 件）」） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 403 | 共有モードで管理者でない |

## 5. 処理

1. すべての実体と記録を消す。
