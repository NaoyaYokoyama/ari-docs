# API0115 管理者のPCの削除

## 1. 概要

管理者の PC の登録を外す（共有モード。FN0102-BR12）。外した PC では管理者の操作ができなくなる（利用者としては使える）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/admin-devices/delete` |
| 認証 | 要（共有モード） |
| 権限 | 管理者（登録した PC から） |
| 実装 | `back/src/api/admin_device.rs` の `delete_device` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| deviceId | body | string | ○ | 外す PC（API0112 の `deviceId`。今使っている PC・ほかの管理者の PC も外せる） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | `{"message": "管理者の PC から外しました", "data": null}` |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 403 | ローカルモード、管理者でない、登録していない PC から使っている |
| 404 | PC が無い |

## 5. 処理

1. 管理者（登録した PC から）であることを確かめる。
2. `admin_device`（TBL0106）の行を消す。管理者の PC がすべて無くなったら、API0114 でサーバーの登録用のコードを使って登録し直す。
