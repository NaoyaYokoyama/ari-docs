# API0706 端末のログアウト

## 1. 概要

本人のほかの端末のセッションを消し、その端末をログアウトさせる（FN0101-BR15）。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/setting/sessions/logout` |
| 認証 | 要（共有モードのみ） |
| 権限 | 利用者 |
| 実装 | `back/src/api/setting/handler.rs` |

## 3. リクエスト

| 名前 | 型 | 必須 | 説明 |
|---|---|---|---|
| key | number | △ | 消す端末の番号（API0705 の `key`）。`others` が false のとき必須 |
| others | boolean | - | true なら、今の端末以外をすべて消す（既定 false） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 成功。`message` は「{件数} 台の端末をログアウトさせました」 |

-

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | `others` が false で `key` が無い（「端末を指定してください」） |
| 401 | 未ログイン |
| 403 | ローカルモード |

## 5. 処理

1. `others` が true なら、本人の今のセッション以外を消す。
2. そうでなければ、本人の `key` のセッションを消す（ほかの人のものは消えない。0 台になる）。
