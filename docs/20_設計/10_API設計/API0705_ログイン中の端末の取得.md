# API0705 ログイン中の端末の取得

## 1. 概要

ログインしたユーザー本人の、有効なセッション（ログインしたままの端末）を返す（FN0101-BR15）。トークンそのものは返さない。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/setting/sessions` |
| 認証 | 要（共有モードのみ） |
| 権限 | 利用者 |
| 実装 | `back/src/api/setting/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| sessions[].key | number | 端末を指す番号（`session` の rowid）。API0706 で使う |
| sessions[].client | string | 端末の名前（例: `Windows・デスクトップアプリ`）。古いログインは User-Agent。画面で名前に直す |
| sessions[].createdAt | string | ログインした日時（サーバーのローカル時刻、`YYYY/MM/DD HH:MM`） |
| sessions[].lastUsedAt | string | 最後に使った日時（同上。1 時間に 1 回だけ更新する） |
| sessions[].current | boolean | 今のリクエストの端末 |
| sessionDays | number | 最後に使ってからこの日数で切れる（FN0902） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 403 | ローカルモード（「ローカルモードではログインしません」） |

## 5. 処理

1. FN0902 のセッションの有効期限を読み、本人の有効なセッションを最後に使った順に返す。
