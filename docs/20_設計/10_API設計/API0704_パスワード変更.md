# API0704 パスワード変更

## 1. 概要

共有モードで、ログイン中のユーザーが自分のパスワードを変える。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/setting/update/password` |
| 認証 | 要（共有モード） |
| 権限 | 利用者 |
| 実装 | `back/src/api/setting/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| currentPassword | body | string | ○ | 現在のパスワード |
| newPassword | body | string | ○ | 新しいパスワード（FN0102-BR05） |
| newPasswordConfirm | body | string | ○ | 新しいパスワード（確認用） |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 成功（「パスワードを変更しました」） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 新しいパスワードの長さの誤り、現在のパスワードが違う（「現在のパスワードが違います」）、確認用と一致しない（「新しいパスワードが一致しません」） |
| 401 | 未ログイン |
| 403 | ローカルモード（パスワードを使わない） |

## 5. 処理

1. 現在のパスワードを照合し、新しいパスワードと確認用の一致を確かめる。
2. パスワードを Argon2 のハッシュにして更新する。パスワードはログに出さない。
3. 本人のほかのセッションを消す（FN0101-BR13）。
