# API0205 取り込み状況の取得

## 1. 概要

ファイルの中身の取り込み状況を返す。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | GET |
| パス | `/api/search/status` |
| 認証 | 要（ローカルモードはユーザー `local`） |
| 権限 | 利用者 |
| 実装 | `back/src/api/search/handler.rs` |

## 3. リクエスト

-

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 取得成功 |

| 名前 | 型 | 説明 |
|---|---|---|
| indexed | number | 今の辞書で取り込み済みのファイル数 |
| outdated | number | 辞書が変わり、取り込み直しを待っているファイル数 |
| failed | number | 読めなかったファイル数 |
| tooLarge | number | 大きすぎて取り込まなかったファイル数 |
| keywords | number | 登録した単語の種類の数 |
| lastRun | object / null | 直近の取り込み（`processed` 取り込んだ数、`pending` 時間切れで次の回に回した数、`finishedAt` 終わった日時 UTC）。起動してからまだ動いていなければ null |
| ocrProgress | object / null | 文字認識している途中のファイルと進み具合（`path` folder/ からのパス、`done` 読み終えた数、`total` 全体の数、`unit` `ページ` か `枚`。FN0202-BR15）。していなければ null |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 401 | 未ログイン |
| 500 | DB の失敗 |

## 5. 処理

1. TBL0203 を数え、直近の取り込みの結果（メモリ）を返す。
