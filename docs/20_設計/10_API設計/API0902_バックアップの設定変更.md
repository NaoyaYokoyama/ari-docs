# API0902 バックアップの設定変更

## 1. 概要

バックアップの設定を保存する。

## 2. エンドポイント

| 項目 | 値 |
|---|---|
| メソッド | POST |
| パス | `/api/backup/settings/update` |
| 認証 | 要。ローカルモードは利用者、共有モードは管理者だけ |
| 権限 | 管理者（共有モード） |
| 実装 | `back/src/api/backup/handler.rs` |

## 3. リクエスト

| 名前 | 場所 | 型 | 必須 | 説明・制約 |
|---|---|---|---|---|
| interval | body | string | ○ | `off` / `daily` / `weekly` / `monthly` |
| hour | body | number | ○ | 時刻（0〜23） |
| retentionDays | body | number | ○ | 定期のバックアップを残す日数 |
| dir | body | string | ○ | 保存先（空なら既定） |
| trashRetentionDays | body | number | ○ | ゴミ箱に残す日数 |

## 4. レスポンス

### 4.1 成功時

| ステータス | 内容 |
|---|---|
| 200 | 保存成功（MSG0901） |

### 4.2 エラー時

| ステータス | 条件 |
|---|---|
| 400 | 間隔・時刻・日数が範囲外、保存先が絶対パスのある フォルダでない |
| 401 | 未ログイン |
| 403 | 共有モードで管理者でない（「バックアップは管理者だけが扱えます」） |

## 5. 処理

1. 検証して保存する（FN0901-BR02）。
