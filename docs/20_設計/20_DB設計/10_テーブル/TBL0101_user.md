# TBL0101 ユーザー

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `user` |
| 概要 | ユーザー。ローカルモードではユーザー ID `local` の 1 行だけを使う。共有モードでは管理者が登録したユーザーを使う（FN0101・FN0102）。 |
| 定義（正） | `back/src/data/migration/T002_create_user.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `user_id` | ユーザー ID | TEXT | 不可 | - | ローカルモードは `local`。共有モードは 1〜32 文字の半角英数字と `_` `.` `-`（FN0102-BR03） |
| `passwd` | パスワード | TEXT | 不可 | - | 共有モード用（Argon2 のハッシュ）。ユーザー `local` は `-`（ログインできない。FN0101-BR10） |
| `display_name` | 表示名 | TEXT | 不可 | - | 画面に表示する名前 |
| `role_id` | ロール ID | TEXT | 不可 | - | 共有モードの権限。`admin`（管理者）/ `user`（利用者）（FN0102-BR01）。ユーザー `local` は `1`（使わない） |
| `updated_at` | 更新日時 | TEXT | 不可 | CURRENT_TIMESTAMP | 作成日時（UTC）。表示名の変更では更新しない |
