# TBL0204 検索の辞書

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `search_dictionary` |
| 概要 | 利用者が登録した単語（業界用語・社内の用語など）。単語の区切りのユーザー辞書として使う（FN0202） |
| 定義（正） | `back/src/data/migration/T009_create_search_index.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `word` | 表記 | TEXT | 不可 | - | NFKC で正規化し、英字は小文字。1〜50 文字（FN0202-BR09） |
| `created_by` | 登録者 | TEXT | 不可 | - | 登録したユーザーの ID |
| `created_at` | 登録日時 | TEXT | 不可 | CURRENT_TIMESTAMP | UTC |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `word` | 同じ単語を登録させない |

## 4. 他テーブルとの関係

| カラム | 参照先 | 参照先が削除されたとき |
|---|---|---|
| `created_by` | TBL0101 user | 行は残る（画面にはユーザー ID を出す） |

## 5. ライフサイクル

| タイミング | きっかけ（API・バッチの ID） | 内容 |
|---|---|---|
| 作成 | API0203 | 登録する |
| 削除 | API0204 | 削除する |
