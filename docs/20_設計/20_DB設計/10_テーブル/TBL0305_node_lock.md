# TBL0305 ファイルのロック

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `node_lock` |
| 概要 | ロックしているファイル（FN0301-BR38）。ロックした人のほかは、上書き・名前の変更・移動・削除ができない。期限を過ぎた行は、読むときに無いものとして扱う |
| 定義（正） | `back/src/data/migration/T024_node_lock.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `node_id` | ノード ID | TEXT | 不可 | - | ロックしたファイル。名前の変更・移動でも外れないよう、パスでなく ID で指す |
| `user_id` | ロックした人 | TEXT | 不可 | - | ユーザー ID |
| `locked_at` | ロックした日時 | INTEGER | 不可 | - | UNIX 秒 |
| `expires_at` | 期限 | INTEGER | 不可 | - | UNIX 秒。上限はサーバーの設定の `fileLockMaxDays`（既定 7 日。FN0902） |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `node_id` | 1 つのファイルにロックは 1 つ |

## 4. 他テーブルとの関係

| カラム | 参照先 | 参照先が削除されたとき |
|---|---|---|
| `node_id` | TBL0301 node | ゴミ箱へ移して `node` の行が消えると、ロックも外れる（行は残るが `node` と結べないので、無いものとして扱う） |
| `user_id` | TBL0101 user | ユーザーを消すと（API0108）、その人のロックも消す。この PC の公開（FN0005）では管理者に移す |

## 5. ライフサイクル

| タイミング | きっかけ（API・バッチの ID） | 内容 |
|---|---|---|
| 作成・更新 | API0320 | ロックした・期限を変えた |
| 削除 | API0321 | ロックを外した（ロックした人・管理者） |
| 削除 | API0108 | ロックした人を消した |
