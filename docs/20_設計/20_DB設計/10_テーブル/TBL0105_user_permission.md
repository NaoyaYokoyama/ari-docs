# TBL0105 利用者の許可

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `user_permission` |
| 概要 | 管理者が利用者に付けた許可（FN0102-BR11）。行が無ければ許可なし。管理者・ローカルモードはこの表によらずすべてできる |
| 定義（正） | `back/src/data/migration/T023_user_permission.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `user_id` | ユーザー ID | TEXT | 不可 | - | 許可を付けた利用者（TBL0101） |
| `permission` | 許可 | TEXT | 不可 | - | `dictionary`（検索の辞書。FN0202-BR10）・`exclusion`（全員の検索の対象外。FN0202-BR17）・`backup`（バックアップを取る・一覧・設定。ダウンロード・復元・削除は除く。FN0901-BR01） |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `user_id`, `permission` | 同じ許可を 2 回付けない |

## 4. 他テーブルとの関係

| カラム | 参照先 | 参照先が削除されたとき |
|---|---|---|
| `user_id` | TBL0101 user | ユーザーを削除したとき（API0108）に消す |

## 5. ライフサイクル

| タイミング | きっかけ（API・バッチの ID） | 内容 |
|---|---|---|
| 作成・削除 | API0111 | 許可を付ける・外す（その人の行を入れ替える） |
| 削除 | API0108 | ユーザーを削除したとき |
