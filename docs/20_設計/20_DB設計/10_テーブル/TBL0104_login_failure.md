# TBL0104 ログインの失敗

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `login_failure` |
| 概要 | ユーザー ID ごとの、続けてログインに失敗した回数とロックの終わり（FN0101-BR12）。無いユーザー ID も記録する |
| 定義（正） | `back/src/data/migration/T011_create_session.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `user_id` | ユーザー ID | TEXT | 不可 | - | ログインで入力されたもの |
| `failures` | 失敗の回数 | INTEGER | 不可 | 0 | 5 回でロックし 0 に戻す |
| `locked_until` | ロックの終わり | TEXT | 不可 | '' | UTC。この日時まではログインできない |
| `updated_at` | 更新日時 | TEXT | 不可 | CURRENT_TIMESTAMP | UTC |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `user_id` | - |

## 4. 他テーブルとの関係

|---|---|---|
| - | - | -（ユーザーを参照しない） |
