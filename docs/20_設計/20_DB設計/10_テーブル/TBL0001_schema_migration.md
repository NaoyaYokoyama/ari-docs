# TBL0001 マイグレーション履歴

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `schema_migration` |
| 概要 | 適用済みのマイグレーションを記録する。起動時に未適用のマイグレーションだけを実行するために使う。 |
| 定義（正） | `back/src/data/migration/T001_create_schema_migration.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `migration_name` | マイグレーション名 | TEXT | 不可 | - | 適用したマイグレーションのファイル名（拡張子なし。例: `T004_create_node`） |
| `applied_at` | 適用日時 | TEXT | 不可 | CURRENT_TIMESTAMP | 適用した日時（UTC） |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `migration_name` | 同じマイグレーションを二重に適用しないため |

## 4. 他テーブルとの関係

| カラム | 参照先 | 参照先が削除されたとき |
|---|---|---|
| - | - | - |

## 5. ライフサイクル

| タイミング | きっかけ（API・バッチの ID） | 内容 |
|---|---|---|
| 作成 | 起動時のマイグレーション処理（`back/src/database/migration.rs`） | 未適用のマイグレーションを実行するたびに 1 行追加する |
| 更新 | - | 更新しない |
| 削除 | - | 削除しない |

## 6. 未決事項

- T001 自体は `schema_migration` が無いときに先に実行され、続けて未適用分としてもう一度実行される（`DROP TABLE IF EXISTS` で作り直されるため結果は同じ）
