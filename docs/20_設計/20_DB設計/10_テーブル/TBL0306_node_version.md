# TBL0306 ファイルの以前の版

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `node_version` |
| 概要 | ari-docs で上書きする前のファイルの中身の記録（FN0301-BR39）。中身は `<データのフォルダ>/versions/<version_id>` に置く。バックアップには含めない |
| 定義（正） | `back/src/data/migration/T025_node_version.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `version_id` | 版 ID | TEXT | 不可 | - | 中身のファイルの名前にも使う |
| `node_id` | ノード ID | TEXT | 不可 | - | どのファイルの版か。ゴミ箱にある間は `trash:<trash_id>:<中の相対パス>` にし、元に戻したら付け直す（FN0302） |
| `name` | 名前 | TEXT | 不可 | - | 残したときのファイルの名前 |
| `size` | 大きさ | INTEGER | 不可 | - | バイト |
| `modified_at` | 中身の更新日時 | INTEGER | 不可 | - | UNIX 秒 |
| `replaced_by` | 上書きした人 | TEXT | 不可 | `''` | ユーザー ID |
| `replaced_at` | 上書きした日時 | INTEGER | 不可 | - | UNIX 秒 |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `version_id` | - |
| INDEX | `node_id`, `replaced_at` | ファイルごとに新しい順に引く |

## 4. 他テーブルとの関係

| カラム | 参照先 | 参照先が削除されたとき |
|---|---|---|
| `node_id` | TBL0301 node | 行き場の無くなった版は、毎時の片付け（BAT0901）で中身と行を消す |

## 5. ライフサイクル

| タイミング | きっかけ（API・バッチの ID） | 内容 |
|---|---|---|
| 作成 | API0304（開いたファイルの戻しも含む）・API0325 | 上書きする前の中身を残す。1 つのファイルで `fileVersionKeep`（既定 10。FN0902）を超えたら古いものから消す |
| 更新 | API0303・API0314 | ゴミ箱へ移した・元に戻したときに `node_id` を付け替える |
| 削除 | API0315・API0316・BAT0901 | 完全に削除した・行き場が無くなった |
