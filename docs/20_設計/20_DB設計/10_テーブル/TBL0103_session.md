# TBL0103 セッション

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `session` |
| 概要 | 共有モードのログインのセッション（FN0101-BR09）。再起動してもログインしたままにするため DB に持つ。復元しても今のものを残す |
| 定義（正） | `back/src/data/migration/T011_create_session.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `session_id` | セッション ID | TEXT | 不可 | - | トークン（UUID v4） |
| `user_id` | ユーザー ID | TEXT | 不可 | - | ログインしたユーザー |
| `created_at` | 作成日時 | TEXT | 不可 | CURRENT_TIMESTAMP | UTC |
| `last_used_at` | 最後に使った日時 | TEXT | 不可 | CURRENT_TIMESTAMP | UTC。1 時間に 1 回更新する。ここから FN0902 の日数（既定 30 日）で切れる |
| `client` | 端末の名前 | TEXT | 不可 | `''` | ログインのときに画面が送った名前（例: `Windows・デスクトップアプリ`）。無ければ User-Agent。200 文字まで（FN0101-BR15。`T015_add_session_client.sql`） |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `session_id` | - |
| INDEX | `user_id` | ユーザーのセッションをまとめて消す・一覧にする（API0705） |
