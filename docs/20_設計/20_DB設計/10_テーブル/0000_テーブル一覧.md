# 0000_テーブル一覧 テーブル一覧

DB は SQLite。場所はデスクトップアプリでは `<作業フォルダ>/.ari-docs/ari.db`（FN0002）、開発時は `back/data/ari.db`（`config.toml` の `database_path`）。マイグレーションは実行ファイルに埋め込み、起動時に未適用のものを実行する。構造の正は `back/src/data/migration/` の SQL。外部キー制約は使っていない。

| ID | 物理名 | 論理名 | 概要 | マイグレーション |
|---|---|---|---|---|
| [TBL0001](TBL0001_schema_migration.md) | `schema_migration` | マイグレーション履歴 | 適用済みのマイグレーションを記録する。起動時に未適用のマイグレーションだけを実行するために使う。 | `T001_create_schema_migration.sql` |
| [TBL0002](TBL0002_system_setting.md) | `system_setting` | システム設定 | 管理者が決める、全員に効く設定（FN0901・FN0902）。 | `T010_create_trash_backup.sql` |
| [TBL0101](TBL0101_user.md) | `user` | ユーザー | ユーザー。ローカルモードではユーザー ID `local` の 1 行だけを使う（FN0101）。 | `T002_create_user.sql` |
| [TBL0102](TBL0102_role.md) | `role` | ロール | ユーザーの権限を表す想定のテーブル。現行のコードからは使っていない（権限は `user.role_id`。FN0102）。 | `T003_create_role.sql` |
