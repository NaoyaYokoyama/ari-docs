# TBL0102 ロール

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `role` |
| 概要 | ユーザーの権限を表す想定のテーブル。現行のコードからは使っていない。共有モードの権限は `user.role_id` で持つ（FN0102 の決定事項）。 |
| 定義（正） | `back/src/data/migration/T003_create_role.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `user_id` | ユーザー ID | TEXT | 不可 | - | 主キー。ロールの ID として使う想定か、ユーザー ID か不明 |
| `role` | ロール名 | TEXT | 不可 | - | ロール名（一意） |
| `folder_permission` | フォルダ権限 | INTEGER | 不可 | 2 | フォルダ機能の権限。値の意味は未定 |
| `wiki_permission` | Wiki 権限 | INTEGER | 不可 | 0 | Wiki 機能の権限。値の意味は未定 |
| `manager_permission` | 管理権限 | INTEGER | 不可 | 0 | 管理機能の権限。値の意味は未定 |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `user_id` | - |
| UK | `role` | ロール名の重複を防ぐ |
