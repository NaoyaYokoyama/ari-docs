# TBL0202 ファイルと単語の対応

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `node_keyword` |
| 概要 | どのファイル（ノード）にどの単語（TBL0201）があるか（FN0202）。`WITHOUT ROWID` |
| 定義（正） | `back/src/data/migration/T009_create_search_index.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `keyword_id` | 単語 ID | INTEGER | 不可 | - | TBL0201 の `keyword_id` |
| `node_id` | ノード ID | TEXT | 不可 | - | TBL0301 の `node_id` |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `keyword_id`, `node_id` | 単語からファイルを引く（検索）。1 つのファイルに同じ単語は 1 行 |
| INDEX | `node_id` | ファイルを取り込み直すときに、そのファイルの行を消す |

## 4. 他テーブルとの関係

| カラム | 参照先 | 参照先が削除されたとき |
|---|---|---|
| `keyword_id` | TBL0201 keyword | -（使われている単語は消さない） |
| `node_id` | TBL0301 node | 行は残る（次の取り込みでファイルが無ければ消す） |

## 5. ライフサイクル

| タイミング | きっかけ（API・バッチの ID） | 内容 |
|---|---|---|
| 作成 | BAT0302 | ファイルを取り込むたびに、そのファイルの行を消してから登録し直す |
| 削除 | BAT0302 | ファイルが消えた・対象外になった・大きすぎる・読めないときに消す |
