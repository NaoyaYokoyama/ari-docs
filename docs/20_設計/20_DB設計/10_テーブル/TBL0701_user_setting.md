# TBL0701 ユーザー設定

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `user_setting` |
| 概要 | ユーザーごとの設定（FN0701）。1 ユーザー 1 行。設定を増やすときは列を追加する |
| 定義（正） | `back/src/data/migration/T008_create_user_setting.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `user_id` | ユーザー ID | TEXT | 不可 | - | `local` |
| `docs_root` | Docs の初期フォルダ | TEXT | 不可 | '' | 正規化した絶対パス（FN0701-BR02）。空文字なら未設定で、リポジトリの `docs/` を表示する |
| `updated_at` | 更新日時 | TEXT | 不可 | CURRENT_TIMESTAMP | 作成・更新した日時（UTC） |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `user_id` | 1 ユーザー 1 行にする |
