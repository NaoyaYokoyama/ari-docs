# TBL0301 ノード

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `node` |
| 概要 | `folder/` 以下のノード（ファイル・フォルダ）に ID を割り当てる。お気に入りなどから参照する。ノードの実体はファイルシステム。 |
| 定義（正） | `back/src/data/migration/T004_create_node.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `node_id` | ノード ID | TEXT | 不可 | - | `nd_` で始まる ID |
| `path` | パス | TEXT | 不可 | - | `folder/` からの相対パス。先頭に `/` を付けない（FN0301-BR01）。同じパスの行は 1 つだけにする |
| `description` | 説明 | TEXT | 不可 | '' | ノードの説明。現行は入力手段が無い |
| `status` | 状態 | INTEGER | 不可 | 0 | 作業状態（作業中・レビュー中・完了・保留を想定）。現行は入力手段が無い |
| `updated_by` | 更新者 | TEXT | 不可 | '' | 最後に更新したユーザー。現行は記録していない（共有モード用） |
| `updated_at` | 更新日時 | TEXT | 不可 | CURRENT_TIMESTAMP | 行の作成日時（UTC） |
| `modified_at` | ファイルの更新日時 | INTEGER | 不可 | 0 | ファイル・フォルダの更新日時（UNIX 時間の秒）。BAT0301 が記録する。0 は未取得（`T012_add_node_modified_at.sql`。FN0201-BR07） |

|---|---|---|
| PK | `node_id` | - |

## 6. 未決事項

- `path` に一意制約が無い（同じパスの行が重複しうる）
- ノードの移動に合わせた行の更新（削除はノード削除 API で行を消す。FN0301-BR15）
- `status` の値と画面表示（`FolderStatus`：working・review・completed・hold）の対応
