# TBL0301 ノード

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `node` |
| 概要 | `folder/` 以下のノード（ファイル・フォルダ）に ID を割り当てる。お気に入りなどから参照する。ノードの実体はファイルシステム。 |
| 定義（正） | `back/src/data/migration/T004_create_node.sql`・`T019_add_node_path_unique.sql`・`T022_node_description.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `node_id` | ノード ID | TEXT | 不可 | - | `nd_` で始まる ID |
| `path` | パス | TEXT | 不可 | - | `folder/` からの相対パス。先頭に `/` を付けない（FN0301-BR01）。同じパスの行は 1 つだけにする |
| `description` | 説明 | TEXT | 不可 | '' | ファイル・フォルダの説明（200 文字まで。FN0301-BR33）。詳細のダイアログで書く（API0319）。状態の列 `status` は T022 で消した |
| `updated_by` | 更新者 | TEXT | 不可 | '' | 最後に ari-docs で作成・アップロード・名前の変更・移動・コピーしたユーザー ID（入れた・消したもののフォルダも。FN0301-BR34）。そのときの更新日時を `modified_at` にそろえて残し、見張り・同期が違う更新日時を見たら（ari-docs の外で変わったら）空に戻す |
| `updated_at` | 更新日時 | TEXT | 不可 | CURRENT_TIMESTAMP | 行の作成日時（UTC） |
| `modified_at` | ファイルの更新日時 | INTEGER | 不可 | 0 | ファイル・フォルダの更新日時（UNIX 時間の秒）。BAT0301 が記録する。0 は未取得（`T012_add_node_modified_at.sql`。FN0201-BR07） |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `node_id` | - |
| UNIQUE | `path`（`idx_node_path`。T019） | 同じパスの行を 2 つ作らない（ファイルの見張りと同期が同時に登録しても 1 行。T019 は重なっていた行を先の行にまとめ、お気に入りを付け替えた） |
