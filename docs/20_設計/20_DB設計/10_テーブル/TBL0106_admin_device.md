# TBL0106 管理者のPC

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `admin_device` |
| 概要 | 管理者の操作をしてよい PC（FN0102-BR12）。デスクトップアプリが場所ごとに作った鍵を `X-Ari-Device` で送り、ここには SHA-256 だけを残す。登録していない PC から使う管理者は、利用者として扱う |
| 定義（正） | `back/src/data/migration/T023_user_permission.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `device_id` | PC の ID | TEXT | 不可 | - | `ad_` で始まる ID |
| `user_id` | ユーザー ID | TEXT | 不可 | - | 管理者（TBL0101） |
| `key_hash` | 鍵の SHA-256 | TEXT | 不可 | - | 16 進数 64 文字。鍵そのものは残さない |
| `name` | 端末の名前 | TEXT | 不可 | '' | 例: Windows・デスクトップアプリ（200 文字まで） |
| `created_at` | 登録した日時 | TEXT | 不可 | 今（UTC） | - |
| `last_used_at` | 最後に使った日時 | TEXT | 不可 | 今（UTC） | 管理者がこの PC から API を使ったときに書き換える（前に書いてから 1 分たったときだけ） |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `device_id` | - |
| UNIQUE | `user_id`, `key_hash` | 同じ PC を 2 回登録しない（もう一度登録したら名前だけ書き換える） |

## 4. 他テーブルとの関係

| カラム | 参照先 | 参照先が削除されたとき |
|---|---|---|
| `user_id` | TBL0101 user | ユーザーを削除したとき（API0108）・利用者にしたとき（API0110）に消す |

## 5. ライフサイクル

| タイミング | きっかけ（API・バッチの ID） | 内容 |
|---|---|---|
| 作成 | API0105 | 最初の管理者を登録したとき（登録した PC） |
| 作成 | API0102 | サーバーの PC の中からログインした管理者が、まだ 1 台も登録していないとき（この PC の公開 FN0005 のあとなど） |
| 作成 | API0114 | コードを入れて登録したとき |
| 更新 | （すべての API） | 管理者が使ったときに `last_used_at`（1 分に 1 回まで） |
| 削除 | API0115・API0108・API0110 | 外したとき・ユーザーを削除したとき・利用者にしたとき |
