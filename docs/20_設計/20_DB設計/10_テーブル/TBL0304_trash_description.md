# TBL0304 ゴミ箱の説明

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `trash_description` |
| 概要 | ゴミ箱へ移したファイル・フォルダ（とその中のもの）の説明（FN0301-BR33）。元に戻したら、戻した場所の `node` に入れ直して消す。バックアップから復元しても今の中身を残す（FN0901-BR06） |
| 定義（正） | `back/src/data/migration/T022_node_description.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `trash_id` | ゴミ箱 ID | TEXT | 不可 | - | TBL0302 の `trash_id` |
| `path` | 相対パス | TEXT | 不可 | '' | ゴミ箱へ移したものからの相対パス（そのものなら空、フォルダの中のものは `a/b.txt`） |
| `description` | 説明 | TEXT | 不可 | - | 移す前の `node.description`（空のものは控えない） |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `trash_id`, `path` | 同じものを 2 回控えない |

## 4. 他テーブルとの関係

| カラム | 参照先 | 参照先が削除されたとき |
|---|---|---|
| `trash_id` | TBL0302 trash | ゴミ箱から消したとき（元に戻す・完全に削除・空にする・保存期間・容量）に一緒に消す |

## 5. ライフサイクル

| タイミング | きっかけ（API・バッチの ID） | 内容 |
|---|---|---|
| 作成 | API0303 | ゴミ箱へ移したとき（`node` の行を消す前に控える） |
| 削除 | API0314 | 元に戻したとき（説明を入れ直してから） |
| 削除 | API0315・API0316・BAT0901 | 完全に削除・空にする・保存期間や容量を過ぎたとき |
