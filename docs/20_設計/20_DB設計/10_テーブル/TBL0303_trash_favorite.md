# TBL0303 ゴミ箱のお気に入り

## 1. 概要

| 項目 | 値 |
|---|---|
| 物理名 | `trash_favorite` |
| 概要 | ゴミ箱へ移したファイル・フォルダ（とその中のもの）を、お気に入りにしていた人（FN0302-BR08）。元に戻したら、戻した場所でお気に入りに入れ直して消す。バックアップから復元しても今の中身を残す（FN0901-BR06） |
| 定義（正） | `back/src/data/migration/T020_create_trash_favorite.sql` |

## 2. カラム

| 物理名 | 論理名 | 型 | NULL | 既定値 | 意味・値のルール |
|---|---|---|---|---|---|
| `trash_id` | ゴミ箱 ID | TEXT | 不可 | - | TBL0302 の `trash_id` |
| `user_id` | ユーザー ID | TEXT | 不可 | - | お気に入りにしていた人 |
| `path` | 相対パス | TEXT | 不可 | '' | ゴミ箱へ移したものからの相対パス（そのものなら空、フォルダの中のものは `a/b.txt`） |

## 3. キー・インデックス

| 種類 | カラム | 目的 |
|---|---|---|
| PK | `trash_id`, `user_id`, `path` | 同じものを 2 回控えない |

## 4. 他テーブルとの関係

| カラム | 参照先 | 参照先が削除されたとき |
|---|---|---|
| `trash_id` | TBL0302 trash | ゴミ箱から消したとき（元に戻す・完全に削除・空にする・保存期間）に一緒に消す |
| `user_id` | TBL0101 user | ユーザーを削除したときに消す |

## 5. ライフサイクル

| タイミング | きっかけ（API・バッチの ID） | 内容 |
|---|---|---|
| 作成 | API0303 | ゴミ箱へ移したとき（お気に入りを消す前に控える） |
| 削除 | API0314 | 元に戻したとき（お気に入りに入れ直してから） |
| 削除 | API0315・API0316・BAT0901 | 完全に削除・空にする・保存期間を過ぎたとき |
