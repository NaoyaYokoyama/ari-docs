# 0020_非機能要件 非機能要件

現行実装から読み取れる内容を書く。決まっていない項目は「未定」とし、9 章の未決事項に挙げる。

## 1. 性能

| 項目 | 内容 |
|---|---|
| 規模 | ローカルモードは 1 人。共有モードは当面 20 人・1 万ファイルまで（2026-11-23 のユーザーの判断。RQ0001） |
| 応答時間（1 万ファイルで確かめた値） | 開発用のビルド（最適化なし）で、Folder の一覧（100 件のフォルダ）約 0.005 秒、ホームの検索（名前と中身）0.01〜0.06 秒、探して開く約 0.08 秒、最近の更新約 0.004 秒（2026-11-23） |
| バッチ処理時間（1 万ファイル） | ノード同期（BAT0301）の起動時の全体の同期は数秒。中身の取り込み（BAT0302）は最初の 1 回（テキスト 1 万件・40 MB）が約 2 分、そのあと何も変わらないときは CPU が 1 分あたり約 0.3 秒（開発用のビルド）。Excel・PDF・文字認識の要るファイルは 1 件ずつもっと時間がかかる（FN0202-BR15） |
| アップロード | 1 回の合計はサーバーの設定の上限まで（既定 1 GB、10 GB まで。FN0902-BR07）。メモリに読まずに受け取る（FN0301-BR29） |
| プレビュー | 30 MB まで。テキスト・CSV・Markdown は先頭 1 MB だけ（FN0301-BR30） |

## 3. セキュリティ

| 項目 | 内容 |
|---|---|
| 認証方式 | ローカルモードはなし（ユーザー `local`。`127.0.0.1` だけで待ち受ける）。共有モードはユーザー ID とパスワード（Argon2）、セッション 30 日・5 回の失敗で 15 分ロック（サーバーの設定で変えられる。FN0101・FN0902） |
| 最初の管理者 | ユーザーがいない共有サーバーは、ほかの PC からの登録に登録用のコード（サーバーの起動画面・`setup-code.txt`）を求める（FN0102-BR02） |
| 認可方式 | 管理者・利用者（`user.role_id`）と、管理者が利用者に付ける許可（検索の辞書・全員の検索の対象外・バックアップ。FN0102-BR11）。管理者の操作は登録した PC（管理者の PC。鍵の SHA-256 で見分ける）からだけ（FN0102-BR12） |
| 通信暗号化 | 共有モードは設定で HTTPS（FN0101-BR14）。この PC の公開（FN0005）は HTTP（社内のネットワークだけで使う） |
| 保存データ暗号化 | なし |
| CORS | デスクトップアプリの画面（`tauri://localhost`・`http://tauri.localhost`）と開発用（`http://localhost:5173`）だけを許可 |
| ファイルアクセスの範囲 | ノードは `folder/` 以下、Markdown ビューアは指定フォルダ以下に限る（FN0301、FN0801） |
| 配布物の署名 | アプリの更新は署名で確かめる（FN0904-BR06）。exe・インストーラーのコード署名は当面なし（OP0002） |
| ログ | エラーは `<データのフォルダ>/logs/error.log`（OP0009） |

## 4. バックアップ・リストア

| 項目 | 内容 |
|---|---|
| バックアップ対象 | DB の写しと `folder/` を 1 つの ZIP にする（FN0901） |
| 取得タイミング | 設定で、しない・毎日・毎週・毎月と時刻を選ぶ。手動でも取れる（FN0901-BR02・BR03） |
| 保存期間 | 設定の日数（FN0901）。ゴミ箱は保存期間と容量の上限（FN0302-BR09） |
| リストア手順 | 設定の「バックアップ」から復元する（今の状態を先にバックアップする。FN0901-BR05。OP0008） |

## 7. 運用・保守

| 項目 | 内容 |
|---|---|
| リリース方法 | `cargo tauri build` で作る Windows の NSIS インストーラーと Linux の AppImage（OP0002） |
| 設定 | デスクトップアプリ: exe と同じフォルダの `config.toml`（作業フォルダのみ。FN0002）。開発時（デバッグビルドのデスクトップアプリを含む）: `back/config.toml`（OP0003） |
| DB の作成・更新 | 起動時にマイグレーションを自動実行する（SQL は実行ファイルに埋め込み。TBL0001）。ユーザー `local` も自動で作る |
| 開発時の検証 | 作業終了時に型チェック・lint・ビルドを自動実行する（`.claude/hooks/verify.sh`） |
