# 0020_非機能要件 非機能要件

現行実装から読み取れる内容を書く。共有モードの非機能要件はまだ決まっていない項目が多い（RQ0001）。決まっていない項目は「未定」とし、9 章の未決事項に挙げる。

## 1. 性能

| 項目 | 内容 |
|---|---|
| 同時接続数 | 1（利用者 1 人） |
| 応答時間 | 未定 |
| バッチ処理時間 | ノード同期（BAT0301）は毎分実行のため、1 分以内に終わること |
| データ件数 | 一覧系 API は最大 30 件で打ち切る（Note・Wiki・お気に入り） |

## 2. 可用性

| 項目 | 内容 |
|---|---|
| 稼働時間 | デスクトップアプリの起動中のみ（バックエンドも同じプロセスで動く） |
| 計画停止 | 未定 |
| 冗長化 | なし（バックエンド 1 プロセス、SQLite 1 ファイル） |
| 障害時の復旧目標（RTO） | 未定 |
| データ復旧目標（RPO） | 未定 |

## 3. セキュリティ

| 項目 | 内容 |
|---|---|
| 認証方式 | なし（ユーザー `local` として処理。FN0101） |
| 認可方式 | なし（利用者 1 人） |
| 通信暗号化 | なし（HTTP。バックエンドは `127.0.0.1:8080` で待ち受け、同じ PC からのみ接続できる） |
| 保存データ暗号化 | なし |
| CORS | `http://localhost:5173` からのみ許可 |
| ファイルアクセスの範囲 | ノードは `folder/` 以下、Markdown ビューアは指定フォルダ以下に限る（FN0301、FN0801） |
| アクセスログ | 標準出力に `メソッド パス` を出す |

## 4. バックアップ・リストア

| 項目 | 内容 |
|---|---|
| バックアップ対象 | 作業フォルダ（`folder/` と `.ari-docs/`）。フォルダごとコピーすれば移せる。バックアップの方法は未定 |
| 取得タイミング | 未定 |
| 保存期間 | 未定 |
| リストア手順 | 未定 |

## 5. ログ

| 項目 | 内容 |
|---|---|
| アプリケーションログ | 標準出力（`println!`） |
| アクセスログ | 標準出力（全リクエストの `メソッド パス`） |
| 監査ログ | なし |
| エラーログ | 標準エラー（`eprintln!`） |
| 保存期間 | なし（ファイルに保存していない） |

## 6. 監視

| 項目 | 内容 |
|---|---|
| 死活監視 | なし（BAT0001 はログを出すだけ） |
| リソース監視 | なし |
| ログ監視 | なし |
| 通知方法 | なし |

## 7. 運用・保守

| 項目 | 内容 |
|---|---|
| リリース方法 | `cargo tauri build` で作る Windows の NSIS インストーラーと Linux の AppImage（OP0002） |
| 設定 | デスクトップアプリ: exe と同じフォルダの `config.toml`（作業フォルダのみ。FN0002）。開発時（デバッグビルドのデスクトップアプリを含む）: `back/config.toml`（OP0003） |
| DB の作成・更新 | 起動時にマイグレーションを自動実行する（SQL は実行ファイルに埋め込み。TBL0001）。ユーザー `local` も自動で作る |
| 開発時の検証 | 作業終了時に型チェック・lint・ビルドを自動実行する（`.claude/hooks/verify.sh`） |

## 8. 制約事項

| 項目 | 内容 |
|---|---|
| OS | Linux・Windows・macOS（Tauri の対応範囲）。未検証の OS あり |
| ミドルウェア | なし（SQLite を同梱） |
| ブラウザ | 未定（開発は Chromium 系で確認） |
| 開発言語 | Rust（edition 2024）、TypeScript 6、React 19 |
| 文字コード | UTF-8 |
| 時刻 | DB の日時は UTC（SQLite の `CURRENT_TIMESTAMP`）。ノードの更新日時はローカル時刻 |

## 9. 未決事項

- 共有モードの非機能要件（同時接続数・認証・通信暗号化・パスワードポリシー）は RQ0001 で検討する
- DB のバックアップ方法
- ログのファイル保存と保存期間
- DB の日時（UTC）を画面でローカル時刻に変換するか
