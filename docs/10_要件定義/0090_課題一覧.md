# 0090_課題一覧 課題一覧

要件一覧（[0000_要件一覧](0000_要件一覧.md)）の各要件の、要求元・優先度・状態を管理する。設計書のうち、管理情報を書くのはこのファイルだけとする。

<details>
<summary>入力ルール（優先度・状態・要求元）</summary>

**優先度**

- 急：障害対応など、通常業務より優先して対応する
- 高：通常業務内の最優先案件
- 中：優先的に対応する
- 低：時間があれば対応する

**状態**

- 未着手：作業開始前
- 要件定義：要件定義中
- 設計：設計作業中
- 製造：開発作業中
- UT：単体テスト
- IT：結合テスト
- ST：システムテスト
- UAT：ユーザー受入テスト
- リリース待：開発・テスト完了、リリース待ち
- 完了：リリース済み
- 保留：一時停止

**その他**

- ID は要件一覧の ID（RQ0000）を使います。
- 要求元には、要望を提出した部署、組織、個人を記載します。

</details>
