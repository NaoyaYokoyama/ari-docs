# 0030_対応するファイル 対応するファイル

ファイル（Folder のノード）について、どの形式に何ができるかの一覧。ファイル名・フォルダ名での検索（FN0201）は、すべてのファイルが対象になる。

利用者は設定画面の「対応するファイル」（SCR0701）で同じ一覧を見られる。画面の一覧は実装の定義をそのまま表示するので、形式を増やしたときは、この文書も合わせて直す。

## 1. 中身で検索できるファイル（FN0202-BR02）

| 種類 | 拡張子 |
|---|---|
| Excel | `xlsx` `xlsm` `xlsb` `xls`（セル・シート名。`xlsx` `xlsm` `xlsb` は図形・テキストボックス・コメントも） |
| OpenDocument の表計算 | `ods` |
| Word | `docx` `docm` |
| PowerPoint | `pptx` `pptm` |
| PDF | `pdf` |
| テキスト | `txt` `md` `markdown` `csv` `tsv` `log` `json` `xml` `html` `htm` `yml` `yaml` `toml` `ini` `cfg` `conf` `properties` `sql` `sh` `bat` `cmd` `ps1` `js` `jsx` `ts` `tsx` `py` `java` `kt` `c` `h` `cpp` `hpp` `cs` `vb` `go` `rs` `rb` `php` `css` `scss` `vue` `tex` `rtf` |

- 100 MB を超えるファイルは取り込まない。取り出した文字は 500 万文字までを使う（FN0202-BR04）
- 実装は `back/src/search/extract.rs` の `FORMAT_GROUPS`。画面には API0208 で返す

### 1.1 画像の中の文字（文字認識。FN0202-BR14、FN0202-BR15）

アプリに組み込んだ文字認識（PaddleOCR PP-OCRv6 small）で読む。外部のソフトは要らない。モデル（約 31 MB）は `models` フォルダに置き、無ければ文字認識だけを飛ばす。使えるかは設定画面の「対応するファイル」に出る。

| 対象 | 内容 |
|---|---|
| PDF の文字の無いページ | スキャンした書類・白黒の複合機の形式（CCITT・JBIG2）・JPEG 2000・文字を図形にしたもの。ページを画像に描いて読む。ページ数の上限は無い（1 ページ約 1 秒） |
| PDF の画像のあるページ | 文字のあるページでも、画面の写しなどの大きな画像（200×60 画素以上）があれば、ページを画像に描いて読む |
| Excel・Word・PowerPoint に貼り付けた画像 | `xlsx` `xlsm` `xlsb` `docx` `docm` `pptx` `pptm` の中の `png` `jpg` `bmp` `gif` `tif` `webp`（EMF・WMF は対象外） |
| 画像ファイル | `png` `jpg` `jpeg` `bmp` `gif` `tif` `tiff` `webp` |

- 実装は `back/src/search/ocr.rs`（文字認識）と `back/src/search/pdf_ocr.rs`（PDF のページを描く・貼り付けた画像を取り出す）。モデルの取得は `back/build_models.rs`

## 2. プレビューできるファイル（FN0301-BR30）

| 種類 | 拡張子 | 表示 |
|---|---|---|
| 画像 | `png` `jpg` `jpeg` `gif` `bmp` `webp` `svg` | 画像 |
| PDF | `pdf` | ブラウザの PDF 表示 |
| Markdown | `md` `markdown` | 見出し・表などを整えて表示 |
| CSV・TSV | `csv` `tsv` | 表（先頭 500 行まで） |
| テキスト | `txt` `log` `json` `xml` `html` `htm` `yml` `yaml` `toml` `ini` `cfg` `conf` `properties` `sql` `sh` `bat` `cmd` `ps1` `js` `jsx` `ts` `tsx` `py` `java` `kt` `c` `h` `cpp` `hpp` `cs` `vb` `go` `rs` `rb` `php` `css` `scss` `vue` | 文字（UTF-8、読めなければ Shift_JIS） |

- 30 MB を超えるファイルはプレビューしない。ほかの形式と同じく「開く」「ダウンロード」を案内する
- 実装は `front/src/lib/previewFormats.ts` の `PREVIEW_FORMATS`

## 3. 対応していないもの

| 対象 | 理由 |
|---|---|
| 古い形式の Word・PowerPoint（`.doc` `.ppt`）、一太郎（`.jtd`）、Visio の中身の検索 | 未対応（FN0202 の未決事項） |
| 古い形式の Excel（`.xls`）と OpenDocument の表計算（`.ods`）の、図形・コメント・貼り付けた画像 | 未対応（セルとシート名だけ読む） |
| 手書きの文字・とても小さい文字 | 文字認識で読めないことがあるため |
| パスワードのかかった PDF | 開けないため |
| Office に貼り付けた EMF・WMF 形式の図 | 画像として読めないため |
| Excel・Word・PowerPoint のプレビュー | ブラウザでは表示できないため。「開く」で PC のアプリで開く |
