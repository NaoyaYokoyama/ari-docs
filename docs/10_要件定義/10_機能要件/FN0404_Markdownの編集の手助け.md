# FN0404 Markdown の編集の手助け

## 1. 概要

Note・Wiki の本文（Markdown）を書きやすくする。書式のボタンとキー、表の挿入と整形、画像の貼り付けを用意する。普通の本文と、Vim モードの本文のエディタ（FN0702-BR07）で同じものを使う。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| 本文に貼り付けた画像（TBL0405） | Note の画像は貼り付けた本人、Wiki の画像は全員 | 縮小した画像。本文には `![説明](/api/content-image/{画像 ID})` と書く |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| 書式のボタン・キー・表 | Note は本人、Wiki は全員 |
| 画像を貼り付ける | Note は本人、Wiki は全員 |
| 画像を見る | Wiki の画像は全員。Note の画像は貼り付けた本人と、その画像を使っている Wiki を読める人（Note から Wiki へ写したとき） |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0404-BR01 | 「編集」「分割」のとき、本文の上に書式のボタンを出す（見出し・太字・斜体・取り消し線／リンク・コード・コードブロック・引用・区切り線・画像／箇条書き・番号付き・チェックリスト／表を入れる・表を整える）。プレビューでは出さない。各ボタンには一言の説明を出す（設定で消せる。FN0701-BR11）。太字などは選んでいる文字を囲み、囲んであれば外す。選んでいなければ見本の文字を入れて選ぶ。見出しは押すたびに `#`→`##`→`###`→なし。箇条書きなどは選んでいる行すべてに付け、すべてに付いていれば外す | 記法を覚えていなくても書けるようにするため |
| FN0404-BR02 | 画像は、貼り付け（Ctrl+V）・本文へのドロップ・「画像」のボタンで入れる。画面で長い辺を 1920 画素までに縮小して WebP（作れない環境では JPEG）にし、元のほうが小さければ元のまま送る。GIF はアニメーションを残すため縮小しない。受け取れるのは PNG・JPEG・GIF・WebP（BMP は画面で変換する）。1 枚 10 MB まで。SVG は受け取らない（中にスクリプトを書けるため）。文字も一緒に入っている貼り付け（Excel のセルの写しなど）は文字を貼る。入れたら元と縮小後の大きさを知らせる | サーバーの容量を使いすぎないため（ユーザーの依頼）。Excel のセルを写すと画像も一緒に入るため |
| FN0404-BR03 | 「表を入れる」は 3 列 2 行の表をひとかたまり（前後に空の行）で入れ、1 つ目の見出しを選ぶ。「表を整える」はカーソルのある表の `\|` の位置をそろえる（日本語は半角 2 文字分の幅。区切りの行（`---`）の左・中央・右寄せを保つ。区切りの行が無ければ足す。列の足りない行は空のセルで埋める）。本文の字体は等幅にして、整えた表が縦にそろって見えるようにする | 表を書きやすく、読みやすくするため |
| FN0404-BR04 | キー: 太字 Ctrl+B、斜体 Ctrl+I、取り消し線 Ctrl+Shift+X、コード Ctrl+E、リンク Ctrl+K、表を整える Alt+Shift+F。本文を書いているときだけ。Vim のエディタは挿入モードのときだけ（ノーマルモードの `<C-b>` などと重なるため） | よく使う書式をキーボードだけで付けられるようにするため |
| FN0404-BR05 | 画像は DB に入れる（バックアップ・復元で本文と一緒に扱えるように）。本文・変更履歴のどこからも使われなくなった画像は、貼り付けてから 1 日たったら消す（BAT0901。毎時） | 貼り付けて保存しなかった画像・消した画像で容量を使い続けないため。貼り付けてから保存するまでの間に消さないため |

## 5. 処理の流れ

1. 書式のボタン・キーで、選んでいる範囲から書き換える範囲を求めて本文を書き換える（元に戻すで戻せる）。
2. 画像は、画面で縮小して API0413 で送り、返った URL で `![説明](URL)` をカーソルの所に入れる（行の途中なら改行し、表のすぐ下なら空の行を挟む）。
3. 表示（プレビュー・分割・変更履歴）では、画像を API0414 で読み込んで出す（ログインのトークンを送るため）。読めなければ「［画像を表示できません］」。

## 6. メッセージ

| ID | 表示する場面 | 文言 |
|---|---|---|
| MSG0423 | 画像を送っている | 画像を縮小して保存しています… |

| MSG0426 | 画像以外のファイル | 貼り付けられる画像は PNG・JPEG・GIF・WebP・BMP です |
| MSG0427 | 表の外で「表を整える」 | 表を整えるには、カーソルを表の中に置いてください |

## 8. 決定事項

| 日付 | 内容 | 理由 |
|---|---|---|
| 2026-11-08 | 書式のボタン・キー、表の挿入と整形、画像の貼り付けを入れる。箇条書きの続き（Enter で次の行にも記号）は入れない | ユーザーの依頼（選んだもの） |
| 2026-11-08 | 画像は画面で縮小（長い辺 1920 画素・WebP）してから送る | ユーザーの依頼（「そのままだとサーバー容量が大変」） |
| 2026-11-08 | 書式のボタンはアプリで作り、普通の本文と Vim のエディタで同じものにする（エディタの部品のボタンは使わない） | Vim のエディタにはボタンが無かったため |
