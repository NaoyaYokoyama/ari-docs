# FN0302 ゴミ箱

## 1. 概要

フォルダ画面で削除したファイル・フォルダは、すぐに消さずにゴミ箱へ移す。ゴミ箱から元の場所に戻せる。完全に削除する・空にすることもでき、保存期間を過ぎたものは自動で消す。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| ゴミ箱の実体 | ファイルシステム | `<データのフォルダ>/trash/<trash_id>/<元の名前>`。データのフォルダは DB のあるフォルダ（デスクトップアプリは `<作業フォルダ>/.ari-docs/`） |
| ゴミ箱（TBL0302） | 全員 | 元の場所・名前・種類・サイズ・削除した人・日時 |

## 3. 権限

| 操作 | 利用者 | 管理者 |
|---|---|---|
| 削除（ゴミ箱へ移す）・一覧・元に戻す | ○ | ○ |
| 完全に削除・空にする | ○（ローカルモード）/ ×（共有モード） | ○ |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0302-BR01 | フォルダ画面の削除（API0303）は、ファイル・フォルダをゴミ箱へ移す。確認は出さず（設定の「削除の前に確かめる」をオンにした PC では確かめる。FN0701-BR11）、移したことと「ゴミ箱から元に戻せます」を知らせる。`node` の行とお気に入りは消す（FN0301-BR15） | 誤って消しても戻せるようにするため。Windows のごみ箱と同じく、確認を出さずに素早く消せるようにするため |
| FN0302-BR02 | ゴミ箱はフォルダ画面のツリーの下の「ゴミ箱」で開く。名前・元の場所・削除した日時・削除した人・サイズを、新しく削除したものから並べる。クリック・Ctrl+クリックで選び、右クリックでメニュー（元に戻す・完全に削除）を出す | - |
| FN0302-BR03 | 元に戻す（ダブルクリックでも可）と、元の場所に戻す。元のフォルダが無ければ作り、同じ名前があれば「名前 (2)」などにする。1 件だけ戻したときは、そのフォルダを開いて選ぶ | - |
| FN0302-BR04 | 完全に削除・ゴミ箱を空にするときは確認する（元には戻せない）。共有モードでは管理者だけができる（それ以外は 403） | 共有のファイルを取り返しのつかない形で消せる人を限るため |
| FN0302-BR05 | 保存期間（既定 30 日。管理者がバックアップの設定で変えられる。FN0901-BR02）を過ぎたものは、定期の処理（BAT0901）で完全に削除する | 容量を使い続けないため |
| FN0302-BR06 | 元に戻したものは、次のノード同期（BAT0301）で `node` テーブルに登録し直す（お気に入りは戻らない） | - |
| FN0302-BR07 | ゴミ箱の実体と記録はバックアップに含めない。バックアップから復元しても、ゴミ箱の中身はそのまま（FN0901-BR06） | ゴミ箱の実体がバックアップの外にあるため |

## 5. 処理の流れ

1. フォルダ画面で削除（Delete・右クリックの「ゴミ箱に移動」など）すると API0303 でゴミ箱へ移す。
2. 「ゴミ箱」を開くと API0313 で一覧を表示する。
3. 「元に戻す」で API0314、「完全に削除」で API0315、「ゴミ箱を空にする」で API0316 を呼ぶ。

## 6. メッセージ

| ID | 表示する場面 | 文言 |
|---|---|---|
| MSG0321 | ゴミ箱へ移した | 「{名前}」（2 件以上は {件数} 件）をゴミ箱に移動しました（ゴミ箱から元に戻せます） |
| MSG0322 | 元に戻した | {件数} 件を元の場所に戻しました |
| MSG0323 | 完全に削除の確認 | {件数} 件を完全に削除しますか？元には戻せません |
| MSG0324 | 空にするの確認 | ゴミ箱を空にしますか？中のものはすべて完全に削除され、元には戻せません |
