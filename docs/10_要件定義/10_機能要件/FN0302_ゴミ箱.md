# FN0302 ゴミ箱

## 1. 概要

フォルダ画面で削除したファイル・フォルダは、すぐに消さずにゴミ箱へ移す。ゴミ箱から元の場所に戻せる。完全に削除する・空にすることもでき、保存期間を過ぎたものは自動で消す。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| ゴミ箱の実体 | ファイルシステム | `<データのフォルダ>/trash/<trash_id>/<元の名前>`。データのフォルダは DB のあるフォルダ（デスクトップアプリは `<作業フォルダ>/.ari-docs/`） |
| ゴミ箱（TBL0302） | 全員 | 元の場所・名前・種類・サイズ・削除した人・日時 |

## 3. 権限

| 操作 | 利用者 | 管理者 |
|---|---|---|
| 削除（ゴミ箱へ移す）・一覧・元に戻す | ○ | ○ |
| 完全に削除・空にする | ○ | ○ |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0302-BR01 | フォルダ画面の削除（API0303）は、ファイル・フォルダをゴミ箱へ移す。確認は出さず（設定の「削除の前に確かめる」をオンにした PC では確かめる。FN0701-BR11）、移したことと「ゴミ箱から元に戻せます」を知らせる。`node` の行とお気に入りは消す（FN0301-BR15） | 誤って消しても戻せるようにするため。Windows のごみ箱と同じく、確認を出さずに素早く消せるようにするため |
| FN0302-BR02 | ゴミ箱はフォルダ画面のツリーの下の「ゴミ箱」で開く。名前・元の場所・削除した日時・削除した人・サイズを、新しく削除したものから並べる。クリック・Ctrl+クリック・Shift+クリック（範囲）・左端のチェックボックス（Ctrl+クリックと同じ。見出しのものですべて選ぶ・外す。FN0301-BR37 と同じ部品）・Ctrl+A（すべて）・↑↓（Shift で広げる）で選び、右クリックでメニュー（元に戻す・完全に削除）を出す。Enter で元に戻す、Delete で完全に削除（確認する）、Esc で選ぶのをやめる（キーは Folder の「すべて選択」「削除」と同じ設定） | Folder の一覧と同じ操作でまとめて扱えるようにするため（ユーザーの依頼 2026-11-28） |
| FN0302-BR03 | 元に戻す（ダブルクリックでも可）と、元の場所に戻す。元のフォルダが無ければ戻す場所を選ぶ（BR10）。同じ名前があれば「名前 (2)」などにする。1 件だけ戻したときは、そのフォルダを開いて選ぶ | - |
| FN0302-BR04 | 完全に削除・ゴミ箱を空にするときは確認する（元には戻せない）。共有モードでもだれでもできる | ユーザーの判断（2026-11-23。以前は管理者だけだった） |
| FN0302-BR05 | 保存期間（既定 30 日。管理者がバックアップの設定で変えられる。FN0901-BR02）を過ぎたものは、定期の処理（BAT0901）で完全に削除する | 容量を使い続けないため |
| FN0302-BR06 | 元に戻したものは、次のノード同期（BAT0301）で `node` テーブルに登録し直す（お気に入りは戻らない） | - |
| FN0302-BR07 | ゴミ箱の実体と記録はバックアップに含めない。バックアップから復元しても、ゴミ箱の中身はそのまま（FN0901-BR06） | ゴミ箱の実体がバックアップの外にあるため |
| FN0302-BR08 | ゴミ箱へ移したものとその中のもののお気に入り（全員分）を控え（TBL0303）、元に戻したら戻した場所（「名前 (2)」になっても）でお気に入りに入れ直す。完全に削除したら控えも消す | 元に戻したのにお気に入りが消えたままにならないようにするため |
| FN0302-BR10 | 元のフォルダが無い（消えた・名前が変わった）ものは、一覧の元の場所に印を付ける。元に戻すときは「元のフォルダがありません」で、元のフォルダを作り直して戻す（最初に選ばれている）か、今あるフォルダを選んで戻すかを選ぶ。まとめて戻すとき、元のフォルダがあるものは元の場所に戻す。選べるのは folder/ の中の今あるフォルダだけ（サーバーでも確かめる） | 消えた場所を勝手に作り直さず、利用者が戻す場所を決められるようにするため（ユーザーの依頼 2026-11-28） |
| FN0302-BR09 | 容量の上限（MB）を、管理者（ローカルモードは利用者）がバックアップの設定で決められる（FN0901-BR02。既定 0 = 上限なし）。上限を超えたら、定期の処理（BAT0901）が古く捨てたものから完全に削除して上限に収める | 既定では上限を設けず、容量が気になる環境だけ決められるようにするため（ユーザーの判断） |

## 5. 処理の流れ

1. フォルダ画面で削除（Delete・右クリックの「ゴミ箱に移動」など）すると API0303 でゴミ箱へ移す。
2. 「ゴミ箱」を開くと API0313 で一覧を表示する。
3. 「元に戻す」で API0314、「完全に削除」で API0315、「ゴミ箱を空にする」で API0316 を呼ぶ。
