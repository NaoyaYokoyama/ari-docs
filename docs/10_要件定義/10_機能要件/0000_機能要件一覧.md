# 0000_機能要件一覧 機能要件一覧

ローカルモードと共有モードを対象とする（動作モードはシステム概要の 4 章）。共有モードの残りの検討事項は [要件一覧](../0000_要件一覧.md) の RQ0001。

| ID | 機能名 | 概要 | 画面 |

| [FN0003](FN0003_探して開く.md) | 探して開く | `Ctrl+P` で Note・Wiki・ファイル・フォルダ・画面・操作を名前のあいまい検索で探して開く。最近開いたもの | SCR0001 |
| [FN0004](FN0004_ari-docsのリンク.md) | ari-docs のリンク | ファイル・フォルダ・Wiki・Note の場所を `ari://…` の文字で渡し、貼る・押すと ari-docs の中で移る | SCR0201, SCR0301, SCR0401, SCR0501 |

| [FN0403](FN0403_Note・Wikiのフォルダ.md) | Note・Wiki のフォルダ | Note・Wiki をフォルダ（入れ子あり）で分ける・移す | SCR0401, SCR0501 |
