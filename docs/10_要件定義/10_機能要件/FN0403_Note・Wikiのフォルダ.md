# FN0403 Note・Wiki のフォルダ

## 1. 概要

Note・Wiki をフォルダで分ける。フォルダの中にフォルダを作れる（入れ子）。一覧（画面の左）はフォルダの木で表示し、ドラッグや「移動...」で入れ替える。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| フォルダ（TBL0403） | Note のフォルダは本人、Wiki のフォルダは全員 | 名前と親のフォルダ |
| 入れ場所（TBL0404） | Note・Wiki と同じ | Note・Wiki がどのフォルダに入っているか。無ければ一番上 |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| Note のフォルダの作成・名前の変更・削除・移動 | 本人だけ（ほかの人のフォルダは見えない） |
| Wiki のフォルダの作成・名前の変更・削除・移動 | 全員（Wiki と同じ。FN0501） |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0403-BR01 | フォルダの名前は前後の空白を除いて 1〜25 文字。同じ場所（同じ親）に同じ名前のフォルダは作れない（名前の変更・移動でも同じ）。入れ子の深さに制限は無い | 見分けられるようにするため |
| FN0403-BR02 | 一覧はフォルダを先に名前順で、その後に Note・Wiki を並べ替えの設定（更新日順・名前順）で並べる。フォルダには中（下の階層も含む）の Note・Wiki の数を出す | - |
| FN0403-BR03 | 新しい Note・Wiki・フォルダは「今の場所」に作る。今の場所は、最後にクリックしたフォルダか、開いている Note・Wiki の入っているフォルダ。右クリックの「新しい〜（この中に）」ではそのフォルダに作る。作成のダイアログに場所を出す | 開いているものの近くに作れるようにするため |
| FN0403-BR04 | フォルダはクリック（Enter）で開け閉めする。開いているフォルダはこの PC（`localStorage`）に覚える。ホーム・お気に入りから開いたものが入っているフォルダは自動で開く | 次に開いたときも同じ見た目にするため |
| FN0403-BR05 | 中が空のフォルダだけ削除できる。中にフォルダ・Note・Wiki があれば、削除せずに知らせる | Note・Wiki にはゴミ箱が無く、まとめて消すと戻せないため |
| FN0403-BR06 | 移動は、行をフォルダの行へドラッグする（Note・Wiki の行へドロップするとその行と同じ場所、空いているところへドロップすると一番上）、または右クリックの「移動...」で移動先を選ぶ。フォルダを自分の中へは移せない | マウスでもキーボードでも移せるようにするため |
| FN0403-BR07 | 絞り込み中はフォルダを使わず、一致した Note・Wiki を並べ、それぞれの場所（「手順書 / サーバー」）を添える | どこにあるかに関係なく探せるようにするため |
| FN0403-BR08 | 一覧のキー操作: ↑↓（j・k）で動く、Enter でフォルダを開け閉め・Note・Wiki を開く、→（l）でフォルダを開く（開いていれば中へ）、←（h）でフォルダを閉じる（閉じていれば入っているフォルダへ） | エクスプローラー・Vim と同じ感覚で使えるようにするため |
| FN0403-BR09 | Note・Wiki を削除したら入れ場所も消す。ユーザーを削除したら、その人の Note のフォルダも消す（Wiki のフォルダは残す） | - |

## 5. 処理の流れ

1. 画面を開くと API0408 でフォルダと入れ場所を読み、Note・Wiki の一覧と合わせて木にする。
2. 作成は API0409（Note・Wiki はそれぞれの作成のあと API0412 で入れる）、名前の変更は API0410、削除は API0411、移動は API0412。
3. 操作のあとは API0408 で読み直す。

| MSG0422 | フォルダが無い | フォルダが見つかりません。削除された可能性があります |
