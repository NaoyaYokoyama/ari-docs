# FN0304 比べる

## 1. 概要

WinMerge のように、2 つのファイル・フォルダの違いを並べて見せる。日本では Excel で仕事をすることが多いため、Excel はシートの表のまま、変わったセルに色を付けて見せる。エンジニアでない人にもわかるよう、「左」「右」と色（変わった: 黄、左だけ: 赤、右だけ: 緑）と「違うところが N か所」で伝える。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| ファイル・フォルダ | 全員 | Folder（`folder/` の中）のもの。比べた結果は保存しない |
| Note・Wiki の版 | Note は本人、Wiki は全員 | 変更履歴（FN0402）の「前の版との違い」も同じ見せ方にする |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0304-BR01 | Folder で 2 つ選んで右クリックの「2 つを比べる」、または 1 つを「比べる相手に選ぶ」にしてから、別のもの（ほかのフォルダのものでもよい）の「「名前」と比べる」で比べる画面（SCR0302）を開く。ファイルどうし・フォルダどうしだけを比べられる。比べる相手はこの画面を開いている間だけ覚える | 同じフォルダにない「前の版」と「今の版」も比べられるようにするため |
| FN0304-BR02 | Excel など（xlsx・xlsm・xlsb・xls・ods）どうしは、シートを名前で組にし、シートごとに「同じ・違う・左だけ・右だけ」を出す。表は右の値を出し、変わったセルは黄色にして左の値を消し線で添える。左にだけある行は赤の消し線、右にだけある行は緑。行番号は左・右それぞれの番号を出す（行を足しても、あとの行が全部違うとは見せない）。3000 行・100 列まで比べ、超えたらその旨を出す | 表のまま見ると、どこが変わったか一目でわかるため |
| FN0304-BR03 | Word・PowerPoint・PDF・テキストは、文字を取り出して左右に並べる。変わった行は黄色、その中の変わった文字に濃い色を付け、左だけの行は赤、右だけの行は緑にする。「違うところだけ」で同じ行を省ける（違いの前後 3 行は残す）。文字認識（FN0202-BR14）はしない（すぐ結果を出すため） | WinMerge と同じ見せ方。書式（太字・色など）は比べない |
| FN0304-BR04 | そのほかの形式（画像など）は、中身が同じかどうかと大きさだけを出す | 中身を並べられないため |
| FN0304-BR05 | フォルダどうしは、中のファイル・フォルダを「同じ・違う・左だけ・右だけ」の一覧にする（既定は違うものだけ）。違うファイルを押すと、そのファイルどうしを比べる。5000 件まで | どのファイルが変わったかを先に知るため |
| FN0304-BR06 | 「次の違い」「前の違い」（`Alt+↓`・`Alt+↑`）で違うところへ移る。「左右を入れ替える」で左右を入れ替える | 長いファイルでも違いを見落とさないため |
| FN0304-BR07 | Excel などは数式も比べる。行をそろえた組（同じ行・変わった行）で数式の違うセルは、値が同じでも違いとし（行は「変わった」）、紫の色と ƒ の印を付けて、左の数式を消し線で、右の数式をそのまま添える（値も変わったセルは黄のまま数式を添える）。数式を読めない形式・シートは値だけで比べる。色・罫線・文字の飾りは比べない | 値が同じでも計算のしかたが変わったことに気づけるようにするため（ユーザーの判断（2026-11-23 の QA）） |

## 5. 処理の流れ

1. Folder で比べるものを選び、右クリックから比べる画面を開く。
2. 画面はファイルなら API0317、フォルダなら API0318 を呼ぶ。
3. 結果を種類ごとに並べる（文字の行と文字の違いは画面で求める。`front/src/lib/lineDiff.ts`）。

## 8. 決定事項

| 日付 | 内容 | 理由 |
|---|---|---|
| 2026-11-23 | ファイル（Excel・文字）・フォルダ・Note と Wiki の版を、WinMerge のように比べられるようにする | ユーザーの依頼（「色々なものを WinMerge みたいに比較できたら嬉しい」「非エンジニアでもわかりやすい仕組み」） |
| 2026-11-23 | 見せ方（左右・色・表のまま・前の値を消し線で添える）・上限（3000 行・100 列・5000 件）・文字認識をしない・比べる相手の選び方 | おすすめで決めた（2026-11-28 にユーザーが確認した） |
| 2026-11-23 | 比べるのは同じ場所の中だけにする（今は） | ユーザーの判断（2026-11-23 の QA）。場所をまたぐと両方にログインして中身を取ってくる仕組みが要るため、場所をまたいだ検索と一緒にあとで決める |
| 2026-11-23 | Excel は数式も比べる（FN0304-BR07）。色・罫線は比べない | ユーザーの判断（2026-11-23 の QA）。見せ方（紫・ƒ・左右の数式を添える）はおすすめで決めた（2026-11-28 にユーザーが確認した） |
