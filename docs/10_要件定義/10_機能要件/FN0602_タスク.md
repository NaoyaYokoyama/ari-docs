# FN0602 タスク

## 1. 概要

個人のやることを、優先度（高・中・低）と期限を付けて管理する。カンバン（未着手・進行中・完了）と一覧で見る。ヘッダーの「Task」（`/task`）。個人のタスク管理は無料版に入れる（チームの管理は Enterprise 版で検討。2026-11-26 のユーザーの判断）。

## 2. ビジネスルール

| ID | ルール | 理由 |
|---|---|---|
| FN0602-BR01 | タスクは作った本人だけが見る・変える・消す（Note と同じ。共有モードでもほかの人には見えない） | 個人のタスク管理のため |
| FN0602-BR02 | タスクはタイトル（100 文字まで・必須）・優先度（高・中・低。既定は中）・期限（日付。無しも可）・状態（未着手・進行中・完了）・メモ（10000 文字まで）を持つ | - |
| FN0602-BR03 | 上の欄にタイトルを入れて Enter で、選んだ優先度・期限の未着手として、未着手の一番上に足す。`Ctrl+N` で欄へ移る | すぐに書き留められるように |
| FN0602-BR04 | ボード: 未着手・進行中・完了の 3 列に並べる。カードをドラッグして、列（状態）と列の中の並びを変える（並びは覚える）。キーでは、カードを選んで `Alt+←→` で隣の列の一番上へ、`Alt+↑↓` で列の中の並びを変える。カードを押すと詳細（タイトル・優先度・状態・期限・メモを変える・削除。期限は「今日・明日・1 週間後・なし」のボタンでも選べる）。完了の列から完了したものをまとめて削除できる | カンバンで進み具合を見るため |
| FN0602-BR05 | 一覧: 期限・優先度・状態・追加で並べ替える（既定は期限の近い順。同じボタンをもう一度押すと逆順）。期限の無いものはいつも後。状態以外で並べるときも完了は下にまとめ、同じものは期限の近い順 → 優先度の高い順。チェックで完了・未着手を切り替える。完了を隠せる。ボードと一覧のどちらで見るか・一覧の並べ方はこの PC に覚える | 期限の近いものから片付けるため。優先度などで見直したいため（2026-11-26 のユーザーの要望） |
| FN0602-BR06 | 期限は日付と曜日で出し、過ぎたもの（完了を除く）は赤で「N 日過ぎ」、今日は「今日」、明日は「明日」と出す。上に未着手・進行中・完了の数と期限切れの数を出す | 遅れに気づけるように |
| FN0602-BR07 | 削除は元に戻せないので、いつも確かめる。ユーザーを消すと、その人のタスクも消す | ゴミ箱が無いため |
| FN0602-BR08 | ホームの「やること」: 完了でないタスクのうち、期限切れ・期限が 7 日以内・進行中のものを期限の近い順に 6 件まで出す（無ければ欄ごと出さない）。チェックで完了、押すとタスクの画面でその詳細を開く。「すべて見る」でタスクの画面へ | 毎日開くホームで、やることに気づけるように |
| FN0602-BR09 | 探して開く（FN0003）: 完了でないタスクを名前で探して開ける。「新しいタスクを作る」でタスクの画面の追加の欄へ。打った文字は一番下の「タスクに追加: …」でそのまま足せる（優先度 中・期限なし。今の画面のまま）。Vim モードは `gk` でタスクの画面へ | どの画面からでもすぐ書き留められるように |
| FN0602-BR10 | 繰り返し: なし・毎日・平日（土日と日本の祝日を除く。振替休日・国民の休日も含め、通信せずにアプリで計算する。`common/holiday.rs`）・毎週・毎月を選べる。完了にすると（チェック・ドラッグ・詳細のどれでも）、同じタイトル・メモ・優先度・繰り返しで次の回を未着手の一番上に作る。次の期限は期限（無ければ今日）から 1 回分ずつ進め、今日より後になるまで進める（毎月で無い日は月末）。完了にしたほうは繰り返しを外す（戻して完了にし直しても二重に作らない）。カードと一覧に繰り返しの印を出す | 定例の作業を毎回足さなくて済むように |
| FN0602-BR11 | 足すとき（上の欄・探して開くの「タスクに追加」）、文の終わりの言葉を期限・優先度にする。期限: 今日・明日・明後日（あさって）・来週（7 日後）・`N日後`・`金曜`／`金曜日`（今日を含めて次のその曜日）・`来週金曜`（来週の月〜日のその曜日）・`12/5`／`12月5日`（年が無く今日より前なら来年）・`2027/1/5`。優先度: `!高`・`!中`・`!低`（全角の！も可）。空白で区切った最後の言葉から読み、読めない言葉でやめる（タイトルは 1 語は残す）。読んだ期限・優先度は欄の期限・優先度にその場で映す。欄で選んだ期限があればそちらが先 | 書きながら期限を付けられるように |
| FN0602-BR12 | ファイル・Note とつなぐ: Folder の行（1 つ選んだとき）と Note・Wiki の一覧の右クリックの「タスクにする」で、名前をタイトルに、ari:// のリンク（FN0004）をメモに入れたタスクを未着手の一番上に足す。メモに書いた ari:// のリンクは、詳細のメモの下に名前と場所で並べ、押すと保存してから開く。カードはメモのリンクを印と名前で出し、一覧はリンクのあるものに印を出す | やることと、その相手のファイル・Note をすぐ行き来できるように |
| FN0602-BR13 | 期限の通知（デスクトップアプリ）: 起動したとき（ログインしたあと）と、開いたまま日が変わって朝 8 時を過ぎたときに、期限が今日のものと過ぎたもの（未完了）を OS の通知に出す（件数と、期限の古い順に 3 件のタイトル）。場所ごとに 1 日 1 回（この PC の `localStorage` の `task-notified:<場所>`）。最初の窓だけが出す。出すかは個人の設定の「期限を通知で知らせる」（`taskNotify`、既定オン。設定の「操作」）。通知は Tauri のコマンド `notify`（`tauri-plugin-notification`）。ブラウザでは出さない | 画面を開かなくても期限に気づけるように（2026-11-27 のユーザーの依頼。時刻・回数はおすすめで決めた） |
