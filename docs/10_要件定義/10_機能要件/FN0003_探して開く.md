# FN0003 探して開く

## 1. 概要

どの画面からでも `Ctrl+P` で入力欄を開き、名前の一部を打つだけで Note・Wiki・ファイル・フォルダ・画面・操作・設定のメニューを探して開く（VS Code・ctrlp.vim・Vimium の `o` と同じ考え方）。打った文字が順に含まれていれば一致とし（あいまい検索）、打つ前は最近開いたものを出す。中身の検索はホーム（FN0201・FN0202）で行う。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| Note・Wiki・ノード | サーバー | 名前（タイトル・ファイル名）と入っている場所で探す（API0207） |
| 最近開いたもの | この PC（ブラウザの `localStorage` の `recent-opened:<ユーザー ID>`） | 開いた Note・Wiki・ファイル・フォルダを新しい順に 30 件まで。サーバーには送らない |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| 探して開く | 全員。Note は本人のものだけ、Wiki・ノードは全員のものが出る（FN0401・FN0501・FN0301 と同じ） |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0003-BR01 | `Ctrl+P`・ヘッダーの「探して開く」で開く。入力欄・本文の中からも開ける。Vim モードでは `o`、本文の Vim のエディタでは `:e 言葉`（言葉を入れて開く）でも開く（FN0702）。ほかのダイアログを開いている間は開かない。Vim モードで同じキーを割り当てているとき（キーの設定・本文の vimrc）は Vim を優先する | どこにいてもすぐ移れるようにするため。Vim の割り当てを壊さないため |
| FN0003-BR02 | 打つ前は「最近開いたもの」（8 件）と「画面・操作」を出す。最近開いたものは、探して開くで選んだもの・Note と Wiki を開いたとき・Folder でファイルを開いたときに残す | よく使うものにすぐ戻れるようにするため |
| FN0003-BR03 | 打った文字を空白で区切り、どの語も「場所/名前」（Note・Wiki はフォルダの名前を `/` でつないだもの、ノードはパス）に順に含まれていれば一致とする。全角・半角、大文字・小文字、カタカナ・ひらがなは区別しない（半角カナも探せる） | うろ覚えの一部・略した打ち方でも見つけられるようにするため |
| FN0003-BR04 | 並びは点数の高い順にする。名前の中での一致・名前の始まりからの一致・単語の始まり（`/`・`_`・`-`・`.`・空白などの次や、英数字とそれ以外の境目）・続いた文字を高くし、離れた文字は低くする。最近開いたものは少し上にする。同じ点数なら名前・場所の短い順。一度に 50 件まで出し、一致した文字を太字にする | 打った文字に近いものを上に出すため（fzf と同じ付け方） |
| FN0003-BR05 | Note・Wiki・ノードはサーバーで探し、上位 50 件を返す（API0207）。打ち終わるのを 0.12 秒待ってから問い合わせる。画面・操作・設定のメニューは画面の中で探し、サーバーの答えと合わせて同じ付け方で並べ直す | 打つたびに問い合わせて重くしないため |
| FN0003-BR06 | 隠しファイル（`.` で始まる名前）と、その中のものは、設定の「隠しファイルを表示する」（FN0701）がオンのときだけ出す。消えたファイル（ノード同期の前）は出さない | Folder の一覧と同じ見え方にするため |
| FN0003-BR07 | `↑`・`↓`・`Ctrl+N`・`Ctrl+P`・`Ctrl+J`・`Ctrl+K`・`Tab` で選び、`Enter` で開く、`Esc` で閉じる（閉じたら前にいたところへ戻る）。変換中の `Enter` は使わない | キーボードだけで使えるようにするため。Vim・Emacs の指の動きでも選べるように |
| FN0003-BR08 | 開いたとき: Note・Wiki はその画面で開く。フォルダは中を開く。ファイルは Folder で場所を開いて選び、アプリで開く（ダブルクリックと同じ）。`Shift+Enter` は、ファイル・フォルダを開かずに Folder で場所を開いて選ぶだけにする | すぐ中身を見たいときと、場所を確かめたいときの両方に使えるようにするため |
| FN0003-BR09 | 画面・操作: Home・Folder・Note・Wiki・Docs・設定へ、新しい Note・Wiki を作る（作る画面を開く）、配色の切り替え、ショートカットの一覧、Vim モードの切り替え。設定のメニュー（そのモード・権限で見られるもの）は打ったときだけ出す（「設定」と打つとまとめて出る）。メニューの言葉（「テーマ」で配色など）でも一致させる | 画面のどこにあるかを覚えなくても使えるようにするため |
| FN0003-BR10 | 最近開いたものから選んだファイル・フォルダが無いときは MSG0009 を出して最近開いたものから除く。Note・Wiki は一覧を読んだときに、消えたものを除き、名前・場所を今のものにする | 消えたものを出し続けないため |

> ari-docs のリンク（`ari://…`）を貼ったときは、そのリンクだけを出して開く（FN0004-BR03）。

## 5. 処理の流れ

1. `Ctrl+P`（Vim モードは `o`）で開く。打つ前は最近開いたものと画面・操作を出す。
2. 打つと、画面・操作・設定はすぐ、Note・Wiki・ノードは少し待ってからサーバーで探し（API0207）、合わせて並べる。
3. `Enter` で開く。最近開いたものに残す。

## 6. メッセージ

| ID | 表示する場面 | 文言 |
|---|---|---|
| MSG0009 | 選んだファイル・フォルダが無い | 「{名前}」が見つかりません（移動・削除された可能性があります） |
| MSG0010 | 合うものが無い | 「{言葉}」に合うものはありません |
| MSG0011 | サーバーで探せなかった | 探せませんでした。もう一度打ってください |
| MSG0012 | Vim モードを切り替えた | Vim モードにしました / Vim モードをやめました |

## 8. 決定事項

| 日付 | 内容 | 理由 |
|---|---|---|
| 2026-10-31 | 名前で探して開く入口を、どの画面にも置く（キーは `Ctrl+P`、Vim モードは `o`） | おすすめの機能として追加した（ユーザーの依頼「おすすめの機能を追加して」）。`Ctrl+K` は Markdown エディタ（画像）と Vim モードの「上の領域へ」に使っているため、`Ctrl+P`（VS Code・ctrlp.vim と同じ）にした |
| 2026-10-31 | 最近開いたものはこの PC に利用者ごとに残し、サーバーには送らない | ほかの画面の設定と同じく PC ごとの使い方のため（FN0701）。サーバーの表を増やさないため |

## 9. 未決事項
