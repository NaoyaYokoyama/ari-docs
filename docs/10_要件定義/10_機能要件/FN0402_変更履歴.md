# FN0402 変更履歴

## 1. 概要

Note・Wiki を保存するたびに、その版を残す。編集画面の「変更履歴」で版を見て、前の版に戻せる。あわせて、保存のときに、開いたあとにほかの人（Note はほかの画面・PC）が更新していないかを確かめる。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| 変更履歴（TBL0402） | Note は本人、Wiki は全員 | 版ごとのタイトル・本文・保存した人・日時 |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| Note の履歴 | 本人だけ |
| Wiki の履歴 | 全員 |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0402-BR01 | 保存するたびに、保存したあとの版を残す。まだ版が無いもの（この機能より前に作ったもの・作成直後）は、保存する前の版も先に残す | 前の版に戻せるようにするため |
| FN0402-BR02 | 1 つの Note・Wiki に残す版は決まった数（FN0902。既定 100 件）まで。減らしたときは、次に保存したときに超えた分を消す。超えたら古いものから消す。Note・Wiki を削除したら履歴も消す（ユーザーを削除したら、その人の Note の履歴も消す） | 容量を使い続けないため |
| FN0402-BR03 | 編集画面の「変更履歴」（時計のボタン）で、版を新しい順に、日時・保存した人・文字数で並べる。選ぶと右にその版の中身（Markdown を整えて）を出す | - |
| FN0402-BR04 | 「この版にする」で、その版のタイトルと本文を編集中の内容にする（未保存になる）。保存するとその版に戻る（戻したことも 1 つの版として残る） | 戻す前に中身を確かめ、保存するかを選べるようにするため |
| FN0402-BR05 | 保存のとき、開いたとき（または前に保存したとき）の更新日時と今の更新日時が違えば確かめる（Wiki は FN0501-BR10、Note は「ほかの画面（PC）で 〜 に更新しています」）。OK なら上書き、キャンセルなら保存しない | 同時に編集したときに黙って上書きしないため |
| FN0402-BR06 | 更新日時は秒までのため、同じ秒の中の 2 つの保存は見分けられない | 現行実装の仕様 |

## 5. 処理の流れ

1. 保存（API0405・API0505）で、食い違いを確かめ、保存して版を残す。
2. 「変更履歴」で API0406・API0506 を呼んで一覧を、API0407 で版の中身を表示する。
3. 「この版にする」→ 保存で戻す。
