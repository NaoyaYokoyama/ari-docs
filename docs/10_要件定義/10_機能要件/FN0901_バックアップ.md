# FN0901 バックアップ

## 1. 概要

ファイル（`folder/`）と DB をまとめて ZIP に保存する。管理者が間隔・時刻・保存期間・保存先を決め、その間隔で自動で取る。設定画面の「バックアップ」で、今すぐ取る・ダウンロード・復元・削除ができる。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| バックアップの実体 | ファイルシステム | `<保存先>/ari-docs_<YYYYMMDD_HHMMSS>_<種類>.zip`。中は `ari.db`（DB の写し）と `folder/`（ファイル） |
| バックアップ（TBL0901） | システム | 作った日時・種類・サイズ・保存先 |
| 設定（TBL0002） | 管理者 | 間隔・時刻・保存期間・保存先・ゴミ箱の保存期間 |

## 3. 権限

| 操作 | 利用者 | 管理者 |
|---|---|---|
| 設定・一覧・作成・ダウンロード・復元・削除 | ○（ローカルモード）/ ×（共有モード） | ○ |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0901-BR01 | バックアップは全員のデータに効くため、共有モードでは管理者だけが扱える（それ以外は 403。設定画面のメニューも出さない）。ローカルモードは利用者が扱える | - |
| FN0901-BR02 | 設定: 自動のバックアップ（しない / 毎日 / 毎週（月曜始まりの週ごと） / 毎月）、時刻（0〜23 時）、保存期間（1〜3650 日）、保存先（絶対パスのある フォルダ。空なら `<データのフォルダ>/backups`）、ゴミ箱の保存期間（1〜3650 日。FN0302-BR05）。既定は「しない」・3 時・30 日・既定の保存先・30 日 | 管理者が期間を決められるようにするため（ユーザーの依頼）。既定で自動にしないのは、ファイルが多いと容量を使うため |
| FN0901-BR03 | バックアップは、DB を使っている途中でも壊れない写し（SQLite の `VACUUM INTO`）と、`folder/` の中身を 1 つの ZIP にする。作っている途中のファイルは `.<名前>.partial` にし、できたら名前を変える | 途中で失敗しても壊れたバックアップを残さないため |
| FN0901-BR04 | 自動のバックアップは、定期の処理（BAT0901。毎分）が、設定の時刻を過ぎていて、その期間（毎日はその日、毎週はその週、毎月はその月）の自動のバックアップが無ければ取る。アプリ（サーバー）が止まっていた期間の分は、次に動いたときに 1 回だけ取る。保存期間を過ぎた自動・復元の前のバックアップは消す（手動のものは消さない） | - |
| FN0901-BR05 | 復元: 確認のあと、先に今の状態をバックアップし（種類「復元の前」）、`folder/` の中身をバックアップのものと入れ替え、DB をバックアップのもので置き換える（SQLite のバックアップ機能を使う）。入れ替えに失敗したら元に戻す。復元のあとは画面を読み込み直す | 間違えて復元しても戻せるようにするため |
| FN0901-BR06 | 復元しても、バックアップの記録（TBL0901）・設定（TBL0002）・ゴミ箱（TBL0302）は今のものを残す。中身の検索（FN0202）は取り込み直す | それぞれの実体がバックアップの外にあるため |
| FN0901-BR07 | バックアップ・復元・削除は同時に 1 つだけ。実行中はほかの操作を断り、ノード同期・中身の取り込みも止める | ファイルと DB を入れ替えている途中に書き換えないため |
| FN0901-BR08 | 一覧は新しいものから、日時・種類（定期 / 手動 / 復元の前）・サイズ・作った人（定期は「自動」）・ファイル名を出す。ファイルが移動・削除されていれば「ファイルが見つかりません」と出し、ダウンロード・復元はできない | - |
| FN0901-BR09 | ダウンロードは、ファイルを少しずつ読んで送る | バックアップが大きいため |

## 5. 処理の流れ

1. 設定画面の「バックアップ」を開くと API0901 で設定を、API0903 で一覧を表示する。
2. 「設定を保存」で API0902。
3. 「今すぐバックアップ」で API0904、ダウンロードで API0907、復元で API0906（成功したら画面を読み込み直す）、削除で API0905 を呼ぶ。

| MSG0904 | 復元 | バックアップから復元しました |

| MSG0906 | 実行中 | バックアップ・復元の実行中です。終わってからもう一度お試しください |

## 8. 決定事項

| 日付 | 内容 | 理由 |
|---|---|---|
| 2026-10-30 | 管理者がバックアップの間隔・保存期間を決め、間隔ごとに自動で取る。設定画面でダウンロード・復元・削除ができる | ユーザーの依頼 |
| 2026-10-30 | 既定は自動にしない（FN0901-BR02）。手動のものは保存期間で消さない（FN0901-BR04） | 実装時に決めた（ユーザーの確認待ち） |

## 9. 未決事項

- 外部の場所（クラウド・別のサーバー）へ送るか
- 復元したときに、ユーザーのログインをすべて切るか（現行は、復元後の DB にいないユーザーだけ 401 になる）
- バックアップの ZIP をアップロードして復元する（別の PC へ移すとき）
