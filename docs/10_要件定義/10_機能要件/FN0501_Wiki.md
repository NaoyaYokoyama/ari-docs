# FN0501 Wiki

## 1. 概要

共有ナレッジ用の Markdown の文書。一覧・作成・編集・削除・お気に入り登録ができる。ローカルモードでは利用者 1 人が使い、操作は Note（FN0401）とほぼ同じ。共有モードでは、ログインしたユーザー全員が参照・編集・削除できる（FN0501-BR01）。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| Wiki（TBL0501） | ユーザー `local` | タイトルと Markdown の本文。`user_id` は作成者を表す |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| 一覧・参照・作成・更新・削除 | ○ |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0501-BR01 | `user_id` は作成者を表すだけで、一覧・参照・更新・削除の絞り込みには使わない | 共有モードで全員が使えるようにするため（決定事項を参照） |
| FN0501-BR02 | 作成時のタイトルは 1 文字以上 20 文字以内。違反時は 400 と MSG0510。更新時のタイトルは 25 文字以内（画面の入力欄と同じ）。作成・更新とも、前後の空白を除いて空なら 400（「タイトルを入力してください。」） | サーバー側で入力チェックしている。空白だけのタイトルは一覧で見分けられないため |
| FN0501-BR03 | 一覧はタイトルの昇順で、すべて返す | 31 件目以降が表示されない問題があったため（旧 RQ0501） |
| FN0501-BR04 | Wiki を削除すると、その Wiki のお気に入りも削除する | 存在しない Wiki のお気に入りが残らないようにするため |
| FN0501-BR05 | 更新すると `updated_at` を現在日時にする | - |
| FN0501-BR06 | 未保存の変更があるとき、別の Wiki を選ぶ・別の画面へ移動する前に確認する | 編集内容を失わないため |
| FN0501-BR07 | `Ctrl+S` で保存する | - |
| FN0501-BR09 | 保存すると、最後に更新した人（`wiki.updated_by`）を記録し、画面の「更新」の横に表示名を出す。まだ誰も更新していなければ作成者を出す | 共有モードで誰が変えたか分かるようにするため（旧 RQ0502） |
| FN0501-BR10 | 保存のとき、開いたとき（または前に保存したとき）の更新日時と今の更新日時が違えば、「{名前}さんが {日時} に更新しています。上書きすると…」（MSG0516）で確かめる。OK なら上書きし、キャンセルなら保存せずに編集中の内容を残す | 同時に編集したとき、後から保存した人が黙って上書きしないようにするため |
| FN0501-BR08 | 画面の操作（表示の切り替え・作成ダイアログ・一覧の絞り込みと並べ替え・ショートカット・保存の入力チェック・更新日時の表示）は Note と同じ（FN0401-BR09〜BR14）。作成ダイアログのタイトルは 20 文字まで（FN0501-BR02） | Note と同じ画面の部品で作るため |

## 5. 処理の流れ

Note（FN0401 の 5 章）と同じ。呼ぶ API は API0501〜API0505、お気に入りは API0604。

## 8. 決定事項

| 日付 | 内容 | 理由 |
|---|---|---|
| 2026-10-11 | Wiki の `user_id` は作成者を表すだけとし、絞り込みに使わない（FN0501-BR01） | 共有モードでは全員が参照・編集・削除できるようにするため（ユーザーの判断） |
| 2026-10-30 | 作成・更新で空白だけのタイトルを 400 にし、更新のタイトルを 25 文字以内にする（FN0501-BR02） | ユーザーの依頼（残課題のうちおすすめのものを実装）。Note（FN0401-BR03）と揃えるため。作成 20 文字・更新 25 文字の違いは未決のまま |
| 2026-10-16 | 画面を Note と共通にする（FN0501-BR08） | 見た目と使い勝手の仕上げ（ユーザーの依頼）。2 つの画面のコードがほぼ同じだったため |
| 2026-10-30 | 一覧の 30 件の制限をなくし（旧 RQ0501）、最後に更新した人を記録し（FN0501-BR09。旧 RQ0502）、保存のときにほかの人の更新を確かめる（FN0501-BR10） | ユーザーの依頼（おすすめの機能・修正案をすべて対応） |

## 9. 未決事項

- 同時に編集している人を、編集中に知らせるか（現行は保存のときに確かめる）
- 編集中のタイトルは 25 文字まで入るが、作成は 20 文字まで（作成ダイアログは 20 文字に制限した。更新はサーバー側も 25 文字まで）。どちらかに揃えるか
