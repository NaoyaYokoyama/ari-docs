# FN0702 Vim モード

## 1. 概要

Vim・Vimium（ブラウザの拡張機能）と同じ感覚で、キーボードだけで操作できるようにする。入力欄の外では `j`・`k` でスクロール、`f` で押すところを文字で選ぶなど、画面全体を Vim のキーで動かす。Note・Wiki の本文も Vim（ノーマル・挿入・ビジュアルモード）で編集できる。キーの割り当ては設定画面で変えられる。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| Vim モードの設定 | この PC（ブラウザの `localStorage` の `vim`） | オン・オフ、操作ごとのキー、スクロールの量、ヒントの文字、本文のエディタの設定。サーバーには送らない（FN0701-BR10 と同じ） |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| Vim モードの設定・利用 | 全員（その PC だけに効く） |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0702-BR01 | 既定はオフ。設定画面の「Vim モード」でオンにする。設定は書き出し・読み込み・初期化（FN0701）に含める | 使わない人の操作を変えないため |
| FN0702-BR02 | 画面全体のキーは入力欄（入力欄・本文・プルダウン）の外でだけ効く。画面の部品が先に使うキー（Note・Wiki の一覧の j・k、ダイアログの Esc など）はそちらを優先する。ダイアログを開いている間は画面の移動（Home へ など）を効かせない | 文字の入力と画面の操作を混ぜないため |
| FN0702-BR03 | 操作と既定のキー: 下へ `j`、上へ `k`、左へ・戻る `h`、右へ・開く `l`、半ページ下へ `d`、半ページ上へ `u`、先頭へ `gg`、末尾へ `G`、文字で選んでクリック `f`、文字で選んで開く `F`、検索・絞り込みへ `/`、書き始める `i`、探して開く（FN0003）`o`、前の画面へ `H`、次の画面へ `L`、右隣・左隣の画面へ `gt`・`gT`、Home・Folder・Note・Wiki・Docs・設定へ `gh`・`gf`・`gn`・`gw`・`gd`・`gs`。数字を先に打つと回数になる（`5j`）。続きのあるキー（`g` など）は押しかけを右下に出し、1 秒（続きが無ければ 1.5 秒）待つ | Vim・Vimium と同じ割り当てにするため |
| FN0702-BR04 | 移動の操作は、一覧のある画面では一覧の中を動く（Folder の一覧: `j`・`k` で行を選ぶ、`l` で開く、`h` で上のフォルダへ、`gg`・`G`・`d`・`u` で先頭・末尾・10 行。Note・Wiki の一覧にフォーカスしているとき: `gg`・`G`・`d`・`u`）。それ以外はスクロールする。スクロールするところは、フォーカスしているところ → 最後にクリックしたところ → 画面で一番大きくスクロールできるところの順に決める。1 回の量は設定の px（文字の大きさに合わせて変わる） | ファイラーと同じく一覧を動かせ、読み物はスクロールできるようにするため |
| FN0702-BR05 | `f`・`F` で、見えていて押せるところ（ボタン・リンク・入力欄・一覧の行など）に文字（ヒント）を出す。文字は上から順に、設定の文字で同じ長さに振る。打った文字のところを押す（入力欄なら入力欄に移る）。`F` はダブルクリックと同じ（ファイルを開く・フォルダに入る）。Esc・ヒントに無い文字・クリック・スクロールでやめる。押せるところが無ければ MSG0713 | マウスを使わずにどこでも押せるようにするため |
| FN0702-BR06 | `/` はその画面の検索欄・絞り込み欄（Home の検索、Folder・Note・Wiki の絞り込み、設定を探す、Docs の検索）に移る。無ければ MSG0714。入力欄で Esc を押すと入力欄から出る（画面の部品の Esc を先に動かす。ダイアログの中は除く） | Vim の / と同じ感覚で探せるようにするため |
| FN0702-BR07 | 「本文も Vim で編集する」（既定オン）のとき、Note・Wiki の本文を Vim のエディタ（CodeMirror + @replit/codemirror-vim）にする。表示の「編集」は本文だけ、「分割」は左に本文・右にプレビュー、「プレビュー」はこれまでと同じ。`:w` で保存、`:q` で一覧へ、`:wq`・`:x` で保存して一覧へ、`:e 言葉` で言葉を入れて探して開く（FN0003）。下の帯に `-- INSERT --` などを出す | Vim の操作で書けるようにするため |
| FN0702-BR08 | `i` は、Note・Wiki では本文に移って挿入モードにする（プレビューなら分割に切り替えてから）。ほかの画面では検索・入力欄に移る。無ければ MSG0715 | - |
| FN0702-BR09 | キーは操作ごとに Vim の書き方（`G`・`<C-d>`・`<Space>` など）で変えられる。「,」で区切ると複数、空なら割り当てなし。読めない部分は使わずに知らせ、ほかの操作と同じキー・始まりが同じキーは設定画面で知らせる | 好みや指の癖に合わせられるようにするため |
| FN0702-BR10 | 本文のエディタには「挿入モードを抜けるキー」（`jk` など）と、vimrc と同じ書き方の追加の設定（`nmap`・`inoremap`・`set` など）を当てる。使えない命令の行は設定画面で知らせる | 自分の vimrc に近づけられるようにするため |
| FN0702-BR11 | Vim のエディタは Vim モードのときだけ読み込む | 使わない人の起動を重くしないため |
| FN0702-BR12 | `?` のショートカットの一覧に、今のキーの割り当てを出す | 変えたキーを確かめられるようにするため |
| FN0702-BR13 | 領域の移動: 左の領域へ `<C-h>`（サイドバー）、右の領域へ `<C-l>`（メイン。Note・Wiki は本文）、下の領域へ `<C-j>`・上の領域へ `<C-k>`（Note・Wiki のタイトルと本文の間）。キーは設定で変えられる。入力欄（タイトルなど）と本文の Vim のエディタ（ノーマルモード）からも使える。サイドバーでは行を `j`・`k`・`gg`・`G`・`d`・`u` で選び、`l`・Enter で開く（ツリーの閉じたフォルダは `l` で開く）、`h` でフォルダを閉じる・上の階層の行へ。サイドバーに戻ると前にいた行（無ければ選んでいる行）に戻る。今いる領域は枠で示す | vimrc でよく使う `nnoremap <C-h> <C-w>h` などと同じ指の動きで領域を移れるようにするため |
| FN0702-BR14 | Folder の一覧のファイル操作: コピー `yy`、切り取り `x`、貼り付け `p`（表示しているフォルダへ）、ゴミ箱へ `D`、名前の変更 `cw`、範囲選択 `V`（それぞれ `Ctrl+C`・`Ctrl+X`・`Ctrl+V`・`Delete`・`F2` と同じ。FN0301）。範囲選択の間は下の中央に `-- VISUAL LINE -- n 件` を出し、`j`・`k`・`gg`・`G`・`u` で選ぶ範囲を広げ、`y` でコピー、`d`・`x` で切り取り、`D` でゴミ箱へ（どれも範囲選択をやめる。`d` は半ページ下へではなく切り取りになる。Vim のビジュアルモードと同じ）。`Esc`・`V` で範囲選択だけやめ、選んだものは残す（もう一度 `Esc` で外す）。左のツリーにいるとき・ダイアログを開いている間は使わない | ranger・vifm と同じ指の動きでファイルを扱えるようにするため。`d` は半ページ下へに使うので、切り取りは Vim で消した文字をレジスタに入れる `x` にした |

## 5. 処理の流れ

1. 設定画面の「Vim モード」でオンにする。
2. 入力欄の外でキーを押すと、押したキーの並びを割り当てと比べ、決まったら操作する（画面が登録した動きがあればそれ、無ければスクロールなど）。
3. Note・Wiki の本文は Vim のエディタで編集し、`:w` で保存する（API0405・API0505）。
