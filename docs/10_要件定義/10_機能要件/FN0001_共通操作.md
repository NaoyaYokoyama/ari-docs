# FN0001 共通操作

## 1. 概要

すべての画面に共通する、ヘッダーによる画面移動・キーボードショートカット・メッセージ表示・確認ダイアログ・配色を定める。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| - | - | - |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| 画面移動・ショートカット | ○ |
| 配色の切り替え | ○ |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0001-BR01 | ヘッダーの左端にロゴ（押すとホーム）を置き、メニューは Home・Folder・Note・Wiki・Docs・Setting の順に並べ、表示中の画面に差し色の下線を付ける。Docs は「Docs を使う」設定（FN0902-BR06）がオンのときだけ出す。右端に探して開く（FN0003）・配色の切り替え・ショートカット一覧のボタンを置く | Docs は設計書を見るための、メイン機能とは別の機能のため |
| FN0001-BR02 | 画面幅が狭いとき（`lg` 未満）は、メニューの文字を隠してアイコンだけ表示する | - |
| FN0001-BR03 | `Alt+数字` は、ヘッダーに出ているメニューへ左から順に振る（機能ごとに決めない）。Docs を出さないときは `Alt+1`〜`Alt+5` が Home・Folder・Note・Wiki・Setting、出すときは `Alt+5` が Docs・`Alt+6` が Setting。`Alt+1` ではホームの検索欄にフォーカスする | キーボードだけで操作できるようにするため。見た目の並びとキーの順を揃え、Setting を一番右に置いたままにするため |
| FN0001-BR04 | `Alt+H/J/K/L` で、画面内のフォーカスを左・下・上・右の領域へ移す（対応している画面のみ） | 同上 |
| FN0001-BR05 | 未保存の変更がある状態でヘッダー・`Alt+数字` から移動するときは、確認ダイアログ（MSG0001）を表示する。ウィンドウを閉じる・再読み込みするときもブラウザの確認を出す | 編集内容を失わないため |
| FN0001-BR06 | 処理結果のメッセージは画面下部の中央にトーストで表示し、info は 3 秒、error は 6 秒で自動的に消す（押すとすぐ消える） | 上部に出すと各画面のタイトル欄に重なり、入力の邪魔になるため |
| FN0001-BR07 | 画面の再読み込みをまたいで表示したいメッセージは `sessionStorage` の `message` に入れておき、読み込み後に表示する | 設定変更後の再読み込みで結果を伝えるため |
| FN0001-BR08 | 入力中以外に `?` を押すと、ショートカットの一覧（ダイアログ）を開く | ショートカットを覚えなくても使えるようにするため |
| FN0001-BR09 | 配色はライト・ダーク・OS に合わせる（既定）から選ぶ。選んだ値はその PC のブラウザ（`localStorage` の `theme`）に保存する | 利用者ごと・PC ごとの好みのため。サーバーに保存するほどの設定ではないため |
| FN0001-BR10 | 確認ダイアログは開いたときに「OK」にフォーカスし、`Enter` で決定、`Esc` でキャンセルする | キーボードだけで操作できるようにするため |

## 8. 決定事項
