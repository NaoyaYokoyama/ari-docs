# FN0401 Note

## 1. 概要

個人用の Markdown のメモ。一覧・作成・編集・削除・お気に入り登録ができる。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| Note（TBL0401） | ユーザー `local` | タイトルと Markdown の本文 |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| 一覧・参照・作成・更新・削除 | ○ |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0401-BR01 | 一覧はタイトルの昇順で、すべて返す | 31 件目以降が表示されない問題があったため（旧 RQ0402） |
| FN0401-BR02 | 作成時は、タイトルの前後の空白を除いて空なら作成しない（画面側のチェック。「作成」を押せない） | - |
| FN0401-BR03 | タイトルは 25 文字以内。作成・更新の API でも、前後の空白を除いて空のもの（MSG0412 と同じ文言）と 25 文字を超えるものを 400 にする | 画面を通さない呼び出しでも、一覧で見分けられないタイトルや長すぎるタイトルを保存させないため |
| FN0401-BR04 | 作成直後の本文は空文字 | - |
| FN0401-BR05 | 更新すると `updated_at` を現在日時にする | - |
| FN0401-BR06 | 未保存の変更があるとき、別の Note を選ぶ・新規作成する・別の画面へ移動する前に確認する（MSG0001。FN0001-BR05） | 編集内容を失わないため |
| FN0401-BR07 | `Ctrl+S` で保存する | - |
| FN0401-BR08 | Note を削除すると、その Note のお気に入りも削除する | 存在しない Note のお気に入りが残らないようにするため |
| FN0401-BR09 | 表示は「編集」「分割」「プレビュー」を切り替えられる。初期表示は「プレビュー」で、選んだ表示はブラウザ（`localStorage` の `editor-mode`）に保存して次も使う。作成直後に「プレビュー」なら「分割」にして本文にフォーカスする。「プレビュー」では本文もタイトルも書けない（`F2` を押すと「分割」にしてタイトルを選ぶ）。本文へ移る操作（`Alt+J`・Vim モードの `<C-l>`）は表示の枠へ移り、Vim モードの `j`・`k` でスクロールする | 作ってすぐ書けるようにするため。読むつもりで押したキーで書き換わらないようにするため |
| FN0401-BR10 | 作成は、一覧の「＋」・`Ctrl+N`・未選択のときの「新しいNote」で開くダイアログで行う。`Enter` で作成し、作成後はその Note を開く。失敗したらダイアログにエラーを表示する | 一覧の上の入力欄と「追加」ボタンが編集中の Note のボタンと混ざって分かりにくかったため |
| FN0401-BR11 | 一覧はタイトルで絞り込める（空白で区切った語をすべて含むもの。全角・半角、大文字・小文字を区別しない）。並びは「更新日の新しい順」（既定）か「名前順」で、選んだ並びはブラウザ（`localStorage` の `content-sort`）に保存する。各行に更新日時を短く表示する（たった今・n 分前・n 時間前・昨日・月/日・年/月/日） | 探しやすくするため。並べ替え・絞り込みは API0401 が返した分（FN0401-BR01）だけが対象 |
| FN0401-BR12 | ショートカット: `Ctrl+N` 新規作成、`Ctrl+S` 保存、`F2` タイトルの編集、`Delete` 削除（入力中以外）、一覧にフォーカス中は `J`/`K`・`↑`/`↓` で移動して `Enter` で開く、`Alt+H/J/K/L` で一覧・タイトル・本文の間を移動。タイトルで `Enter` を押すと本文へ移る | キーボードだけで操作できるようにするため |
| FN0401-BR13 | 保存のとき、タイトルの前後の空白を除いて空なら保存しない（MSG0412） | 一覧で見分けられなくなるため |
| FN0401-BR14 | 更新日時は、端末の時刻（DB の UTC から変換）で表示する | DB の `CURRENT_TIMESTAMP` は UTC のため |

## 5. 処理の流れ

### 5.1 一覧と選択

1. Note 画面を開くと API0401 で一覧を取得し、左に表示する（FN0401-BR11）。
2. Note を選ぶと API0402 で本文を取得して表示する（未保存の変更があれば先に確認する）。取得中は読み込み中の表示にする。
3. ホームのお気に入り・検索結果から来た場合は、その Note を開いた状態で表示する。

### 5.2 作成

1. 「＋」・`Ctrl+N`・「新しいNote」で作成ダイアログを開き、タイトルを入力して「作成」（`Enter`）を押す（FN0401-BR10）。
2. API0403 で作成し、MSG0401 を表示して、作った Note を開き、一覧を再読み込みする。

### 5.3 更新

1. タイトル・本文を編集すると「未保存」を表示する。
2. 保存ボタンまたは `Ctrl+S` で API0405 を呼び、MSG0403 を表示して「保存済」に戻し、更新日時と一覧を新しくする。

### 5.4 削除

1. ゴミ箱を押す（または `Delete`）と MSG0405 で確認する。
2. OK なら API0404 で削除し、MSG0406 を表示する。
