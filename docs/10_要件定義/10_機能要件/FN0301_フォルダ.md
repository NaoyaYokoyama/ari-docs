# FN0301 フォルダ（ノード）管理

## 1. 概要

ノードのルート（既定は `folder/`。FN0301-BR11）以下のファイル・フォルダ（ノード）を一覧表示し、作成・削除・アップロード・OS の既定アプリで開く操作を行う。ノードの実体はファイルシステムにあり、`node` テーブル（TBL0301）にはお気に入りなどで参照するための ID を登録する。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| ノードの実体 | ファイルシステム | ノードのルート（既定は `folder/`）以下のファイル・フォルダ。設計書では `folder/` と書く |
| ノード（TBL0301） | システム | ノードのパスと ID の対応。説明・状態・更新者の列もある |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| 一覧（API0301） | ○ |
| 作成（API0302） | ○ |
| 削除（API0303） | ○ |
| アップロード（API0304） | ○ |
| OS で開く（API0305） | ○ |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0301-BR01 | ノードのパスは `folder/` からの相対パスで、先頭に `/` を付けない（例: `a/b/memo.txt`） | 画面・DB・お気に入りでパスを一致させるため |
| FN0301-BR02 | 一覧は、指定フォルダ直下のノードを返す（API の並び順はファイルシステムの返す順）。読めない項目（アクセス権が無い・壊れたリンクなど）は飛ばし、一覧の取得は止めない。画面ではフォルダを先にして名前順に並べ、列見出しで名前・更新日時・サイズの昇順・降順に並べ替えられる | 探しやすくするため。1 つのファイルのせいで一覧が見られなくならないようにするため |
| FN0301-BR03 | 削除は `parentPath` と `name` で対象を特定する。`name` が空・`.`・`..`、または `/`・`\` を含む場合は 400 | 親フォルダ以上を削除してしまう不具合を防ぐため |
| FN0301-BR04 | フォルダの削除は、中身も含めてゴミ箱へ移す（FN0302） | - |
| FN0301-BR05 | 一覧の行をクリックすると選び、ダブルクリック（または Enter）するとフォルダは中を開き、ファイルは OS の既定アプリで開く（共有モードは FN0301-BR21）。Ctrl（macOS は ⌘）を押しながらのクリックで選ぶものを足し・外し、Shift を押しながらのクリック・↑↓で範囲を選ぶ。Ctrl+A ですべて選ぶ。空いているところのクリック・Esc で選択を外す。2 件以上選ぶと、件数と「切り取り」「コピー」「削除」「選択を外す」の帯を出す | ファイルの編集はアプリの外で行うため。Windows のエクスプローラーと同じ操作にするため |
| FN0301-BR06 | ドラッグ＆ドロップでファイル・フォルダを、「アップロード」ボタン（ファイル・フォルダを選べる）でアップロードできる。一覧の空いているところにドロップすると表示中のフォルダへ、フォルダの行・パンくずにドロップするとそのフォルダへ入れる。フォルダは中の構成を保ったまま保存する。同じ名前があるときは FN0301-BR23。アップロード中はボタンに進み具合（%）を出す | - |
| FN0301-BR07 | 一覧の列は、名前・更新日時・サイズとする。名前の前に種類ごとのアイコン（Excel は緑、Word は青、PowerPoint は橙、PDF は赤、画像・圧縮・動画・音声・ソースコードなど）を出す | 種類を見分けやすくするため |
| FN0301-BR08 | 一覧の各ノードには、お気に入りの `favoriteId` を付けて返す（未登録なら空） | 詳細ダイアログでお気に入りの状態を表示するため |
| FN0301-BR09 | `node` テーブルへの登録は、ノード同期（BAT0301。ファイルの変更を見張って数秒で反映し、10 分ごとに全体を合わせる）とお気に入り登録（API0602）で行う。アプリの外で消された・移されたものの行（とお気に入り）は消す | - |
| FN0301-BR10 | ノードの操作は `folder/` の中に限る。一覧・作成・削除・アップロード・開く の API で、パス（`path`・`parentPath`・`paths`）に `..`・絶対パス・ドライブ指定を含むものは 400（「パスが正しくありません」）とし、何も操作しない。先頭の `/` は取り除く | アプリの管理外のファイルを壊さないため。アップロードはブラウザが事前確認なしに送れる形式のため、他の Web ページから送られても `folder/` の外に書き込ませないため |
| FN0301-BR11 | ノードのルートは、デスクトップアプリでは `<作業フォルダ>/folder`（FN0002）、開発時は `back/config.toml` の `folder_root`（既定は `../folder`）とする。作業フォルダ（FN0002）とは別に変えることはできない（作業フォルダを変えると DB と一緒に切り替わる。FN0002-BR09）。存在しなければバックエンドを起動しない | お気に入りや `node` テーブルがルートからの相対パスで記録されるため。共有モードでも全員で同じルートを使う想定のため |

| FN0301-BR13 | 作成・削除・アップロード・開く の API はログインが必要（未ログインは 401） | ユーザーのデータを扱う API はログイン必須のため（CLAUDE.md の共通の仕様） |
| FN0301-BR14 | 表示中のフォルダが見つからないとき（移動・削除された）は、エラーと「folder の先頭へ」を表示する | 空のフォルダと区別するため |
| FN0301-BR15 | 削除したら、そのノードの `node` テーブルの行と、それを指す全ユーザーのお気に入りを削除する。フォルダなら中のノードの行とお気に入りも削除する。ファイルを消した後のこの後始末に失敗しても、削除は成功として返す（ログに出す） | 存在しないノードのお気に入りが残らないようにするため。ファイルは既に消えているため |
| FN0301-BR16 | ルートフォルダ一覧の API（API0306）もログインが必要（未ログインは 401） | ユーザーのデータを扱う API はログイン必須のため |
| FN0301-BR17 | 共有モードでは、サーバーの OS でファイルを開く API（API0305）は 400（「共有サーバーのファイルはアプリから開けません」）とする。画面からは FN0301-BR21 で開く | ファイルはサーバーにあり、サーバーで開いても利用者には見えないため |
| FN0301-BR18 | 名前は F2・右クリックの「名前の変更」で、一覧の行の中で変える（拡張子の前までを選んだ状態で始める。Enter・ほかをクリックで決定、Esc で取り消し）。使えない名前・同じ名前は FN0301-BR12 と同じ。大文字・小文字だけの変更はできる。`node` テーブルのパス（フォルダなら中のものも）を変え、お気に入り・中身の検索をそのまま使えるようにする | Windows のエクスプローラーと同じ操作にするため |

| FN0301-BR20 | コピー: Ctrl（macOS は Option）を押しながらドラッグする、または「コピー」（Ctrl+C）してから「貼り付け」（Ctrl+V）。同じ名前があれば「名前 - コピー」「名前 - コピー (2)」…にする。フォルダは中身ごとコピーし、自分の中へはコピーできない | 同上 |
| FN0301-BR21 | ファイルはダウンロードできる（右クリックの「ダウンロード」。保存先を選ぶ）。共有モードでファイルを開くと、ダウンロードして利用者の PC の一時フォルダに保存し、OS の既定アプリで開く（保存すると自動でサーバーに戻す。FN0301-BR28） | 共有サーバーのファイルを開けるようにするため |
| FN0301-BR22 | ローカルモードでは、右クリックの「ファイルの場所を開く」で、エクスプローラー（Windows はそのファイルを選んだ状態、macOS は Finder、Linux は入っているフォルダ）を開く | - |

## 5. 処理の流れ

### 5.1 一覧の表示と移動

1. フォルダ画面を開くと、ルート（`folder/` 直下）の一覧を表示する。
2. 左のツリーのフォルダをクリック、または一覧でフォルダをダブルクリックすると、そのフォルダを開く。
3. パンくずリストをクリックすると、その階層へ移動する。`Alt+↑` で 1 つ上の階層へ移動する。

### 5.2 作成

1. 「新しいフォルダ」または「新しいファイル」（`Ctrl+N` は新しいフォルダ）を押すと、作成ダイアログを開く。
2. 種類と名前を入力して「作成」（または `Enter`）を押すと、API0302 を呼び、MSG0309 を表示して一覧とツリーを再読み込みし、作ったものを選ぶ。失敗したらダイアログに MSG0310 を表示する。

### 5.3 詳細・お気に入り・削除

1. 一覧で右クリック、または行頭の「︙」を押すと、詳細ダイアログを開く。
2. 種類・場所・更新日時（共有モードでは更新者・説明も）を表示する。
3. 「開く」でフォルダは中を開き、ファイルは OS の既定アプリで開く。
4. 「お気に入り」でお気に入りの登録・解除を行う（FN0601）。
5. 「削除」を押すと API0303 でゴミ箱へ移し、MSG0321 を表示する（FN0302-BR01）。

### 5.4 アップロード

1. 一覧にファイル・フォルダをドラッグすると、ドロップできることを枠で示す。ドロップするか「アップロード」でファイルを選ぶと、API0304 で表示中のフォルダへ保存し、MSG0311 を表示して一覧とツリーを再読み込みする。失敗したら MSG0312 を表示する。
