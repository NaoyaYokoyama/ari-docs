# FN0902 サーバーの設定

## 1. 概要

全員に効くログインと保存の決まり（セッションの有効期限・ログインのロック・変更履歴に残す数）と、Docs（FN0801）を使うかを、管理者が設定画面の「サーバーの設定」で変える。決めていなければ既定の値で動く。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| 設定（TBL0002 の `server_settings`） | 管理者 | 下の 5 つの値（JSON） |

## 3. 権限

| 操作 | 利用者 | 管理者 |
|---|---|---|
| 設定の表示・変更 | ○（ローカルモード）/ ×（共有モード） | ○ |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0902-BR01 | 全員に効くため、共有モードでは管理者だけが扱える（それ以外は 403。メニューも出さない）。ローカルモードは利用者が扱える | FN0901-BR01 と同じ |
| FN0902-BR02 | 設定と範囲・既定: セッションの有効期限 1〜365 日（既定 30。FN0101-BR09）、ロックするまでの失敗の回数 3〜20 回（既定 5。FN0101-BR12）、ロックする時間 1〜1440 分（既定 15）、変更履歴に残す数 1〜1000 件（既定 100。FN0402-BR02）。範囲の外は 400 で、保存しない | 短すぎる期限・少なすぎる回数で使えなくならないようにするため |
| FN0902-BR03 | ログインの 3 つは共有モードのときだけ画面に出す（ローカルモードはログインしない）。保存すると次のリクエストから効く（再起動は要らない）。有効期限を短くすると、それより前から使っていないセッションはすぐ切れる。残す数を減らすと、その Note・Wiki を次に保存したときに超えた分を消す | - |
| FN0902-BR04 | 画面では、それぞれに説明・範囲・既定の値を出し、範囲の外ならその場で知らせて「保存」を押せなくする。「初期値に戻す」で入力欄を既定の値にする（保存は別） | 初めて触る管理者でも、何が起きるかと安全な値が分かるようにするため |
| FN0902-BR05 | 設定は復元しても今のものを残す（TBL0002。FN0901-BR06） | - |
| FN0902-BR06 | 「機能」の「Docs（Markdown ビューア）を使う」で、Docs（FN0801）を使うかを決める（既定はオフ）。オフのときはヘッダーのメニュー・`Alt+数字`・探して開く・Vim の `gd`・起動したときの画面・設定の「Docs の初期フォルダ」に出さず、`/docs` を開くと Home へ移り、API0801・API0802 は 404 を返す。保存した人の画面にはすぐ反映し、ほかの人・PC には次に画面を開いたとき（API0101）に反映する | Docs は設計書を見るための、メイン機能とは別の機能のため。全員の画面の並び（FN0001-BR03）が揃うよう、利用者ごと・PC ごとではなく全体で決める |

## 5. 処理の流れ

1. 設定画面の「サーバーの設定」を開くと API0908 で今の設定を表示する。
2. 値を変えて「保存」を押すと API0909 を呼び、MSG0907 を表示する。

## 6. メッセージ

| ID | 表示する場面 | 文言 |
|---|---|---|
| MSG0907 | 保存 | サーバーの設定を保存しました |
| MSG0908 | 範囲の外 | 「{項目}」は {最小}〜{最大} {単位}で指定してください |
| MSG0909 | 管理者でない | サーバーの設定は管理者だけが扱えます |
