# FN0002 作業フォルダ

## 1. 概要

デスクトップアプリ（Tauri）は、ファイルとデータを**作業フォルダ**に置く。作業フォルダの中に `folder/`（ノードのルート）と `.ari-docs/`（DB などのデータ）を作る。作業フォルダの場所は exe と同じフォルダの `config.toml` に書き、既定は exe と同じフォルダとする。起動時にその作業フォルダでバックエンドを起動してからホームを表示する。作業フォルダは設定画面から変えられる（将来の共有フォルダ用。RQ0304）。

デスクトップアプリには 2 つの**使い方**がある。使い方はインストーラー（Windows）か初回起動の画面で選び、あとから設定画面でも変えられる。

- 個人用（`local`）: 上の作業フォルダでバックエンドをローカルモードで動かす。ログインは不要で、ほかの PC からは接続できない（FN0101-BR06）
- 共有サーバーに接続（`server`）: バックエンドは動かさず、共有モードで動いているサーバー（OP0007）に接続する。ユーザー ID とパスワードでログインする（FN0101）

開発時（`cargo run` と開発サーバー、デバッグビルドのデスクトップアプリ）はこの機能を使わず、`back/config.toml` の設定で動く（OP0003）。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| アプリの設定ファイル | exe と同じフォルダ | `config.toml`。使い方（`mode`: `local` / `server`。無ければ `local`）、作業フォルダ（`workspace`）、共有サーバーの URL（`server_url`）を持つ。相対パスは exe のフォルダから解決し、`"."` は exe と同じフォルダ |
| 作業フォルダ | 利用者 | `folder/`（ノードのルート）と `.ari-docs/ari.db`（DB）を置く |

既定の配置（初回起動後）:

```text
<exe のフォルダ>/
  <exe>（Linux は実行ファイルか .AppImage）
  config.toml      … workspace = "."
  folder/
  .ari-docs/ari.db
```

exe のフォルダは次のように決める。

| 起動のしかた | exe のフォルダ |
|---|---|
| Windows・Linux の実行ファイル | 実行ファイルのあるフォルダ |
| Linux の AppImage | `.AppImage` ファイルのあるフォルダ（環境変数 `APPIMAGE`） |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| 作業フォルダの変更 | ○（exe のフォルダの `config.toml` を使っているとき。デバッグビルドでは ✕） |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0002-BR01 | 起動に失敗したとき（FN0002-BR06・FN0002-BR07）は、起動エラーの画面（SCR0002）を表示する。ホームなどの画面は表示しない | バックエンドが動いていないため |
| FN0002-BR02 | 作業フォルダは OS のフォルダ選択ダイアログで選ぶ | 存在するフォルダを確実に選ばせるため |
| FN0002-BR03 | 作業フォルダの中に `folder/` と `.ari-docs/` を作る（既にあればそのまま使う）。DB は `.ari-docs/ari.db`、ノードのルートは `folder/`、Markdown ビューアの既定のフォルダも `folder/` とする | ファイルとデータを 1 つのフォルダにまとめ、フォルダごと移せるようにするため。将来の共有フォルダの選択（RQ0304）とも合わせるため |
| FN0002-BR04 | 選んだフォルダに既に `.ari-docs/` がある場合は、そのデータを使うことを画面で知らせる | 既存のデータを引き継げることを伝えるため |
| FN0002-BR05 | exe のフォルダに `config.toml` が無いとき（初回起動）は、使い方を選ぶ画面（SCR0003）を出す。選ぶと `config.toml` を作って再起動する。個人用の作業フォルダは `"."`（exe と同じフォルダ）とする | インストーラーの無い Linux の AppImage と、インストーラーで選ばなかったときにも使い方を選べるようにするため |
| FN0002-BR06 | exe のフォルダに書き込めず `config.toml` を作れないときは、使い方の保存のときにエラー（MSG0005）を表示する | 作業フォルダを選んでも保存できないため。Program Files・`/usr/bin` などに置かれたとき |
| FN0002-BR07 | 作業フォルダが無い・`folder/` などを作れない・バックエンドを起動できない（ポート 8080 が使用中など）ときは、起動エラーの画面にエラーを表示し、作業フォルダを選び直せるようにする | 共有フォルダに繋がっていないときなどに、起動できないまま止まらないようにするため |
| FN0002-BR08 | 作業フォルダを変えたら、`config.toml` に保存してアプリを再起動する。作業フォルダが exe のフォルダなら `"."`、それ以外は絶対パスで保存する | バックエンドが同じプロセスで動いており、作業フォルダを変えるには起動し直す必要があるため。`"."` にしておくと、exe ごとフォルダを移しても使えるため |
| FN0002-BR09 | 作業フォルダを変えると、ファイル・Note・Wiki・お気に入りなどはすべて新しい作業フォルダのものに切り替わる。前の作業フォルダのデータはそのまま残る | ノードのルートと DB を同じ作業フォルダにまとめているため（FN0002-BR03）。お気に入りなどがノードのルートからの相対パスで記録されても（FN0301-BR11）、DB と一緒に切り替わるので食い違わない |
| FN0002-BR10 | 個人用では、バックエンド（API・バッチ）はデスクトップアプリと同じプロセスで動かし、アプリを閉じると止まる | 起動用の exe 1 つで使えるようにするため |
| FN0002-BR11 | Windows のインストーラーは、最初のページで使い方（個人用 / 共有サーバーに接続とその URL）を選ばせ、インストール後に `config.toml` を書く。`config.toml` が既にある（上書きインストール）・サイレントインストールのときは、ページを出さず `config.toml` も書かない | 利用者が最初から使い方を決めて入れられるようにするため（ユーザーの依頼）。更新で設定を消さないため |
| FN0002-BR12 | 共有サーバーに接続する使い方では、バックエンドを起動せず、作業フォルダも作らない。画面の API の接続先を `server_url` にする | データはサーバーにあるため |
| FN0002-BR13 | 共有サーバーの URL は `http://` か `https://` で始まり、ホスト名（とポート）だけを持つ（パス・空白を含まない）。前後の空白と末尾の `/` は取り除いて保存する | 接続先の URL を組み立てるため |
| FN0002-BR14 | 画面で共有サーバーを選んで保存するときは、先に API0104 で接続し、ari-docs の共有モードのサーバーかを確かめる（MSG0006〜MSG0008） | 打ち間違いのまま再起動して使えなくならないようにするため |
| FN0002-BR15 | 使い方は、設定画面の「使い方」・起動エラーの画面・ログイン画面の接続エラー（FN0101-BR11）から変えられる。変えたら `config.toml` に保存してアプリを再起動する（API0004）。今の作業フォルダの設定は残す | 起動後に接続先が使えなくなったときにも直せるようにするため |
| FN0002-BR16 | 個人用のデータ（作業フォルダ）と共有サーバーのデータは別のもので、使い方を変えてもデータは移らない | - |
| FN0002-BR17 | デバッグビルドでは使い方は変えられない。環境変数 `ARI_DOCS_SERVER_URL` があれば、その共有サーバーに接続する（開発用） | 開発時に共有サーバーへの接続を試せるようにするため |
| FN0002-BR18 | Windows のインストーラーで「共有サーバーに接続する」を選んだら、次へ進む前に `<URL>/api/server-info`（API0104）を呼び、ari-docs の共有モードが答えるかを確かめる（Windows に入っている PowerShell を使う。5 秒まで待つ。URL は環境変数で渡す）。確かめられなければ理由（つながらない / ari-docs ではない / 共有モードではない / PowerShell が使えない）を出し、「このまま進める」か「URL を直す」かを選ぶ。URL の終わりの `/` は除いて保存する | 入れたあとに使えないと分かるのを防ぐため。サーバーの用意がまだのときも入れられるようにするため（2026-11-09 の決定） |
| FN0002-BR19 | 共有サーバーに接続する使い方で起動したとき、同じ確かめ方（5 秒まで）でサーバーに接続できるかを確かめ、できなければ「共有サーバーに接続できません」の画面（SCR0002 の 9 章）を出す。「もう一度試す」・接続先の URL の変更・個人用への切り替えを選べる | サーバーが止まっている・URL が変わったときに、利用者が迷わないようにするため |

## 5. 処理の流れ

### 5.1 起動

1. exe のフォルダの `config.toml` を読む。無ければ初回起動の画面（SCR0003）で使い方を選ばせる（FN0002-BR05）。
2. 共有サーバーに接続する使い方なら、URL を確かめて（FN0002-BR13）ログイン画面（SCR0004）かホームを表示する（FN0002-BR12）。
3. 個人用なら、`workspace` の作業フォルダで `folder/`・`.ari-docs/` を確認し（無ければ作る）、バックエンドを起動する。
4. 起動できたらホームを表示する。できなければ SCR0002 にエラーを表示する（FN0002-BR07）。

### 5.3 使い方の選択・変更

1. 初回起動の画面（SCR0003）・設定画面の「使い方」・起動エラーの画面・ログイン画面の接続エラーで、個人用か共有サーバーに接続（URL を入力）かを選ぶ。
2. 「保存して再起動」を押すと、共有サーバーのときは API0104 で接続を確かめる（FN0002-BR14）。
3. API0004 で `config.toml` に保存し、アプリを再起動する。

### 5.2 作業フォルダの変更

1. 設定画面の「作業フォルダ」（SCR0701）か、起動エラーの画面（SCR0002）で「フォルダを選択」を押してフォルダを選ぶ。API0002 で `.ari-docs/` があるかを調べ、作るもの（または既存のデータを使うこと）を表示する。
2. 「このフォルダで再起動」を押すと API0003 を呼ぶ。`folder/`・`.ari-docs/` を作り、`config.toml` に保存して、アプリを再起動する。
3. 再起動後は 5.1 の流れで起動する。

## 9. 未決事項

- ポート 8080 が使用中のときの対処（空いているポートを使う仕組み）
- 作業フォルダの選択で、新しいフォルダを作るか既存の共有フォルダを選ぶかを分ける（RQ0304）
- インストーラーのページは Tauri のテンプレートの都合で最初（ようこそページの前）に出る。順番を変えるならテンプレートを差し替える必要がある
