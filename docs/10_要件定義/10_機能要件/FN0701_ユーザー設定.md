# FN0701 ユーザー設定

## 1. 概要

利用者の表示名と、Docs（Markdown ビューア。FN0801）を開いたときに表示する初期フォルダを変更する。共有モードでは、自分のパスワードも変更できる（API0704）。

あわせて、設定画面の作り（まとまりごとのメニュー・設定の検索）と、この PC だけに保存する画面の使い方の設定（表示・操作・ショートカットの一覧・書き出しと初期化）を決める。初めて使う人は説明を読みながら選べ、慣れた人は検索・ショートカット・書き出しで素早く扱えるようにする。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| ユーザー（TBL0101） | ユーザー `local` | 表示名 |
| ユーザー設定（TBL0701） | ユーザー `local` | Docs の初期フォルダ |
| 画面の使い方の設定 | PC（ブラウザの localStorage） | 配色・文字の大きさ・画面の動き・起動したときの画面・Note と Wiki の表示・削除の確認・隠しファイル・Folder の右のプレビュー・ボタンの説明（`front/src/app/preferences.ts`） |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| 表示名の変更 | ○ |
| Docs の初期フォルダの変更・解除 | ○（ローカルモードのみ） |
| 画面の使い方の設定・書き出し・読み込み・初期化 | ○ |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0701-BR01 | 表示名の変更に成功したら画面を再読み込みし、結果のメッセージを表示する | 画面に表示している表示名を更新するため |
| FN0701-BR02 | Docs の初期フォルダは絶対パスで指定する。保存時に存在するフォルダかを確かめ、正規化した絶対パスで保存する。存在しない・フォルダでない場合は 400 と MSG0703 | 開けないフォルダを保存しないため |
| FN0701-BR03 | Docs の初期フォルダを解除すると、リポジトリの `docs/` を表示する状態に戻る | - |
| FN0701-BR04 | Docs の初期フォルダを設定できるのはローカルモードのみ。共有モードでは 403 | 共有モードで他人にサーバー内のファイルを見せないため（FN0801-BR02 と同じ考え方） |
| FN0701-BR05 | 設定画面は、他の画面から開くときに表示するメニューを指定できる（Docs 画面の「初期フォルダを変更」から開くと「Docs の初期フォルダ」を表示する） | 設定したい項目へすぐ移動できるようにするため |
| FN0701-BR06 | 設定画面の「パスワード変更」は共有モードのときだけ表示する。ローカルモードでは隠す（API も 403）。変更には現在のパスワードが必要で、新しいパスワードは確認用と一致させる（FN0102-BR05 の長さ） | ローカルモードではログインしないため |
| FN0701-BR07 | 設定画面の「表示」で配色（ライト・ダーク・OS に合わせる）を選べる。保存先は FN0001-BR09 のとおりブラウザ | ヘッダーのボタンと同じ設定を、選択肢を見ながら選べるようにするため |
| FN0701-BR08 | 表示名は、前後の空白を除いて空か、今の表示名と同じときは変更できない（「変更」を押せない）。前後の空白は除いて送る。失敗したら MSG0706 を表示する | 空の表示名を作らないため |
| FN0701-BR09 | 設定画面のメニューは「アカウント」「表示と操作」「検索」「管理」「このアプリ」「その他」のまとまりに分けて並べる。メニューの上の欄で設定を探せる（名前と、探すときに使いそうな言葉で一致させる。例:「ロック」で「サーバーの設定」、「文字」で「表示」）。Enter で最初に一致したものを開き、Esc で消す。開いているメニューは URL（`?section=`）に持つ | 項目が増えても、初めての人は場所の見当がつき、慣れた人は名前を打つだけで開けるようにするため。再読み込み・戻るで同じメニューに戻れるようにするため |
| FN0701-BR10 | 「表示」: 配色（FN0701-BR07）、文字の大きさ（小 14px / 標準 16px / 大 18px / 特大 20px。画面全体の文字・余白と Note・Wiki の本文が大きくなる。アイコンの大きさは変えない）、画面の動きを減らす（OS に合わせる / 減らす / 減らさない。ダイアログなどの動きを止める）。既定は標準・OS に合わせる | 見えにくい人・動きで酔いやすい人・動作の遅い PC でも使えるようにするため |
| FN0701-BR11 | 「操作」: 起動したときに開く画面（Home / Folder / Note / Wiki / Docs / 前回の画面。前回の画面には設定画面と開いていたメニューも含む。URL で画面を指定して開いたときはそのまま）、Note・Wiki を開いたときの表示（プレビュー / 分割 / 編集。Note・Wiki の画面で切り替えたときも覚える）、Note・Wiki のボタンの説明を出す（書式のボタン・表示の切り替え・お気に入り・保存・変更履歴・削除。マウスを乗せて少し待ったとき・Tab などのキーで選んだときに、名前と一言の説明を下に出す。クリックでは出さない。オフなら名前だけ。既定はオン）、Folder で削除の前に確かめる（FN0302-BR01 の例外。既定はオフ）、Folder で隠しファイル（「.」で始まる名前）を表示する（既定はオン）、Folder を開いたときに右にプレビューを出す（FN0301-BR31。既定はオン） | よく使う画面からすぐ始められるようにするため。うっかりの削除が心配な人と、隠しファイルが邪魔な人に合わせられるようにするため |
| FN0701-BR12 | 「表示」「操作」は、この PC（ブラウザの localStorage）だけに保存する（配色と同じ。FN0001-BR09）。サーバーには送らない。既定の値と違う項目があれば「既定に戻す」を出す | 家と会社など、PC ごとに変えられるようにするため |
| FN0701-BR13 | 「ショートカット」に、キーボードショートカットの一覧（`?` で開くものと同じ。FN0001）を出し、操作の名前やキーで絞り込める | 覚えていない操作を探せるようにするため |
| FN0701-BR14 | 「設定の書き出し・初期化」で、この PC に保存した画面の使い方の設定を JSON のファイルに書き出す・読み込む・初めの状態に戻す（確認してから）。ログインの情報・ユーザー名・サーバーの設定・データは含めず、消さない。読み込むファイルの知らない値・壊れた値は既定の値にする | 別の PC に同じ設定を移せるようにするため。表示がおかしくなったときに戻せるようにするため |

## 5. 処理の流れ

### 5.1 表示名の変更

1. 左のメニューで「ユーザー名」を選ぶ。
2. 新しい表示名を入力して「変更」を押すと API0701 を呼ぶ。
3. 成功したら画面を再読み込みし、MSG0701 を表示する。

### 5.2 Docs の初期フォルダの変更

1. 左のメニューで「Docs の初期フォルダ」を選ぶ（Docs 画面の「初期フォルダを変更」からも開ける）。
2. API0702 で今の設定を取得し、「現在」の欄に表示する。未設定なら、代わりに表示するフォルダ（リポジトリの `docs/`）を表示する。
3. 絶対パスを入力して「保存」を押すと API0703 を呼び、MSG0702 を表示する。
4. 「解除」を押すと、空文字で API0703 を呼び、MSG0704 を表示する。

## 8. 決定事項

| 日付 | 内容 | 理由 |
|---|---|---|
| 2026-10-11 | パスワード変更は共有モードの機能とし、本設計の対象外とする | ローカルモードではログインしないため。2026-10-30 に共有モードを対象に加え、現在のパスワードと確認用の検証を入れた（FN0701-BR06） |
| 2026-10-11 | Docs の初期フォルダを設定できるようにする。保存先は新しいテーブル `user_setting`（TBL0701） | ユーザーの要望。今後の利用者ごとの設定もこのテーブルに列を足して保存できるようにするため |
| 2026-10-11 | 設定画面の「パスワード変更」をローカルモードでは隠す（FN0701-BR06） | ユーザーの判断 |
| 2026-10-16 | 「表示」（配色）を追加し、表示名の画面側の入力チェックとエラー表示を入れる（FN0701-BR07・BR08） | 見た目と使い勝手の仕上げ（ユーザーの依頼） |
| 2026-11-08 | Note・Wiki のボタンに一言の説明を出し、設定で消せるようにする | ユーザーの依頼（「フォーカスしたときにひとこと説明がほしい（設定で無効にすることが可能）」） |
| 2026-10-30 | 設定画面をまとまりごとのメニューと検索に作り直し、文字の大きさ・画面の動き・起動したときの画面・削除の確認・隠しファイル・ショートカットの一覧・設定の書き出しと初期化を加える（FN0701-BR09〜BR14）。項目と既定の値は実装時に決めた | ユーザーの依頼（素人から玄人まで満足できる設定に。中身はおまかせ。あとでユーザーの意見を入れる） |

## 9. 未決事項

- 画面の使い方の設定を、PC ごとではなくユーザーごと（サーバー）に保存するか
- ショートカットのキーを利用者が変えられるようにするか

- 表示名のサーバー側の入力チェック（空文字・文字数）
- ローカルモードで表示名を表示する場所（現行はホームのあいさつと設定画面だけ。ヘッダーは共有モードのときだけ表示する）
