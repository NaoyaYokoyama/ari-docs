# FN0201 ホーム（検索）

## 1. 概要

キーワードで Note・Wiki・ノード（ファイル・フォルダ）を横断検索し、結果から各画面へ移動できる。あわせて、お気に入り（FN0601）の一覧を表示し、そこから各画面へ移動できる。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| Note（TBL0401） | ユーザー `local` | 検索対象 |
| Wiki（TBL0501） | ユーザー `local` | 検索対象 |
| ノード（TBL0301） | - | 検索対象（名前） |
| お気に入り（TBL0601） | ユーザー `local` | 一覧の表示対象 |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| 検索（API0201） | ○ |
| お気に入り一覧（API0601） | ○ |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0201-BR01 | Note・Wiki はタイトルまたは本文に、ノードは `folder/` からの相対パスにキーワードを含むもの（部分一致）を対象とする。ファイルの中身でも探す（FN0202） | - |
| FN0201-BR02 | ノードは `node` テーブルに登録済み（同期バッチ BAT0301）で、ファイル・フォルダの実体があるものだけを返す | 同期バッチは削除されたファイルの行を消さないため |
| FN0201-BR03 | 検索結果は Note・Wiki・ノードの順に並べ、画面では種類ごとにまとめて表示する。Note は更新日時の古い順、ノードは名前で見つかったものをパスの順に、そのあとに中身で見つかったものをパスの順に並べる（FN0202-BR07） | 現行実装の仕様（ノードは 2026-10-16、中身は 2026-10-30 に追加） |
| FN0201-BR04 | 検索はキーワード入力欄で Enter を押したときに実行する。前後の空白を除いて空のとき・かな漢字変換の確定の Enter では実行しない。`Esc` で入力と結果を消す | 空のキーワードでは全件が返るため |
| FN0201-BR05 | お気に入り一覧は、ノード・Note・Wiki の順に並べる | 現行実装の仕様 |
| FN0201-BR06 | 検索結果・お気に入りをクリックすると、種類に応じて各画面で開く（5.2） | - |
| FN0201-BR07 | 検索していないときは、「最近更新されたもの」に、Wiki（8 件。最後に更新した人つき）・ファイル（10 件。フォルダと消えたものは除く。更新日時はノード同期 BAT0301 が記録したもの）・自分の Note（5 件）を、新しいものから出す。クリックすると各画面で開く | 共有モードで、ほかの人の変更に気づけるようにするため |
| FN0201-BR08 | 検索結果のファイル・フォルダが 2 つ以上の場所（`folder/` 直下のフォルダ）にまたがるときは、場所で絞り込むボタン（すべて・各フォルダ）を出す | 結果が多いときに探しやすくするため |
| FN0201-BR09 | 検索欄の横のボタンで、探す種類を選べる（複数可。既定は「すべて」）。種類は Excel・CSV（`xlsx` `xlsm` `xlsb` `xls` `ods` `csv` `tsv`）・Word（`docx` `docm` `doc` `rtf` `odt`）・PowerPoint（`pptx` `pptm` `ppt` `odp`）・PDF・テキスト（`txt` `md` `log` `json`・コードなど）・画像（`png` `jpg` `gif` `bmp` `webp` `svg` `tif` `heic`）・その他のファイル・フォルダ・Note・Wiki。名前で見つかったものと中身で見つかったもの（FN0202）の両方を絞り込む。拡張子の大文字・小文字は区別しない。「すべて」のときに 1 つ選ぶとそれだけになり、すべて選ぶ・すべて外すと「すべて」に戻る。結果を出しているときに変えると、選んだ種類で探し直す。選んだ種類はこの PC（`localStorage` の `preferences`）に覚え、設定の書き出し・初期化に含める（FN0701） | 探したい種類のファイルだけを見たいため（ユーザーの依頼） |

## 5. 処理の流れ

### 5.1 検索

1. 利用者がキーワードを入力して Enter を押す。
2. フロントが API0201 を呼び、検索結果を種類（Note・Wiki・ファイル・フォルダ）ごとに一覧表示する。0 件のときは MSG0201 を表示する。

### 5.2 お気に入り・検索結果から移動

1. ホームを開くと、フロントが API0601 を呼び、左側にお気に入りを表示する。
2. 利用者がお気に入りか検索結果をクリックすると、種類に応じて次の画面へ移動する。
   - Wiki: Wiki 画面（SCR0501）で、その Wiki を開く
   - Note: Note 画面（SCR0401）で、その Note を開く
   - ノード: フォルダ画面（SCR0301）で、ノードの親フォルダを開く。フォルダなら中を開き、ファイルなら詳細ダイアログを開く

## 8. 決定事項

| 日付 | 内容 | 理由 |
|---|---|---|
| 2026-10-16 | 検索結果から各画面で開けるようにする（FN0201-BR06。旧 RQ0201） | ユーザーの依頼（足りない機能の追加） |
| 2026-11-08 | 探す種類を選べるようにする（FN0201-BR09。既定はすべて）。種類ごとに複数選べ、ホームの検索欄の横に置く。Note・Wiki・フォルダも種類に含める | ユーザーの依頼（場所と単位はユーザーの選択。Note・Wiki・フォルダを含めるのは実装時に決めた） |
| 2026-10-16 | ノード（ファイル・フォルダ名）を検索対象に含める（FN0201-BR01・BR02） | 検索欄の案内に「ファイル」とあり、それに合わせるため（ユーザーの依頼） |
| 2026-10-16 | 空のキーワードでは検索しない（FN0201-BR04） | 全件が返って意味が無いため |
| 2026-10-30 | ホームに最近更新されたものを出し（FN0201-BR07）、検索結果を場所で絞り込めるようにする（FN0201-BR08） | ユーザーの依頼（おすすめの機能・修正案をすべて対応） |
