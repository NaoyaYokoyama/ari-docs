# FN0801 Markdown ビューア

## 1. 概要

指定したフォルダ以下の Markdown を閲覧専用で表示する。あわせて、ドキュメントルール（`docs/00_概要/0090_ドキュメントルール.md`）に沿ったチェック結果を警告として表示する。Folder（FN0301）とは独立した機能とする。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| Markdown ファイル | ファイルシステム | 指定フォルダ以下の `.md`。ari-docs からは変更しない |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| リポジトリの `docs/` を表示 | ○ |
| 任意のフォルダを指定して表示 | ○ |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0801-BR01 | 表示するフォルダは、URL の指定 → 設定の初期フォルダ（FN0701）→ 既定のフォルダの順に決める。既定のフォルダは、デスクトップアプリでは `<作業フォルダ>/folder`、開発時はリポジトリの `docs/`（`config.toml` の `docs_default_root`） | 普段使うフォルダをすぐ開けるようにするため |
| FN0801-BR02 | 任意のフォルダを指定して表示できる | 設計書などをリポジトリの外で管理しても閲覧できるようにするため |
| FN0801-BR03 | 指定フォルダの外のファイル（`..`・絶対パス・シンボリックリンク経由）は読めない。違反は 400 | フォルダ外の情報漏えいを防ぐため |
| FN0801-BR04 | `.md` 以外のファイルは読めない | 閲覧対象を Markdown に限るため |
| FN0801-BR05 | 閲覧専用とし、ファイルの作成・変更・削除はしない | Folder（FN0301）と役割を分けるため |
| FN0801-BR06 | 先頭の YAML（front matter）を見出しのカードとして表示する。値の ` #` 以降はコメントとして無視する | - |
| FN0801-BR07 | 次の場合に警告を表示する: front matter が無い／必須項目（id・title・type・status・updated）が無い／id がファイル名と一致しない／id が重複／status が規定外／updated が YYYY-MM-DD でない（テンプレートを除く）／related に存在しない ID がある（テンプレートを除く） | ドキュメントルールの 4〜6 章 |
| FN0801-BR08 | 本文中と related の ID（FN・SCR・API・TBL・BAT・UT・IT・OP・TL と業務ルール ID）は、該当する文書へのリンクにする。コードブロックとインラインコードの中は対象外 | 文書間を ID でたどれるようにするため |
| FN0801-BR09 | 本文中の `<!-- -->`（記入ガイド）は、表示するかどうかを切り替えられる。初期値は表示する | テンプレートの確認に使うため |
| FN0801-BR10 | 表示中のフォルダと文書を URL（`/docs?root=...&path=...`）に保持する | 再読み込みや共有で同じ表示を開けるようにするため |
| FN0801-BR11 | ツリーの上の検索欄で、ファイル名・ID・名称（front matter の `title`）を部分一致で絞り込む。空白で区切った語はすべてを含むものに絞る。全角・半角と大文字・小文字は区別しない | 文書を早く探せるようにするため |
| FN0801-BR12 | 検索中は、該当する文書が見えるようにフォルダをすべて開く。Enter で先頭の結果を開き、Esc で検索をやめる。入力欄の外で `/` を押すと検索欄にフォーカスする | キーボードだけで探して開けるようにするため |
| FN0801-BR13 | 本文の ```` ```mermaid ```` ブロックは図として描画する。書き方の誤りで描画できないときは、原文とエラー内容を表示する | 図は mermaid で書くルールのため（ドキュメントルール 7 章） |
| FN0801-BR14 | 設定の初期フォルダが存在しないときは、既定のフォルダを表示し、その旨のお知らせを表示する | エラーのままにすると、空欄で表示し直しても同じエラーになり抜け出せないため |
| FN0801-BR15 | サーバーの設定の「Docs を使う」（FN0902-BR06。既定はオフ）がオンのときだけ使える。オフのときは画面に出さず、API0801・API0802 は 404 | メイン機能とは別の、設計書を見るための機能のため |

## 5. 処理の流れ

1. ビューアを開くと、API0801 で指定フォルダ（未指定なら `docs/`）の Markdown の一覧と front matter を取得する。
2. 左にフォルダツリー、右に「一覧・チェック結果」を表示する。
3. 文書を選ぶと、API0802 で本文を取得して表示する。
4. 上部の入力欄にフォルダのパスを入れて「表示」を押すと、そのフォルダに切り替える。空欄なら初期フォルダ（FN0801-BR01）に戻る。「初期フォルダを変更」を押すと設定画面（SCR0701）を開く。
5. ツリーの上の検索欄に入力すると、ツリーを絞り込む（FN0801-BR11、FN0801-BR12）。

## 8. 決定事項

| 日付 | 内容 | 理由 |
|---|---|---|
| 2026-10-11 | Folder 画面とは独立した、フォルダ指定のビューアとする | Folder は DB の状態と紐づくため |

| 2026-10-11 | mermaid の図を描画する（FN0801-BR13）。ライブラリ `mermaid` 11 系を使い、図を表示するときに読み込む | 図を mermaid に統一したため（ユーザーの要望） |
| 2026-10-11 | 設定の初期フォルダ（FN0701）を使えるようにする（FN0801-BR01、FN0801-BR14） | ユーザーの要望 |
| 2026-11-08 | 設定で使う・使わないを切り替える（既定は使わない。FN0801-BR15） | ユーザーの依頼（メイン機能とは別にする） |
