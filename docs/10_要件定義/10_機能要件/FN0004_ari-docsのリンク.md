# FN0004 ari-docs のリンク

## 1. 概要

ファイル・フォルダ・Wiki・Note の場所を、`ari://` で始まる短い文字（リンク）にしてほかの人に渡せるようにする。受け取った人は、ari-docs の探して開く（Ctrl+P）やホームの検索欄に貼るか、Note・Wiki の本文に書かれたリンクを押すと、同じ ari-docs の中でそこへ移れる。PC の絶対パス（`C:\Users\…`）ではなく、ari-docs の中の場所で指す。

## 2. 対象データ

| データ | 持ち主 | 説明 |
|---|---|---|
| リンク | - | 保存しない。画面で作り、画面で読む |

リンクの形:

| 対象 | 形 | 例 |
|---|---|---|
| フォルダ | `ari://folder/{folder/ からのパス}` | `ari://folder/テスト用/01_文書` |
| ファイル | `ari://file/{folder/ からのパス}` | `ari://file/テスト用/01_文書/報告書.pdf` |
| Wiki | `ari://wiki/{wikiId}` | `ari://wiki/wk_7WTYADM1WDG1` |
| Note | `ari://note/{noteId}` | `ari://note/nt_7WTYADM1WDG1` |

## 3. 権限

| 操作 | 利用者 |
|---|---|
| リンクを作る・開く | 利用者。開けるかは対象の権限に従う（Note は本人だけ） |

## 4. 業務ルール

| ID | ルール | 理由 |
|---|---|---|
| FN0004-BR01 | パスは読めるように日本語のまま書き、`%`・空白・括弧・`[]<>#?"'` と `` ` ``・`\` だけを `%xx` にする（チャットや Markdown のリンクで切れないように）。読むときは `%xx` を戻し、前後の空白・`<>` は除く。`..` を含むもの・空のファイルのパスは開かない | チャットに貼っても読めて、壊れないようにするため |
| FN0004-BR02 | リンクを作る: Folder の右クリックの「リンクをコピー」（複数選べば 1 行に 1 つ）・空いているところの「このフォルダのリンクをコピー」・Ctrl+Shift+C（選んでいなければ表示中のフォルダ）。Note・Wiki の画面の上の「リンクをコピー」と、一覧の右クリックの「リンクをコピー」。コピーしたらお知らせを出す（Note は「自分しか開けません」も添える） | すぐ渡せるようにするため |
| FN0004-BR03 | リンクを開く: 探して開く（FN0003）に貼ると「リンクを開く: {名前}」だけを出し、Enter で移る（サーバーには探しに行かない）。ホームの検索欄に貼って Enter でも移る（探さない）。Note・Wiki の本文のリンク（`[名前](ari://…)`）を押すと移る | 受け取った人が迷わず開けるようにするため |
| FN0004-BR04 | 移り先: フォルダは中を開く。ファイルは OS のアプリで開かず、入っているフォルダを開いて選ぶ（右のプレビュー（FN0301-BR31）で中身が見える）。Wiki・Note はその画面で開く。見つからなければ各画面のお知らせ（Folder は「「{名前}」が見つかりません（移動・削除された可能性があります）」） | 開く前に場所と中身を確かめられるようにするため |
| FN0004-BR05 | Note・Wiki の本文にリンクだけ（1 行に 1 つ）を貼ると、名前を付けた Markdown のリンク（`[名前](ari://…)`）にして入れる。名前はファイル・フォルダは最後の名前、Wiki・Note は今のタイトル（引けなければ「Wiki」「Note」） | 本文で読みやすくするため |
| FN0004-BR06 | 名前の変更・移動をするとファイル・フォルダのリンクは使えなくなる（パスで指すため）。Wiki・Note のリンクは ID で指すので、タイトルを変えても使える | パスはお気に入りなどと同じ考え方（FN0301-BR11） |

## 5. 処理の流れ

1. 作る: 対象からリンクの文字を作り、クリップボードに入れる（`front/src/lib/ariLink.ts`・`front/src/app/useAriLink.ts`）。
2. 開く: 文字を読み、画面と state を決めて移る（未保存の変更があれば確かめる。FN0001-BR05）。

## 8. 決定事項

| 日付 | 内容 | 理由 |
|---|---|---|
| 2026-11-08 | ari-docs の中で場所を渡せるリンク（`ari://`）を作る。開き方はアプリの中に貼る・本文のリンクを押す。対象はファイル・フォルダ・Wiki・Note | ユーザーの依頼（「同じ ari-docs ですぐ移動できる感じ。PC の絶対パスとは違う」）。開き方・対象はユーザーが選んだ |
| 2026-11-08 | チャットなどのリンクを押して ari-docs を開く（OS に `ari-docs://` を登録する）ことはしない | ユーザーの選択。Linux の AppImage では登録が不安定で、作業も増えるため |
